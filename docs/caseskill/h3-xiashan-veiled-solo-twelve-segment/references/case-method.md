## 方法来源与适用范围

将下山案例的资产分权、袖与面纱消歧、动作链、局部镜头模式和逐段完整提交方法转为可维护的编排流程，先修正文内可证的时间和状态冲突，再生成执行文本。

本方法由原案例文本、逐案评估和 H3 官方协议共同整理。原案经验、评估发现与本次补齐的数据/检查接口须分别表述；案例作者的成功报告不等于本次实测。原稿快照保留原貌，冲突由本文件及技能入口裁决。

- 原案例十二段、141.845秒、134 BPM、四处Hero、两次旋转、独舞、空手、暖灯冷影和半纱均为项目设置，不是H3通用限制。
- 本技能提出的S05／S09模式修订、S03／S08脚部标题修订、S11峰值前出态属于可审查的工程决策，不冒充作者原始结果。
- 原稿中歌词和半纱透气表现并不证明模型可精确同步口型；保护口鼻遮挡比补造可见唇形优先。
- 研究覆盖全部文本与评估，不包含音频、视频生成或视觉验收；提到的验证只是一份执行计划。

## 失败表现与修复

| 失败表现 | 修复步骤 | 依据 |
|---|---|---|
| 袖子掠过脸后面纱消失 | 将动作主语改为舞袖，声明袖与面纱分离且不接触，面纱附着和口鼻覆盖贯穿；场景门帘另名。 | README.md:17；prompt.md:300–303,659–663 |
| 歌词说有人举杯，空场出现宾客 | 使用空置建筑和无人高台，歌词标为非视觉锚点，移除字面叙事动作与暗示人物存在的环境称呼。 | README.md:16；prompt.md:266,283 |
| 动作链写4拍，窗口却接近8拍 | 由精确BPM复算，明确增加过渡或保持拍数，或重编窗口；不得把未分配的时间算成已精确对拍。 | prompt.md:51–59；review:29 |
| 被称为稳定段的镜头过冲或绕行 | 检查模式白名单和局部覆写，删掉非法E8；把相机路径、roll和主体旋转分开，消除orbit与no orbit同窗并存。 | prompt.md:309,553；review:31 |
| 手部或发丝特写实为脚，或已经举到顶还继续升高 | 以实际动作和可见构图修正标题／相机／接缝；峰值接力把前段出口改为峰值前，而不是重复无路可走的状态。 | prompt.md:169–187,474–492,669–724 |

## 迁移示例

**任务**

做36秒、3段各12秒的独舞：图1是无头正面服装，图2给脸和背面，面纱不能摘。BPM120、全曲首拍0.25秒已由我提供；第2段允许轻微延迟观察，第3段最后0.5秒完全定住。歌词表暂时没有，全部复用原音频。

**预期处理示例**

时间表为[0,12)、[12,24)、[24,36]，精确拍长0.5秒；因12秒正好24拍，三段局部首拍均为0.25秒，这是换算结果而非无条件复制。不生成歌词onset。图1授权正面身体与服装、图2授权脸／发型／背部／半纱，场景与调色另按用户文字。面纱始终附着遮口鼻；舞袖可扫脸前但不碰面纱。第1段11.5–12.0秒左袖在肩高由右向左扫，身体左脚承重；第2段0–0.5秒同一左袖同向续动，随后揭示身体，不自动复刻参考照站姿。只给第2段配置观察→迟跟→轻过冲→修正，不改变舞者稳定性。第2段末保持右掌在胸前上行，第3段从同一掌和支撑起势。第3段11.5–12.0秒明确关闭胸部提沉、足底微滚和相机运动；若仍有布料余动则不称整画面冻结。三段分别生成完整Ref2VA六字段，Audio 1均为对应12秒原曲fully_copy，不追加风声或衣料声。资产与镜头检查是待执行计划，不能据此宣称面纱已经通过生成测试。

示例是编排示范；其中任务给定参数和演算不代表当前已经读取了对应媒体，也不代表一次 H3 推理已完成。完整生成端交付仍需按输出模板选择正确字段和真实素材绑定。
