# 双图分权与面纱状态保护的多段独舞

将下山案例的资产分权、袖与面纱消歧、动作链、局部镜头模式和逐段完整提交方法转为可维护的编排流程，先修正文内可证的时间和状态冲突，再生成执行文本。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **参考权威表**：逐图登记可提供的信息。无头正面照只授权正面服装与身体；三视图可授权脸、发型、背部和穿戴物。环境、色调、姿势、首帧必须另列，不因一张图出现过就自动继承。
- **不可变资产清单**：标明面纱、眼镜、头饰等的佩戴、遮挡、透明度和可变形边界，并给舞袖、环境纱帘等相近材质的物体独立名字。
- **时间与音频证据**：提供全曲或分段时长、源起止、BPM／首拍或实测拍点、歌词 SRT／onset 表、最终音频使用策略；没有媒体或文件则标为用户给定／待验证，不能报告40/40通过。
- **舞蹈与镜头配置**：给出主要动作驱动、技术峰值、地面段、静止定义、可用模式及适用段、空间演进和背景人物许可。将段数、旋转次数、半纱设计与相机高度视为项目参数。

## 执行流程

1. **建立一份可编译的主配置**：统一保存图像权威、资产状态、背景许可、色调、音频、段界、局部拍点、动作入口出口和镜头模式。最终每段内联必要约束，但维护时从同一配置生成，不能靠文件末尾的全局说明让独立任务自动继承。
2. **划清身体、衣袖、面纱和场景帘幕**：面纱始终附着并保持口鼻覆盖，眼眉按授权可见；舞袖可经过脸前但不拉扯面纱；手推的纱只能是明确命名的门帘。用附着／覆盖锁替代含糊的所有纱都不动；若允许呼吸带来的微变形，不再同时写面纱绝对静止。色调来自独立文字要求，不能冒称无头服装图提供环境。
3. **选择时间权威并重算每段拍网格**：原案复刻以正文十二段连续的0.000–141.845秒为文本权威，标记README中至181.956秒的切点串为旧版本；真实媒体到手后再核对。局部时间由全局拍点减去段起点，不能每段都复用0.441秒首拍。用60/BPM保留精度，逐窗检查动作拍数＋过渡＋保持是否覆盖窗口；例如C1的0.889–4.471约8拍，不能只标4拍而不交代余时。
4. **编排带静止优先级的动作链**：每链写支撑脚、重心、身体朝向、手袖路径、相对拍数和出态；复杂地面段明确坐姿后弯→侧卧→支撑高踢→回落→跪→站的接触点。持续呼吸层只适用于未被覆盖的区间；绝对静止窗口显式暂停胸部与脚底微动，或改为宏观姿态保持并允许呼吸，两种措辞不混用。技术峰值和旋转次数按新任务分配。
5. **把歌词限制为时序与情绪信息**：有证据才写逐句本地onset；歌词中的宾客、举杯、来人不产生画面人物或道具。空场用具体空置建筑描述，避免host／banquet等词暗示人物。原案局部口鼻随句微动只是可选表演政策；用户不要求口型则关闭，并保留面纱覆盖。场景投影明确属于同一个舞者，不新增第二角色。
6. **逐接缝核验实际可见对象**：登记左右侧、物体、屏幕方向、速度、身体支撑和景别；切点说明动作原因。原案S03正文起于脚，S08也起于脚，应默认把HAND／HAIR标题与相机修为脚部特写，或确实重编动作而不能只改标签。S07静止→S08起步作为明确的静止切点例外；S11→S12默认把前段出口修为接近最高点仍上行，避免已经最高又继续升高。第一段没有前段时单独定义开场。
7. **用模式白名单消除相机冲突**：稳定为默认；延迟观察模式只用于配置允许的段，按观察→迟反应→轻过冲→修正→重新捕获组织，舞者自身不醉。原案默认保留S03／S10／S11许可，删除S05的E8过冲；S09选择稳定同步弧线或固定机位，删除E8延迟环绕及相反的orbit／no orbit组合。需要改白名单时同时修改主配置和每段正文。机位写真实位置、轴向、主体关系和可见结果。
8. **编译官方字段并给出分层验证计划**：按Ref2VA六字段和detailed_description组织英语执行正文，将真实切镜编为[Shot N]、动作时间窗保留为镜头内阶段；参考图不伪装成I2VA首帧。音频若完整复用则统一audio reuse＋fully_copy并禁止叠加新声，删除节奏参考／No signal copy等相反句。列出资产与空背景试段、双段接缝、旋转、地面和终止段的待执行检查；只对现有文本报告审计结果。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **XS01**：每段执行文本必须包含所需规则；统一配置负责维护，独立任务不依赖文件末尾全局段。
- **XS02**：图像权威按属性分开，正面服装图不同时控制环境与色调；无头信息不能用于面部锁定。
- **XS03**：穿戴面纱、可挥动舞袖、可推开的场景纱帘是三个对象；动作主语、接触和不可变状态必须区分。
- **XS04**：141.845秒正文时间表与181.956秒README不能并用；局部拍点需从源时间换算，动作拍数与窗口余时全部分配。
- **XS05**：绝对静止覆盖持续微运动层；若选择宏观静止，则删除absolute等绝对措辞并说明仍可呼吸。
- **XS06**：歌词提供时序和情绪，不默认增添人、物、字幕或完整口型；没有SRT和音频不能声称逐句已对齐。
- **XS07**：接缝的对象必须在前段实际结尾和后段实际开头可见；静止起步与首段开场是显式例外，不套用仍在运动的模板。
- **XS08**：稳定与延迟观察模式通过段级白名单选择；不能同时要求稳定、不环绕及延迟环绕。
- **XS09**：手、地面支撑与身体发力应驱动袖摆；地面技术需写接触转换，不以衣料运动代替动作因果。
- **XS10**：原案混合的首帧话术、integrated_multimodal_description和音频参考／全复用冲突须编译为单一Ref2VA方案；原文仅作档案。

## 输出与检查

- **权威与资产配置**：每张图的授权／排除属性，穿戴物、舞袖、门帘的状态与接触边界，背景与调色来源，镜头模式白名单。
- **时间和动作总表**：源段界、段长、局部拍点、证据状态、链入态／出态、已分配拍数与余时、技术峰值和静止覆盖区间。
- **逐段可提交提示词**：英语Ref2VA六字段、完整内联规则、真实切镜与镜头内阶段、统一音频使用策略；与只读原稿区分。
- **接缝与验证清单**：相邻段可见对象／方向／支撑／速度表，静止切点例外，资产背景试段、双段接缝、地面、旋转、终止检查及尚未验证项。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash

```
