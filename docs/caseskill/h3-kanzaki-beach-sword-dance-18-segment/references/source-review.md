## 2. 多维简评

**方法论完整度。**`methodology.md` 明确作品主题、音乐结构、权限、动作、镜头、状态、声音、独立提示词及检查顺序，并把错误分成身份、状态、时间、镜头、场景问题后定向修订。对单人道具表演 MV，可作为主流程骨架；对动作迁移、多人物剧情或可替换场景仍需额外分支，原文也区分了方案权限。[S2：14–65、269–337]

**输入输出与静态一致性。**输入是一张视觉图和各段裁剪音频，输出为六字段文本。逐段静态核对确认：18 段时长合计 **230.034 秒**，每段均具六字段且仅出现一个 `[Shot 1]`。这是文本结构检查，不证明接口接受全部字段、生成按毫秒执行或影片一镜到底成功。[S3：65–1186]

**核心可迁移机制。**“外观交给图、状态交给时间表”很适合抽取：同一物件的设计、数量、持有人、位置及状态转换应分开管理。图像初始收刀状态不应覆盖后续持刀状态，这一优先级在 SEG03–18 中反复落实。后期匹配剪辑也被明确区分于段内切镜，避免把不同生产环节混为同一指令。[S1：53–65；S2：132–171、233–252；S3]

**方法与实例落差。**README 要求从总则到每镜头不留度数，实际 SEG01/02/05/09/14 仍有角度数字；SEG17 相机段同时组合后退、环绕、升高和前推，尚未落实“一个主运镜＋至多一个辅助”。这证明不能把方法文章中的要求直接记为成品已满足。[S1：67–73；S3：130、191、374、616、917、1107]

**复现边界。**参考图、音频和成片不随仓分发，且没有可运行 skill、模型版本、生成参数与多轮结果统计。原文勾选“自检完成”属于作者记录；本次未观看媒体，也未运行 H3。六字段应继续服从实际工作流语法，方法文自身亦有此限定。[S1：7–14、104–111；S2：290–304；S3：51–62]

## 3. skill 化判断与最小落地步骤

建议将本案例优先作为“长篇道具表演 MV 编排”原型，并把案例实体留在参考材料中：

1. 定义输入配置：参考图权限、音频 manifest、段落功能、主体与道具数量、状态转换、主运镜和后期桥接方式。
2. 先生成统一状态/时间表，再编译每段六字段；规则来源与当前状态使用单一权威版本。
3. 静态审查时间覆盖、重复拔刀、初始状态冲突、字段适配、机位语法和运镜组合；作品级检查另行记录。
4. 用开场、持刀连续段、细节近景及高潮段做生成回归，覆盖道具复制、握持和海岸连续性，再扩到跨段剪辑。

## 4. 主要缺口与优先级

- **P0：同步规范与正文。**清理上述五处度数及过多主运动；若保留某项例外，应写明适用条件。[S3]
- **P0：统一状态与时间说明。**SEG02 段前描述“剑已处在身体侧下方”，正文却从完整收刀开始；SEG01 状态锚指定 3.500–3.850 秒拔刀，动作事件又写 3.870 秒开始拔刀。原文已明确授权 SEG01、SEG02 各自独立开场拔刀，且组内采用方向/母题匹配；两次拔刀本身不另列为错误。[S1：57–58；S3：23、45、60、118、124、158、163、179–183]
- **P1：压缩冗余并固定握持。**方法提倡避免重描外貌、明确解剖学握持关系，但实例大量重复服装外观并用“正确的手”等泛称。应按实际资产决定必要描述与持握字段。[S2：54–65、165–171；S3：102、132、224、254]
- **P1：补工程验证。**以可替代的授权测试资产记录模型/工作流版本及回归结果，保持原案例未公开资产的边界。[S1：12、111]
