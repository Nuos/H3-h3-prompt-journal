# 以道具状态与单镜头组织长篇表演MV

将海滩剑舞的外观／状态双轨、独立分段编译、物理机位与技术和作品双重审查转成可迁移导演流程，保留已授权的开场重述而消除真实文内冲突。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **作品与场景权限**：选择固定参考现场或可替换背景；列出身份、服装、道具、环境、天气和光向的图像授权与排除范围，并定义表演或剧情定位。
- **道具状态配置**：登记道具数量、设计来源、解剖学持握手、鞘所在身体侧、初始状态、允许的拔出／收回区间和跨段是否允许开场重述。资产不可见时不猜测正确手。
- **音频与时间表**：提供源窗、分段文件、段长、可靠拍点／首拍、歌词或器乐事件、音频最终使用政策；保留原裁切，不擅自切齐小节或重新起拍。
- **动作与镜头意图**：为每段选一个主要视觉问题、动作链、一个主运镜及可选辅助、可见部位优先级和后期桥接母题。动作参考若只是文字转写，不虚构已上传Video引用。

## 执行流程

1. **确定现场与表演授权**：先选固定现场或可替换世界，再写视觉Subject；原案图1同时锁人物与海滩，但新任务只锁身份时不得保留海滩绝对权威。纯道具表演仅借动作与镜头语言，不把参考作品的敌人、战斗、魔法或歌词字面意象搬入。已有外观由参考承担，避免每段重写服装与道具设计。
2. **建立外观和状态两张表**：外观表定义同一物件；状态表定义每段从何状态开始、何时转换、谁持有、数量及身体附着关系。刀身＋刀柄／护手属于同一把剑，空鞘是另一部件；拔出后腰部不能仍有第二个刀柄。后续段文字状态覆盖参考图入鞘初态，原鞘保持相对腰胯固定并随身体运动。持握用解剖学左右手，不能写正确的手或画面左。
3. **先修开场版本和拔出窗口**：原案明确授权S01和S02作为两个独立开场拔刀段，不能把两次拔刀自动判错；记录它们为蒙太奇重述而非线性状态连续。默认保留S02正文入鞘开场并修段前已持刀说明。S01以状态锚3.500–3.850为文本权威，将3.870事件改为拔出后的上提护势，不再称开始拔刀；真实音频到手再验证窗口。若新任务要求严格线性一次拔刀，则仅在授权段转换，后段全为已持刀。
4. **建立音乐事件及段落能量曲线**：每段时间使用global−source_start，验证窗口无空洞和重叠；将歌词点、拍点、动作起点和高潮完成点分别登记。原案139.5 BPM只能推拍间距，缺首拍与测量文件不能认证每个1.720／3.440本地事件是强拍。为各段分配建立、展开、内省、再推进、器乐高潮和终止等功能；段数和分组只做组织参数。
5. **把剑路写成完整身体过程**：每链交代蓄势、脚底压力、重心、髋躯干、肩肘腕到剑尖的路径、峰值、减速、恢复及下一护势。宽步、低位、前倾延展与旋身有支撑和回收，不在每拍机械挥剑。抽帧参考只迁移动态；对抬腿高度、翻滚和跳跃的限制按新任务确定。最后数十毫秒不新增整套转身或挥刀，给动作完成留实际时间。
6. **压缩为一个主运镜和一项辅助**：按本段要看清拔出、完整剑路、脚下支撑或眼神选择景别，然后写起始位置→连续路径→动作触发→终构图。若采用NO DEGREE LAW，修S01／02／05／09／14五处度数为真实空间关系，不把身体旋转次数误删。S17默认改为横向跟随为主、随低位到站立的小幅升降为辅，删除额外后退、环绕和前推；同步动作时间行。道具近景不能同时要求脸、双脚、整剑与远海全部清晰。
7. **分离段内镜头和后期桥接**：每段仅[Shot 1]，动作阶段用局部时间描述，摄像机变化必须可连续完成。分组不强制逐帧首尾姿势一致；为后期列出反光、发丝、湿沙、地平线或剑线的素材特征及运动方向，而非要求模型在段内执行匹配剪辑。S03／11等开场摘要写刀刃、正文却写鞘口的情况统一为一个真实对象；默认按实际正文鞘口反光更新摘要和镜头。末段是终止，删除机械套用下一段转场的模板句。
8. **归一音频与官方字段后进行双重审查**：选择完整原音轨fully_copy则删除新增海浪／脚步／剑声；若确需保留原曲并混入环境声则用partially_copy并说明新增声音，不能称完整最终轨未变。按官方Ref2VA六字段编译英语正文，用Subject分别绑定人物、道具和环境，只有真实关键帧才单独列Picture；summary使用官方任务类型。先查状态、时间、字段、运镜与场景，再查记忆点、段落差异和结尾完成感。作者勾选不作为生成通过记录。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **KZ01**：人物和场景的图像权限分别定义；固定现场与替换背景不能同时设为绝对权威。
- **KZ02**：道具外观由参考继承，数量、持有人、位置和当前状态由时间表决定；后续状态覆盖参考图初始入鞘状态。
- **KZ03**：原案S01和S02各自独立拔刀是已授权开场设计；应修S02前文／正文矛盾及S01两个拔出时间，而非擅自删除第二次。
- **KZ04**：保留真实源窗和相位，不为整齐重切小节；BPM给间隔而不自动给每段首拍或人声时点。
- **KZ05**：道具路径由脚步、重心、躯干及持握传递，峰值必须有制动和恢复；动作与镜头同时响应音乐。
- **KZ06**：采用本案摄影政策时，一个主运镜至多一个辅助；数字角度要改成位置与路径，且摘要、动作行、相机段同步。
- **KZ07**：每段一镜到底与后期匹配是不同阶段；两段一组不要求精确同帧续接，也不授权内部暗切。
- **KZ08**：场景连续指同一空间、海岸线与光源逻辑，不等于不同机位下海平线永远占同一屏幕坐标；同一反光桥接必须指同一可见对象。
- **KZ09**：fully_copy表示完整最终音轨复用；新增环境声时必须改用混合保留方案，原案sole track加底声的冲突不可保留。
- **KZ10**：六字段齐全、一个Shot标签和作者勾选只能证明文本结构；重编官方类型、Subject职责与英语正文后仍需另行验证媒体和生成。

## 输出与检查

- **参考与状态配置**：人物／场景权限、道具外观来源、数量、解剖学握持、鞘的身体附着、段级初态和转换窗口、开场重述许可。
- **音乐与段落设计表**：源起止、文件、局部时点与证据级别、视觉问题、动作链、能量位置、主运镜与辅助、可见信息优先级。
- **独立Ref2VA执行文本**：逐段完整六字段、英语正文、单Shot连续路径、当前状态覆盖参考初态、统一音频策略，不依赖全局说明或上段上下文。
- **后期桥接与双重审查记录**：反光／发丝／剑线等匹配候选，段内与后期边界；状态、时间、镜头、场景、声音和作品完成感的文本审计，另列生成待验证项。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
