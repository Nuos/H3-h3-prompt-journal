原始结果：[集合JSON](collection-validation.json)、[创建器/证据JSON](creator-and-evidence-validation.json)、[21项回归日志](plan-audit-regression.txt)、[三项试用及复现](forward-runs/README.md)。调研时官方参考实现自身的上游40项测试也通过，日志另存 [upstream-skills-ref-tests.txt](upstream-skills-ref-tests.txt)；这40项不计入本项目21项新回归测试。

### 离线任务的具体结果

1. **摄影纪律组件**：摄影机3.5秒到位，人物4秒起转，5秒在转身中匹配切到侧面；人物持续运动，响应时序与剪辑策略分开。严格静态检查返回0。组件模式没有生成正文，未声称组件文字获得自动语义认证。
2. **右入三造型展示**：每段按4秒/24FPS生成，保留0–3秒，三段合成9秒/30FPS；两处pose→右入跨步硬切，音乐在后期整轨连续。真实图片和音乐缺失，保留draft。宽松检查0错误/12警告；严格检查按预期返回1，报告13条尚未就绪事项，未伪造pass。
3. **触地换纹完整提示词**：8秒T2VA，三次接触变化对应四个状态；生成与编辑帧率分别换算，旧纹理保持至接触，切换后先展示再起抬，末段完整覆盖。严格正文/计划检查返回0。这项由主编执行，不标为独立盲测。

三项内容核对为主编阅读实际产物后的判断，具体标准和局限见 [editor-review.json](forward-runs/editor-review.json)。所有脚本均明确返回 `semantic_validation=not_performed` 与 `model_inference=not_performed`；人工填写的案例审核记录不被当作自动证明。

| 案例 | 本次处理 |
|---|---|

| 帆板MV | 分开人物图的身份职责与逐段首帧；重制音乐后重新对齐全局事件；纠正音乐mini-turnaround的转身误译。 |
| 三人环绕 | 区分弧线与360度、在场与可见、遮挡许可和相机连续；20秒严格单次需求不被多段拼接偷换。 |

| 摄影/舞蹈资料库 | 将提前、同步、滞后响应与剪辑规则分开，修正拍数、圈数、范本文本和超长生成预算。 |

本集合的格式基线为 Agent Skills `83021e2be457a9b6679148719c1f6074f0ad975e`，H3协议基线为 MiniMax-H3 `199b7d0e1fd95e7b3eafa8c15eca692534142427`；案例固定提交为 `91a33376e9ae84d0b9b3a2c1a7f6991d5b9e358e`。规范原件、来源清单和许可归属见 [官方规范基线](../_standards/README.md)。

`SKILL.md`及有效frontmatter是格式核心；scripts、references、assets、evals和agents/openai.yaml是此集合采用的可选工程组织。500行以内是官方建议及本项目采用的入口限制，不宣称这些额外目录是标准强制项。

未完成的范围包括：实际H3推理、原案媒体审阅、音频拍点测量、生成身份稳定率、镜头物理可行性、真实接缝质量和当前具体部署能力测试。本文不报告上述结果。106项场景未全量执行，也没有把一次案例成功报告等同于可泛化模型能力。
