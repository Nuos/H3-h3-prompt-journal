# 实际任务试用：触地换纹展示

## 任务

使用 h3-leg-lift-contact-cut-stocking-six-look，为一个新设计的成年虚构人物编排8秒服装展示：固定机位，只有袜纹在2、4、6秒的触地瞬间硬切，整片完全静音，最终编辑交付30 FPS。没有外部参考资产；可以使用纯文字生成。交付完整英文提示词、计划和检查记录，不生成视频。

## 执行与结果

本项由主编代理实际执行，属于知晓实现的完整工作流试用，**不作为独立盲测**。读取技能入口、案例方法、官方模式规则和计划字段说明后，创建 SEG01.txt 和 plan.json，并实际运行检查脚本。

采用一次8秒/24 FPS的T2VA请求，后期30 FPS交付，两者分开。三次转换有四个状态；拍摄机位固定，但有三次同视角外观硬切。零基帧边界为原生48/96/144与编辑60/120/180。后期转换应保持这些切点，不跨切点混合不同纹理；本次只规划，没有实际转换。

|---|---|---|---|---|
| E1 | 1.50 / 1.75s | 2s，素色→细条纹 | 2–2.5s | 3.5s |

左脚承担主要支撑，右脚只做小幅抬落；鞋、衣服、场景、光照和身份保持。没有输入素材，不登记虚假的图片、视频或音频引用。完全静音是任务明确要求，因此两个声音字段均为N/A。

`case_checks`中的pass表示本次已经审核提示词和计划是否写对；不表示成片的脚位、接触或硬切已经实现。生成后还需测实际接触帧、切换帧、保持长度、支撑脚漂移和纹理外的变化。原始静态结果见 audit-result.json。
