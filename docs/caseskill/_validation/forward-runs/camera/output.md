## 2. 本案例交付

### 2.1 规则选择

| 项目 | 采用方式 | 理由 |
|---|---|---|
| 摄影响应轴 | 移动段用 `anticipate_hit`；其余段用 `stable_observe` | 提前到位后观察持续动作 |
| 剪辑轴 | `phase_match_cut`，仅一次 | 用户明确要求转身中切到侧面 |
| 共享时钟 | 到位 3.500 秒，起转 4.000 秒 | 共享时间不等于同相启动 |
| 中途动作匹配 | 保持世界旋转方向、肩部相位、角速度、支撑脚与惯性 | 侧面首帧接续正面末帧的下一动作相位 |
| 历史规则例外 | 不继承 1.5–2 秒提前量、禁止动作中切换、最后定格、低角度和闪切 | 这些是历史案例条件，和本次明示要求不同 |
| 延迟观察模式 | 不适用 | 本任务要求提前到位 |

依据：[E1/E3/E6 与 PART2 的历史正文](https://github.com/Nuos/H3-h3-prompt-journal/blob/91a33376e9ae84d0b9b3a2c1a7f6991d5b9e358e/case-studies/2026-10-camera-movement-discipline-library/prompt.md)；[规则冲突与适用条件的案例复审](https://github.com/Nuos/H3-h3-prompt-journal/blob/91a33376e9ae84d0b9b3a2c1a7f6991d5b9e358e/docs/casereview/2026-10-camera-movement-discipline-library.md)。来源依据为技能内置快照；本次未联网。所有具体时间及几何数值除用户指定的 12 秒与 0.5 秒外，均为本次创作选择。

### 2.2 五字段摄影块

完整英文五字段块位于 `camera-component.en.txt`。下表为中文核对版：

| 时段 | CAMERA POSITION | CAMERA GEOMETRY | CAMERA MOVEMENT | MOVEMENT TRIGGER | END CAMERA POSITION |
|---|---|---|---|---|---|
| 0.000–2.000 | 正面 `(0,-6,1.2)m` | 水平、全身双人、朝中心 | `none` | `none` | 原位 |
| 2.000–3.500 | 正面 `(0,-6,1.2)m` | 保持轴线、高度和镜头，物理后撤拉宽 | 沿负 Y 轴直线后移一次 | 2.000 秒，共享时钟；发生在持续准备动作中 | 3.500 秒到 `(0,-8,1.2)m` 并完全停稳 |
| 3.500–5.000 | 正面目的机位 | 水平、全身双人 | `none` | `none` | 原位直到切换 |
| 5.000–12.000 | 侧面预置机位 `(+8,0,1.2)m` | 沿负 X 轴观察中心；全身双人 | `none` | `none` | 原位直到结束 |

坐标约定：X 为左右、Y 为前后、Z 为高度。双人转动中心采用 `(-0.9,-1.0)m` 与 `(+0.9,+1.0)m` 的对角错位，减少切至侧面后的互相遮挡。上述几何为可执行的编排假设，不是实测场地。侧面机位预先存在，5 秒发生的是剪辑切换。

### 2.3 中文共享时序

| 时间 | 双人动作 | 摄影状态 | 剪辑 |
|---|---|---|---|
| 0.000–2.000 秒 | 开场即在运动中，保持双人舞句 | 正面固定 | 无 |
| 2.000–3.500 秒 | 持续步法与重心转移，为转身作准备 | 一次平顺直线后移，3.500 秒完全停稳 | 无 |
| 3.500–4.000 秒 | 准备动作继续，不能停成造型 | 已在目的机位，固定观察 | 无 |
| 4.000–5.000 秒 | 4.000 秒开始连续转身 | 正面固定 | 无 |
| 5.000 秒 | 两人仍处在转身途中 | 切至已预置的侧面视角 | **唯一一次动作／旋转相位匹配切换** |
| 5.000–6.000 秒 | 接续同一次转身，无重复、跳相或反转 | 侧面固定 | 无 |
| 6.000–12.000 秒 | 从转身直接释放到下一舞句，末帧仍在运动 | 侧面固定 | 无 |

**提前量：** `3.500 - 4.000 = -0.500 秒`，因此摄影机先到，转身后开始。以 24 fps 规划，3.500 秒对应帧 84，4.000 秒对应帧 96，间隔 12 帧；5.000 秒对应侧面首帧 120，正面末帧为 119。帧号从 0 开始，仅作为规划索引，并非生成结果的测量值。

切换的连续性以同一个世界空间动作核对。换到侧面后，画面投影方向可以变化，但人物实际旋转不能为模仿先前屏幕方向而反转。侧面首帧接正面末帧之后的动作相位，不复用末帧、不重启转身、不用停顿掩盖切点。固定的是摄影机，人物从始至终持续运动。
