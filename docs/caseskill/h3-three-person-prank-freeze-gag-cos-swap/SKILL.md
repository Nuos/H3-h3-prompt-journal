# 三人画外干扰、定格笑点与仅换皮复现

先还原谁先做了什么、使谁的动作改变，再冻结时间与因果结构进行外观迁移；明确区分演员动作、第一人称摄影、后期定格和三类声音，修复原案时长、帧数、字段数量及道具清单的含混。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **任务模式与素材角色**：声明逆向分析、沿用已确认机制的skin-only换皮，或允许重排节拍的新改编。原视频若仅用于观察，登记analysis_only；最终T2VA不绑定参考图。若用户要求图像身份绑定，重新依据官方H3模式选择，不沿用纯T2VA标签。没有媒体时标missing，使用案例文本仅能构造待核验方案。
- **可检查的画面与音频**：记录片长、原始帧率、可定位的画面和声轨；提交有歧义的时间窗、竞争剧情解释及支持帧。音频峰值是候选事件，不以三次响声自动推算BPM；无素材时不复述作者量测为本次观测。
- **主体、道具与功能依赖**：分别登记可见A、可见B、画外持机者的身份与操作权限，追踪杯、瓶、头盔面罩的所有者及开闭状态。确认B早期小瓶与后期蓝瓶是否同一件；无证据时保留待确认，不让道具凭空替换。
- **外观替换合同**：列出替换前后脸发、衣料、配色，以及动作接触的服装词；保持功能性翻转面罩等因果道具兼容。列出禁止改动的角色关系、事件次序、时间、机位、定格和声音。
- **输出时间与编辑约定**：明确duration指生成基片还是含定格的成片，规定所有时间戳使用哪条时间线、原生24FPS与剪辑帧率、定格采用追加还是替代帧。官方标准单次生成4–15秒；15.3秒源案不能直接当作单次标准生成能力。

## 执行流程

1. **限定证据与改编边界**：把本次素材分成分析材料与H3实际输入，标出missing、observed、user-specified和inferred。若仅换皮，先冻结已有经确认的因果／时间／声音基线；若时长、人数或节拍要改，另立改编版本，避免把重排伪称skin-only。
2. **建立竞争解释并追踪画外第三人**：先用稀疏浏览提出至少两个能解释关键水花或反应的候选原因，再只在决定性伸手、接触、改向窗口增加抽帧，短动作必要时逐帧。把绿色袖子、手和车头作为待关联线索；核实其连贯性后登记持机者既拍摄又干扰，不能因未露脸删除行动者，也不能仅凭同色就证明同一身份。
3. **锁定动作与道具的因果状态机**：每轮写准备→干扰者先伸手→可见接触→受力者改向／停止→结果→反应。源案面罩初始UP，第一轮由第三人压到DOWN，A在7.2秒自行开启，第二轮持续UP且仅头盔侧面受力；不可把关面罩、转头和喷水写成同时无因果的动作堆。记录被打湿的部位累积变化与杯瓶归属。
4. **分别编排表演、摄影、编辑和声音**：演员动作保持自然连续，摄影只按持机者俯拍倒水和伸手干扰的动机发生小幅抖动；不把定格误作现场全员暂停。每个笑点单列capture／入点、持续帧数、白闪或微放大叠层、恢复源帧。声音分现场声、后期SFX、音乐：无配乐可与三个定格音效共存。
5. **对账总时长与整帧边界**：先选输出时间线或基片时间线并全表统一。逐个换算定格窗口、对白、动作先后及结束点；源文末15.3秒超出名义15秒，首定格6.2→6.8为0.6秒而非统一0.5秒，24FPS还需帧取整。给出保留原节奏的后期方案或明确改编后的≤15秒方案；不悄悄压缩时间后继续声称仅换皮。
6. **在功能兼容后做外观迁移**：只重写主体外观、衣料湿润响应、头发惯性和动作直接触及的服装名词，保留原道具功能。新造型缺翻转面罩时先标合同冲突；若仍需源第一轮笑点，使用用户允许的兼容头盔，否则声明改写机制。角色联想产生的实验器材、警械等不自动加入。输出逐项before→after→连带物理变化差异表。
7. **组织H3正文与验收清单**：按官方当前模式组织主体／环境／动作／摄影／声音正文，将复杂证据和剪辑表置于独立交付附件；原案实际12个顶层字段只作为案例组织方式，不能宣称14个或H3强制字段。生成前检查主体数、道具状态、力先于反应和时轴；生成后依据实际成片逐帧核对画外手归属、三次冻结、恢复连续性及声画对应，未运行时只报告计划审校。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **R1**：画外持机者是本案第三个行动者；摄影视点不意味着中立观察。手、袖子、道具只在有连续证据时归并到同一主体，身份推断保留置信与缺证。
- **R2**：每个喜剧结果必须有可见准备、干扰者先行动、接触及受力改变；源案面罩UP→第三人关DOWN→A自己开UP→第二轮保持UP的顺序不可在skin-only中改变。
- **R3**：三次定格属于后期画面保持；用入点／持续帧数／叠层／恢复方式四项定义，演员表演层不写成所有人自行停住。三次和半秒是本案例选择，不是H3普遍要求。
- **R4**：明确时间戳是否包含定格，并使总时长、帧率、定格区间可对账。原15.3秒与首0.6秒冲突必须记录；官方标准生成能力和后期延长成片分开描述。
- **R5**：仅换皮冻结行动者、因果、时点、摄影、定格和声音，只允许外观与其接触到的材料响应变化；功能性道具被删除或时间被移动即转为机制改编。
- **R6**：现场声、后期SFX、配乐分列；没有音乐不等于全轨静音。RMS峰值或响声不能单独证明节拍、BPM或因果，未获取音轨不报告实测结果。
- **R7**：所有杯瓶有稳定身份与拥有者；湿发、衣料、面罩水膜随事件累积，不因定格恢复或换皮重置。B的小瓶与蓝瓶描述差异应核实或显式裁决，不能暗中增删道具。
- **R8**：分析来源与生成参考分离；本案T2VA无图输入，原视频逆向分析不自动变成Ref2VA。实际12字段和外部配套skill链接不构成额外官方强制规范或已验证实现。

## 输出与检查

- **证据与因果表**：逐事件记录时间窗、观察到的画面／声音、竞争解释、最终选择及置信，主体操作权限、接触、结果和缺失素材分列。
- **道具与身体状态账本**：每轮开始／结束的面罩开闭、杯瓶持有、头部朝向、湿润部位和画外手入口；每个改变附可见动作或明确待确认。
- **H3正文与后期时间表**：符合当前输入模式的可用提示词，以及生成基片时长、成片时长、fps、freeze四元组、对白／现场声／SFX／音乐分层；工程计划不得冒充实测。
- **仅换皮差异表与审校报告**：记录允许变化、保持字段、连带物理变化及合同破坏项；分别报告生成前计划审校和生成后待验证，不把相似结果证明为唯一源剧情。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
