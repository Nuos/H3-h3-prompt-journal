## 方法来源与适用范围

将机位名称展开为相互兼容的空间条件与可检查画面结果，解决整段复制模板导致的高度、滚转、静止与跟拍冲突。

本方法由原案例文本、逐案评估和 H3 官方协议共同整理。原案经验、评估发现与本次补齐的数据/检查接口须分别表述；案例作者的成功报告不等于本次实测。原稿快照保留原貌，冲突由本文件及技能入口裁决。

- A0加A1–A25共26条正文条目；25不是25个互斥机位类别。
- 本技能将S1素材工程化为机位子技能；完整分镜、编舞和音频仍由调用方提供，不夸称成套视频制作。
- NO DEGREE、禁止怼脸和全身入画按当前项目要求启用，不随库全局强制。
- 未执行H3渲染，几何可检查性提高属于设计目标，成功率提升未被验证。

## 条件分支与冲突处理

| 条件 | 执行动作 | 案例/评估依据 |
|---|---|---|
| 用户要求贴地荷兰角 | 取A5的地面高度和仰向光轴，叠加A19的共同滚转，删除A19自然人类高度。 | prompt.md:159-195,579-603；review:29 |
| 要求正上方且正面平视脸部 | 指出同一时刻几何不兼容，按主要意图选择真顶视或斜上方；若用户要两者则规划不同镜头。 | prompt.md:291-357 |
| 要求站定侧面加后方连续跟拍 | 拆为不同阶段或选择一种运动模式，并明确机位到新方位的路径/切镜。 | prompt.md:361-385,517-543 |
| 无测量数据 | 使用明确标注的设计假设或相对人体高度，不声称厘米数、距离和角度经过实测。 | review:27,35 |

| 失败表现 | 修复步骤 | 依据 |

## 迁移示例

**任务**

为8秒全身舞蹈写机位：前4秒贴地低角度并有荷兰角，后4秒人物向镜头走一步；禁止数值角度，肩颈必须入画。

**预期处理示例**

设计为同一镜头：镜头位于地面上方约一掌高度、主体左前方，保持足够距离容纳头、肩颈与双脚；光轴斜向上，全环境随相机绕光轴的轻微固定滚转形成共同倾斜。0–4秒相机位置与滚转保持不变；4–8秒主体沿已给路径前进一步，相机不变焦，主体与近端手臂因真实距离缩短而增大，背景相对关系连续。删除A19的人类高度默认值；不填写角度数字。若前进一步会裁掉头脚，先增大设计距离或缩小步幅，并把这一假设交给主编排器。输出画面须检验头肩颈/双脚可见、地面近前景和共同倾斜；未生成时这些仍是目标。

示例是编排示范；其中任务给定参数和演算不代表当前已经读取了对应媒体，也不代表一次 H3 推理已完成。完整生成端交付仍需按输出模板选择正确字段和真实素材绑定。
