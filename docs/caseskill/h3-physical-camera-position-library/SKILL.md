# 物理摄影机机位：八要素编排与兼容检查

将机位名称展开为相互兼容的空间条件与可检查画面结果，解决整段复制模板导致的高度、滚转、静止与跟拍冲突。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **拍摄对象与空间**：提供主体、场景地面/墙面/障碍、运动轨迹和可用机位空间；区分实际已知与假设。
- **机位意图与画幅**：记录观众应看见的身体部位、环境关系、景别与画幅，再选机位，不仅收集形容词。
- **时间与运动策略**：给每个机位持续区间及主体移动；明确相机锁定、跟随、平移、俯仰、滚转或组合。
- **项目约束**：记录是否禁数值角度、是否要求保留肩颈/全身、是否允许贴近透视及设备入镜；未指定时不强加其他案例政策。

## 执行流程

1. **把机位词改写成画面目标**：先明确需要看到什么空间关系，如地面近前景、人物向上延伸，或地面成为主平面。把 low angle 等词保留为检索词，不用它代替几何。
2. **拆开正交控制字段**：分别填写方位、高度、距离、光轴、滚转、相机平移/静止、主体路径、可见部位。A1–A18为位置/距离/跟随混合条目，A19–A21为朝向操作，A22–A25为响应与组装规则；不称为25个互斥机位。
3. **按目的选取最少模板**：从源库选一项基础位置，再选必要的滚转、俯仰或运动响应。贴地与正上方互斥；荷兰角可叠加不同高度，但应删除原A19的人类高度默认值。
4. **求解兼容与物理路径**：检查一镜同一时刻只有一组高度/距离/光轴，静止与跟拍不同时成立；若要变化就写时间、连续路径和终点。区分真实靠近与变焦、固定位置俯仰与升降、真实后方视点与主体转身。
5. **生成八要素镜头定义**：依次写位置、高度、距离、光轴、主体空间关系、预期可见结果、移动响应、机位锁定。未给出的尺寸明确作为假设或使用相对身体/地标尺度，避免伪装成量测。
6. **嵌入当前模式时间线**：把自然英文机位句嵌入目标镜头，与动作共用同一时间区间；基础模式放在integrated_multimodal_description，Ref2VA放在detailed_description。库的camera_system和八项小标题是设计表，不强行增加官方字段。
7. **生成可检验的构图验收点**：列可见地面比例、头肩顶部是否应可见、全景地平线共同滚转、主体与背景透视是否一致，以及器材是否可见。只把这些作为检验目标；实际输出未查看时不宣称通过。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **CP-01**：每镜明确机位的八要素，不把25条模板全部堆入同一提示词。
- **CP-02**：位置高度、镜头方向和绕光轴滚转分别建模；荷兰角不等于低机位或高机位。
- **CP-03**：正上方应同时满足相机在主体正上方、光轴垂直地面；斜上方保留面部可见度是另一方案。
- **CP-04**：贴地、后跟、手持等描述保留其真实空间与运动关系，不用裁切、身体伸缩或独立旋转主体伪造透视。
- **CP-05**：静止相机与持续跟拍不能在同一时段无说明并存；组合必须明确阶段及转换路径。
- **CP-06**：仅在项目明确启用NO DEGREE时，将角度数字改成相对空间几何，保持垂直/斜向/侧前后关系；库本身含数值角度。
- **CP-07**：对原库的模型效果保证改写为验收目标；当前材料无对照数据证明物理描述必然胜过短角度标签。
- **CP-08**：设备隐藏是该子技能的默认设计要求；若任务明确拍摄剧组设备，按任务重设，而不是把摄影机物理描述误生成为画内摄影机。

## 输出与检查

- **机位参数与兼容表**：逐镜方位、高度、距离、光轴、滚转、移动模式、主体路径、可见部位及假设来源。
- **八要素机位描述**：可以嵌入当前H3主字段的自然英文句子，与实际时间区间绑定。
- **构图验收与修复建议**：预测可见几何、可能误解、冲突消解及待生成验证项目；不把文本检查当画面成功。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
