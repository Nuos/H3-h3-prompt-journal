# H3 右入单状态展示与硬切装配

把状态目录、独立生成任务和音频对位编辑分开，保留源案例经反推修订后的真实结构，并让首帧状态、切点两侧内容和可变属性成为可检查契约。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **固定视觉锚**：给出人物参考、场景来源、固定主服装与配饰、正面全身机位。参考图权限明确排除当前状态允许变化的鞋袜属性，未提供场景不自动继承源厨房。
- **有序状态目录**：每状态定义袜饰的材质/花纹/高度等实际差异，状态数决定片段数；无文字版不生成源编号和横幅。
- **音频与编辑时窗**：提供目标音轨、总时长、已核验切点或明确的计划边界、输出fps与文字开关；原2.267/4.233是该案例文字记录，不是新音频测量值。
- **生成能力**：提供实际H3最小/最大时长、帧数规则及是否允许生成余量后裁切。源1.667–2.267秒不自动代表当前部署能够原样调用。

## 执行流程

1. **确认源片机制与证据等级**：若有源视频，先检查候选切点前后逐帧状态，区分同机位硬切与画内换装。检测阈值只产出候选；0.08/0.27是原案例经验。没有视频/日志时只使用最终正文结构，并将源4.4秒候选的去留原因记未记录。
2. **建立固定项和状态例外**：把身份、主服装、场景、机位与当前袜饰变量分开。对每状态只定义差异，不把参考图“所有衣服永不变化”的绝对措辞和袜饰变更同时写入。
3. **按状态生成独立任务**：一个状态对应一个独立生成片段，首帧已处于该服饰状态和画右跨步入画过程中；只安排一次大跨步、落定软膝缓冲、短pose动作和终帧保持。单段不包含上个状态残影、退出画面或空帧等待。
4. **计算局部/全局时间与可用时长**：由编辑边界计算每镜局部时长和全局偏移，核对总和。若部署不能直接生成短片段，给出较长生成时长和明确可用裁切窗，仍保持成片首帧处于跨步、末帧在pose，不通过无说明变速凑时长。
5. **定义可见跳切的两侧状态**：以最终prompt为权威采用上一镜pose保持→下一镜新look跨步开场；不要继承README“切点两侧都在迈步中”的冲突句。跳切是设计效果，无需伪造人物左出/空场/右入的无缝机制。
6. **生成完整逐镜提示词和编辑表**：每镜携带单图锚、单人、已在跨步中的开场、当前状态差异、pose phrase、固定全身机位六锚。输出独立正文及编辑决策表；原音轨整条后期铺底，去除片段生成的重复音轨，文字仅在用户要求时按状态切换。
7. **验收片段与装配**：片段检查首帧新状态、一个人物、右入、无走出、固定景别和末帧pose；装配检查硬切边界、总帧数、原音轨来源和状态顺序。没有实际生成/剪辑文件时标为规划验收，不能因fully_copy文字就宣称波形已保真。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **SRE01**：每个状态独立生成，首帧已经是该状态并处于画右跨步中；单段不描述画内换装。
- **SRE02**：终帧保留pose，下一镜从跨步进入；两侧不是同一动作无缝续接。
- **SRE03**：只改变状态目录指定的袜饰属性，其余身份、主服装、场景和机位保持；图像权威保留明确例外。
- **SRE04**：不添加走出清屏、空帧或另一人物来解释状态变化，硬切本身负责重置片段。
- **SRE05**：生成片段与后期整轨音频装配分工明确；fully_copy提示文字不替代真实音频复用。
- **SRE06**：切点检测阈值及4.4秒候选只属于源分析记录；没有逐帧证据不能断言它是误报或无关。
- **SRE07**：实际调用前核验短时长/帧数支持，可用生成余量和裁切实现目标，但不虚构调用能力。
- **SRE08**：一镜一状态、右侧入画和无文字是本展示策略的默认，不作为全部H3任务的统一限制。

## 输出与检查

- **状态与不变量清单**：每状态唯一变化、固定视觉项、参考权限例外、文字开关。
- **逐镜独立提示词**：当前状态从首帧生效、右入跨步、落定pose、单人、固定全身机位和片段尾态六锚。
- **编辑决策表**：镜头ID、状态ID、全局区间、局部时长、实际生成长度、可用裁切窗、硬切两侧动作、音频窗口、fps/帧号。
- **片段与成片验收表**：首帧状态、人物数、入画方向、终帧pose、构图、切点、总长、原轨复用及尚未核验的候选点。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
