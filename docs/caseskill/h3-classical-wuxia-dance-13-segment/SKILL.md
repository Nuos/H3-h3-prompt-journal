# 音乐事件驱动的古典武侠舞分段编排

将十三段提示词和二十条方法论转成从音乐事件、动作母题到镜头及交付审计的流程，使每段独立生成仍能保持作品结构与资产状态。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **作品定义**：记录舞种、情绪能量曲线、每段功能、主要动作与观众必须看到的信息；选择独立蒙太奇、连续动作匹配剪辑或分组一镜到底。
- **视觉与道具参考**：登记图像对身份、服装、场景、灯光、姿势的授权范围，以及现有武器／道具的数量、佩戴或持握方式、相对身体位置与可变状态。
- **音乐与分段清单**：提供源起止、音频文件标识、实际段长、BPM与首拍或拍点表、人声事件和器乐间隙；标出实测、用户给定、从BPM推算和未知。
- **动作预算**：给定风格、动作能力边界、旋转／跳跃／地面段预算、主母题和高潮位置；动作密度由音乐及完整准备恢复时间决定。

## 执行流程

1. **先确定作品与剪辑契约**：先写五项：舞种、情绪位置、主动作、可见信息、段落功能，再选剪辑模式。原案是段内有动机蒙太奇；如果需要跨段身体连续，额外建立配对状态，不能由同一音频自动推得连续物理镜头。把段数和局部特写开场设为可调参数。
2. **建立参考与武器状态表**：图像只管已授权属性，动作由新编排决定。无武器时写清空手动作，不反复堆不存在武器的名称；佩戴入鞘武器保持附着身体的局部位置和入鞘状态，不能把世界坐标不动误作锁定；持握武器则保留握持手与接触，调整相冲突的开掌或双手动作。歌词中的刀剑、宫殿、同伴不自动授权实体或新场景。
3. **将所有时间组织为同一事件表**：读取源窗与段文件，段长=end−start，动作统一使用local=global−segment_start；检查无重叠、无空洞、文件与窗口匹配。分别保存beat、vocal_start、vocal_end、phrase、cut和phase，不把它们合并。原案manifest缺席时只核验文本表，不宣称真实音频已对齐。标称0.663秒用60/90.5精算；原OFFBEAT间隔整拍，不擅自解释为八分反拍，应保留source_tag并标明拍号／强弱语义待证。
4. **发展可以识别的动作母题**：建立一个有具体路径的主母题，如前臂收拢→对角线展开；在开场、发展、低谷、回归中改变幅度、质地、方向、部位或先后次序。每段安排持续层、主要动链层、微动作层，持续层并不意味着每个部位永远移动。密度参考仅作为起点，先为准备、发起、扩张、峰值、惯性和恢复留足时间。
5. **从动力链编排到音乐事件**：每链记录受力来源、支撑脚、重心、轴线、腿胯躯干肩臂腕指传递、眼神到达及回收；手势不能代替脚下承重。标注动作是提前准备、在拍点完成，还是随人声起点启动。修原案S05时保留6.044作为DOWNBEAT触发并注明在6.950人声前展开；9.000为上一人声结束后的桥接，9.633才是下一句起点，删除At the next/final vocal phrase的误称。零到首句、句间空白和无词尾奏均有具体运动。
6. **让每个镜头揭示身体信息**：删去镜头句后先确认舞蹈成立，再为一镜选择主要运动、真实机位、轴向、距离和可见关节。脚部特写揭示支撑，肩后镜头解释躯干传递，面部近景承接眼神到达。原案S03脚部开场必须延续同一重心到肩后切镜，不能切后重摆。区分真实cut与镜头内阶段；若使用本案无数字角度风格，就用物理关系完整替代，而不是只删除角度。
7. **编写接缝和器乐结尾**：连续模式逐边界记录左右支撑、脚位、朝向、重心、手臂路径、速度、道具状态与景别；独立蒙太奇模式明确允许何种重新构图。原案S01高斜线末态到S02眼脸开场没有完整配对，默认补同一身体姿态下的眼脸特写，不自动重置。末段按器乐重音继续发展母题，尾部安排减速与收束到真实音频尾；若需要尾前静止，为其明确起止，不与必须持续动作混写。
8. **编译独立提示词并审计**：每段输出Ref2VA六字段，定义视觉Subject和Audio职责，音频完整复用用audio reuse／fully_copy，所有切镜在detailed_description按官方Shot语法表示。删去原稿重复词与无法执行的泛化句。审计时间越界、事件引用、无词段动作、武器状态、母题回收、cut目的和跨段配对；输出文本已核查与音频／生成待验证两种状态。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **WX01**：作品意图、音乐和编舞先于镜头；删除相机文字后动作仍应成立。
- **WX02**：动作链包含准备、受力、展开、重音峰值、惯性和恢复；持续层不是所有身体部位始终移动。
- **WX03**：母题通过质地、方向、幅度和先后变化贯穿作品；动作密度和技术预算不采用固定数量公式。
- **WX04**：源窗口与局部时间分开，拍点／人声起止／剪辑点分别建事件，缺manifest不等于有实测精度。
- **WX05**：S05的6.044和9.000不能标作6.950和9.633人声的入句时刻；允许提前动作，但应说明提前与对应事件。
- **WX06**：图像权威随项目授权；歌词意象不增添物体，武器状态锁定要区分无武器、佩戴入鞘和实际持握。
- **WX07**：摄影机说明真实位置与路径；每次切镜或移动必须提供支撑、线条、方向或音乐结构的新信息。
- **WX08**：音乐首尾相连与身体接缝是两项检查；跨段连续必须有状态表，蒙太奇跳接必须明确许可。
- **WX09**：无歌词、间奏和尾奏仍编排动作；最终收束以实际音频尾为目标，不把缺歌词当成静止指令。
- **WX10**：成品时间戳只代表编排意图；按官方Ref2VA字段归一后，文本检查、音频核验和生成回归分别报告。

## 输出与检查

- **作品与参考契约**：舞种与能量曲线、剪辑模式、图像授权、武器分支及保持范围、音频最终使用策略。
- **统一音乐事件表**：源文件、源起止、段长、局部拍点／人声起止／器乐窗／cut，来源及精度标签，提前动作与入句动作的对应关系。
- **动作与接缝计划**：母题发展、每链动力过程、可见技术信息、镜头目的，以及连续边界的身体／道具／构图匹配表。
- **逐段Ref2VA提示词与审计**：各自完整的官方六字段执行文本，末段器乐收束，已修复的文本冲突、仍缺媒体证据和待运行回归项。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
