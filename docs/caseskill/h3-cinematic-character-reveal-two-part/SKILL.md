# 双段角色揭示：姿态索引、接缝资产与连续母带

把两条各自完整的提示词连接为有实际交接数据和统一声音策略的角色片，保留原案的近景姿态蒙太奇，同时修正镜头计数、去重和音频继承中的含混。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **同一角色的分工参考**：登记姿态/身体/服装/场景来源与唯一脸部来源；多张图服务同一个角色，不合并成新人。补充姿态图不得自动接管人脸。
- **可定位的批准姿态库**：为实际可见姿态建立ID、文件/图内区域、主要几何、允许微动和已使用方式；参考未给时不能虚构Pose 01–11映射。
- **时长与剪辑表**：记录全片时长、生成切片、时间块、块内真实切镜及最低可读时间；案例30秒是两次15秒生成，不是一次标准长请求。
- **声音素材与传递能力**：明确使用真实连续母带还是重新生成音乐，登记母带全局位置、合法分段参考、环境声底层、运行时能否接收末帧/关键帧/参考音轨。
- **允许回调与禁止重复**：定义去重对象是同一姿态、同一构图还是同一转场机制，并明确是否允许同姿态换裁切/视角的视觉回调。

## 执行流程

1. **建立参考权限和姿态索引**：把脸部、身体/服装、场景、姿态和运动样例分开登记。一个角色可由多个来源共同定义；角色脸部只取用户指定来源，批准姿态逐项定位到图内区域，姿态数量不足时不能自动补出Pose 10/11。
2. **规划两段不同叙事职责**：第一段完成眼部/脸部引入和主要姿态介绍，末尾保留可接续暂停态；第二段从该态继续，升级细节/姿态蒙太奇后收束主视觉。角色、教堂和配色是原案配置，可按用户任务替换；约20秒的创作经验不作模型长度规则。
3. **展开时间块为实际镜头**：先保留每段13个CUT块的源结构，再将CUT内的多次硬切逐一展开为Shot和起止。Part 1 CUT 08/10、Part 2 CUT 05/08/11尤其需要内部表；镜头编号按实际切镜连续递增。把连续推进/拉焦与切镜分开，不一律按视觉阶段切镜。
4. **用真实音频建立节拍与帧预算**：只有取得母带/可靠拍表后才写实测BPM或拍点；先列秒数的版本属于时间设计。给五拍高潮和多片段快切选择实际拍/细分拍并计算可用帧数；帧网格量化后复核全片覆盖，负荷不足时减少切镜或延长窗口。
5. **把接缝契约变成实际交接包**：共同设计第一段最后1.4秒与第二段开头0.9秒，记录姿态、视线、相机位置/朝向/景别、光照、环境和衣料余势。取得第一段实际末帧及必要末段后再绑定第二段的开场锚点；运行时不支持该传递时明确能力缺口，提供另选模式/后期接缝方案，不称文本继承为精确视觉继承。
6. **落实一条母带与声场连续**：优先使用一条全片母带在编辑时间线上连续播放，生成需要的音频参考按每次合法时长分段，第二段从全局15秒而非0秒开始。环境声底层和跨边界混响另写策略。选择完整最终音轨复用或保留音乐后混音，不能fully_copy后又要求生成额外声效。
7. **审计镜头复用和图像层变换**：用姿态ID、景别、方向、背景构图、转场机制逐镜比较。允许的回调写明变化维度；原Part 1 CUT 05与Part 2 CUT 07都用建筑遮挡，应替换后者为本次清单未用机制，或明确允许受控回调。图形匹配、频闪回声与裁切作用于摄影图像，不将人体变形或复制成新角色。
8. **输出两端对应的官方提示词**：按实际输入选Ref2VA六字段或适用的基础模式；两段各自包含完整参考职责、视觉状态和声音策略。第二段有真实首帧锚点才给独立Picture定义；全片母带不是任意长度H3输入。交付时间表、交接包状态、去重结论与未实测范围，实际生成后再验证身份和接缝。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **CR-01**：脸部唯一来源与身体/服装/姿态/场景来源分别绑定到同一角色；补充姿态不得混入新脸或新增人物。
- **CR-02**：所有主要姿态必须能在真实参考中定位；Pose 01–11是原稿标签，不是已经建立的图内索引。允许微动不等于允许发明主要姿态。
- **CR-03**：每段13 CUT是时间块数量，包含多次分切的块须展开，不能直接报告恰好13个实际镜头或全片26镜头。
- **CR-04**：跨生成精确接续需要实际末帧/状态和运行时支持；两张原始定妆图及双端重述不足以证明上一片段状态已传入。
- **CR-05**：连续BGM和环境声有全局偏移与编辑/复用方案；第二段不从音轨0秒重启，完整音轨复制与新增声效不得冲突。
- **CR-06**：无BPM/拍表时不能把秒数表称为已验证卡点；五拍高潮和块内快切需明确实际拍点、细分拍及帧预算。
- **CR-07**：镜头去重按具体机制和构图审计，允许回调需声明变化维度；两段建筑遮挡实际相似，不能照抄完全不重复的结果断言。
- **CR-08**：图形剪辑改变摄影图像关系，不能变形角色身体；近景优先保留身份和服装细节，稳定姿态允许任务指定的眼睛/衣料微动。
- **CR-09**：30秒原案按两个15秒生成切片规划；引入/升级/收束为创作结构，约20秒、纯器乐或特定教堂风格都不是H3通用能力限制。

## 输出与检查

- **参考权限与姿态索引**：每个输入的实际用途、角色唯一脸部来源、批准姿态ID与图内位置、各段已用/待重点展示状态。
- **展开后的真实镜头表**：创作块ID与实际Shot映射、全局/局部起止、帧预算、视觉事件与音乐证据、姿态/景别/机制。
- **双端交接包**：第一段出态、第二段入态、末帧/末段资产、相机/光照/衣料余势、音频偏移、环境声底层与运行时可用性。
- **两段H3正文与去重报告**：各段独立完整字段、真实参考绑定，逐镜去重/回调例外、静态检查和待生成验证范围。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
