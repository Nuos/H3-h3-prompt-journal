## 方法来源与适用范围

把两条各自完整的提示词连接为有实际交接数据和统一声音策略的角色片，保留原案的近景姿态蒙太奇，同时修正镜头计数、去重和音频继承中的含混。

本方法由原案例文本、逐案评估和 H3 官方协议共同整理。原案经验、评估发现与本次补齐的数据/检查接口须分别表述；案例作者的成功报告不等于本次实测。原稿快照保留原貌，冲突由本文件及技能入口裁决。

- README的six shot mechanisms实际列出七项；改用逐项清单，不将原数字当有效统计。
- 原Part 1用了Pose 01–09，Part 2又用Pose 10/11，而README举9–10姿态能撑30秒只是经验举例；实际任务从真实资产索引出发，不强迫不存在的编号。
- 原结构没有官方字段，封装时保持其叙事和摄影方法，重新按真实输入采用三字段或六字段；不将REFERENCE/VISUAL LANGUAGE大写章节直接充作Ref2VA接口。
- two-part并非所有长视频唯一结构；本技能在案例方法内提供可迁移交接流程，未测试生成稳定性。
- three-quarter不固定等于45°–60°；sttained glass按stained glass理解；Index/British Puritan保留为源风格线索，不自行补成已确认的作品或历史分类。
- 本次新增姿态定位、真实Shot表、帧预算、实际传参和母带编辑接口，解决原案与评估指出的操作缺口，不冒称原作者已实现。

## 失败表现与修复

| 失败表现 | 修复步骤 | 依据 |
|---|---|---|
| 第二段重新露眼睛开场、环境和配乐都重置 | 从交接包重建入口，真实传入允许的末帧/参考片段；剪辑统一母带和环境层，不只追加“continue”一句。 | README.md:26-48；review:40 |
| 宣称26镜头，但块内还有十多个短切 | 展开实际切点并重新编号，检查切点递增且覆盖15秒；把原CUT编号作为创作块索引保留。 | review:30 |
| 第二段说不重复却再次穿柱遮挡揭示 | 登记重复机制并更换为本片未用形式，或明确回调允许项，不将名称architectural cut的改变当机制改变。 | prompt.md:116-117,442-449 |
| 无Pose 10/11真实对应却自动编出人体姿态 | 只从已定位姿态库选用，以新取景重访既有姿态；缺资产则留待补齐。 | review:28,42 |
| 五拍被塞进1.3秒但音乐没有对应节拍 | 核对音频拍点与帧预算，改为已证实细分拍或降低事件密度；不要凭源标签替代音频证据。 | prompt.md:486-497；review:42 |
| 姿态匹配变成扭曲、暂停态变成死帧 | 将匹配限定到剪辑/图像层，将姿态稳定与眼睛衣料残余运动分别定时。 | prompt.md:86-96,140-149,535-550 |

## 迁移示例

**任务**

用同一角色的8个批准姿态和一张脸部图做30秒两段揭示，第二段接末态，BGM贯穿；不要发明姿态，不要宣称已听过尚未上传的音乐。

**预期处理示例**

先把8姿态登记为P01–P08，脸部图只绑定同一Subject的面部身份；不创建P09–P11。分两次15秒/24FPS生成，第一段重点使用P01–P05，末1.4秒以P05稳定但保留衣料余势；第二段最初0.9秒接续该态，再展示P06–P08，并在新的景别/方向中回调已批准姿态。真实首段末帧尚未获得，因此第二段开场锚点保持待取得，不伪称已传入。13个源CUT只作设计块，内部快切逐一展开为实际Shot并按全局偏移15秒换算。当前音乐拍点未提供，只交暂定秒数表和待填拍表；最终用一条30秒母带从0到30秒连续播放，送H3的参考如需要则按0–15与15–30裁成合法片段。逐镜去重标明P1建筑遮挡与P2同类方案重复，重编后者或记录允许的回调。生成后的脸部一致性、真实切点和无缝程度仍待媒体验收。

示例是编排示范；其中任务给定参数和演算不代表当前已经读取了对应媒体，也不代表一次 H3 推理已完成。完整生成端交付仍需按输出模板选择正确字段和真实素材绑定。
