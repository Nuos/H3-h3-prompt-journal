# 宋韵古典舞的双层节拍、差异化高光与连续交接

把长篇舞蹈导演稿转化为有输入权限、统一时钟、动作依赖、镜头状态和交接契约的分段生成任务，在保留宋韵身韵与水袖响应的同时，去除原案残留版本、时间和画幅歧义。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **作品与交付约束**：给定总长、分段窗、情绪曲线、共同画幅或多版交付计划、连续动作匹配还是允许蒙太奇，以及腾空、支撑、地面动作的允许范围；段数与技术动作数量按新任务决定。
- **图像权限与服装能力**：指定完整人物／服装／场景参考和仅作身份结构澄清的参考；确认水袖、裙腰、裙幅及可见支撑空间。没有圆裙就不生成圆盘式裙形，没有实际上一段末帧就不声称已经继承其真实状态。
- **音乐与事件**：提供各段音频文件、源起止、实际段长、BPM、首拍相位或拍点表、结构重音和人声事件；每项标记用户给定、源案例记载、实测、推算或未知，并指定原音完整复用还是允许叠加拟音。
- **可执行动作与边界状态**：登记每段主动作的支撑部位、准备、峰值、恢复，人物解剖学左右、身体朝向、下一落脚、双手与袖尾状态，以及需要保持还是重新编排的接缝；新项目允许简化原案高难动作。

## 执行流程

1. **建立视觉权限与共同画幅**：先定义谁决定人物、服装、场景、灯光和色彩，谁只补充脸与身体结构。原案 Picture 1 是完整视觉权威，Picture 2 不能接管姿势、环境、机位或首帧。人物与环境可以分别定义为可复用 Subject，并记录参考权限。为新生成任务在编舞前选定统一画幅；如需保留原案前五段竖幅倾向、末段16:9，明确公共母版及 contain／留边或独立版本策略，不能靠拉伸或裁掉支撑脚、裙缘拼成同一成片。
2. **统一分段窗和双层节拍**：维护唯一事件表：源时间、段内时间、事件类型、来源与置信状态。原案六窗为0–12.410、12.410–25.610、25.610–38.070、38.070–50.533、50.533–62.500、62.500–75.468秒。细拍间隔按60/BPM计算，慢身体脉冲可选每两细拍，结构性★／◆另列，不能把每一细拍都标作强拍。原案121.5 BPM的精确计算值约0.493827秒，0.494是显示近似，不用反复累加近似制造漂移；缺首拍相位不能仅凭BPM编造准确拍点。源S04只保留1.924、3.899、5.875、7.850、9.825、11.801的递增表，旧乱序表只留档。
3. **按主导机制安排高光而非改名重复**：为每段写主导变量、支撑关系、空间路径、衣料响应、准备与恢复预算。原案由脸部揭示到裙幅展开、腾空交叉改向、单轴着地控制、位移腾跃、肩／上背低位旋转；这些只是可选编排。S03与S05共享腾空换腿子动作，应分别强调反向身体线与平移路径，不能宣称完全无重合；若用户要求机制严格唯一，就替换其中一个。删除S05“整舞第二个主要Hero”和不存在的前段单手720度地板转回指，用段内技术高光与全局清单计数。不给 Hero 等作者标签赋予H3内置参数或标准舞蹈术语地位。
4. **展开身体、材料与支撑的因果链**：每个动作从支撑脚接地与换重开始，写骨盆、腰、躯干、肩、臂、腕、指尖和水袖的响应次序，头眼在需要时延迟。腾跃应有推地、轨迹与对侧承重恢复，着地控制应持续说明支撑脚，地板动作应说明肩／上背接触与低位恢复而非跳到终态。裙形从腰头传到内、中、外层和裙缘，不把比喻的blade或disc生成金属物，也不让袖裙先于身体自主移动。对服装、时长或可见性不适配的高难动作先简化，再保留情绪与节奏功能。
5. **把连续性写成逐对交接状态**：将每段出口与下一入口逐项对齐：解剖学左／右支撑、另一脚的下一落点、身体朝向、重心进程、双手／袖尾相位、头眼方向、运动方向与速度趋势、相机位置和身体可见范围。把原案“某只脚”“一侧较重”“略斜”落实为新编排的具体状态；无实际成片时标作目标状态，不假称已观测。下一段0秒直接接仍在进行的运动，除最终收束或用户允许的剪辑外，不回中性站姿。参考图保持身份并不自动携带前一生成片段的末态；需要硬关键帧时按实际已提供的关键帧重新选择模式。
6. **拆开跟拍、短重构图、硬锁与切镜**：为相机登记tracking、brief_reframe、lock三个互不重叠的时段；原案实际上包含持续跟拍，不能把整个方案压成只有burst和lock。每次锁定写开始、结束和相机位置，随后恢复跟拍也要有边界。technical peak时可锁相机让舞者完成动作，脸部payoff安排在身体链与恢复之后。用脚／小腿至头顶等实际覆盖定义构图，不能按medium-close标签裁成胸像；需要看支撑脚和完整裙幅时局部放宽到足够的身体范围。three-quarter译为四分之三侧面。区分真实切镜和同一镜头内运动段，只给真实切镜加官方Shot标签。
7. **明确终止与声音对象的范围**：把最终约束拆成相机、身体、布料三条状态。原案末段11.650–12.968同时写微小呼吸／布料余动和absolute static；默认工程修订为相机完全锁定、人体安静但可呼吸、袖裙逐渐停稳，改名locked ending。若用户明确要求全画面冻结，则该区间显式覆盖呼吸与材料余动。结尾到时停止追加新动作。原唱歌词可继续存在于配乐，不等于舞者唱歌或对口型；如保留原案S05脚步／衣料声建议并叠加在音乐上，应选择partially_copy，不得同时写fully_copy。
8. **编译自足的H3分段正文并分层检查**：每段独立编译Ref2VA的subject_definitions、summary、retention_analysis、detailed_description、overall_soundscape、non_diegetic_music；展开本段需要的共享权限与边界，使用英文动作正文，保留原文对白／歌词。把人物和环境绑定到Subject，身份澄清图不充当首帧。summary使用官方任务类型，视音频保留程度分别选择。检查总长、事件排序、段内范围、无重置接缝、机制复用说明、画幅、镜头状态和冻结范围，再用scripts/audit_plan.py做其能力范围内的结构审计。报告文本修复、未知音频事实与待生成核验；3位小数时间意图不等于24fps逐帧落点已获保证。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **SG01**：完整视觉参考与身份结构澄清参考权限分开，参考图不自动等于首帧或前段实际末态；歌词中的原文色词不构成新增视觉色彩指令。
- **SG02**：段内时间由源窗口换算，细拍、慢舞句和结构重音分层；使用唯一递增拍表，BPM不能替代未知相位或实测音频。
- **SG03**：高光以主导机制和支撑／路径区分；承认S03与S05共享换腿子动作，删除S05第二Hero与不存在的720度历史回指。
- **SG04**：脚与重心驱动躯干、手腕和水袖，裙摆始终依附腰头并有材料滞后；衣料比喻与力学意图不是已验证物理模拟。
- **SG05**：接缝要求左右明确的动态状态匹配，不能只用同一身份或“某只脚”证明连续；无生成末帧时仅声明计划目标。
- **SG06**：前五段竖幅倾向与末段16:9必须有交付契约；新项目先选共同画幅，保留混合旧片时明示母版、留边／裁切与独立版本。
- **SG07**：跟拍、短重构图和硬锁有明确区间；锁定相机时人体可继续；景别按真实身体覆盖，three-quarter为四分之三侧面。
- **SG08**：持续舞句不等于禁止切镜，动作阶段不等于Shot；技术峰值先完整呈现，再让脸部构图完成情绪收束。
- **SG09**：结尾必须选相机硬锁且微动允许，或全画面冻结其一；原音完整复用与叠加拟音也要分别选择，不用一句绝对约束覆盖不同对象。
- **SG10**：原案Hero命名、六段结构和双层节奏属于案例编排；翻译与作者结果陈述不增加独立实验，文本检查不认证模型同步或连续性。

## 输出与检查

- **素材与交付契约**：人物／场景Subject及参考权限、服装结构边界、允许动作、共同画幅或混合画幅合成方案、音频最终使用策略。
- **双层音乐与高光表**：每段源起止和局部事件、精确计算与显示精度、细拍／慢舞句／★◆的层级、高光主导变量、共享子机制及准备恢复预算。
- **身体材料交接和摄影机计划**：左右明确的支撑与动作链、腰头至裙缘／腕至袖尾的延迟、段间目标状态表、跟拍／重构图／锁定区间、真实切镜及最终三个对象的停止条件。
- **逐段Ref2VA与证据分层审计**：每段可独立提交的六字段英文正文，修订后的时间与旧回指清单，翻译术语修正，未核验音频相位／末帧／成片效果及下一步实际核验项。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
