## 3. skill 化判断与最小落地步骤

**可以形成原型，但不宜将全文一次性塞入每个生成任务。**建议流程：识别片型与参考权限 → 按舞种/支撑状态检索动作 → 用实际音乐时间窗约束容量 → 补齐出入态与动力链 → 选择一种镜头响应模式 → 输出逐段自包含文本 → 按现有十项逐窗检查返修。[S2]

最小工程化工作包括：为动作建立稳定 ID 和字段（拍数、入态、出态、受力、峰值、回收、道具、适用片型、证据等级）；把 E/I/G 作为按需加载的参考模块；编写拍数/秒数、状态可接续、模式互斥检查；用跨舞种、跨 BPM、换道具和不同片长任务建立回归集。以上均为建议，当前目录没有已实现的 skill 包与回归执行器。

## 4. 主要缺口与优先级

1. **P0：消除同步模式冲突。**使用规则及 E 章总则要求同时启动、峰值同步；E1 要求提前跑位、画框先到；E8 又要求迟半拍跟随。三者可分别服务不同风格，但当前“适用本章全部条目”的总则不能直接兼容这些例外。[S2：23—30、686—698、777—817]
2. **P0：给跨切与首帧策略加条件。**E3 写“从不切在动作半途”，E6 允许旋转中相位匹配；H0 要复制参考首帧姿势，J 面向锁姿写真。应输出“动作续接/姿态跳切”“继承首帧/仅继承身份”等显式模式，禁止全库通用拼接。[S2：716—721、750—763、919—933、1953—1975]
3. **P1：校验元数据和范本结构。**C19 标题 7 拍而分解到第 8 拍；J7 宣称 9 镜、8 次硬切，但镜头表只列 SHOT 1—8；“旋转≤2”与多圈链还需明确计数单位。应先修数据，再把规则自动化。[S2：398—402、494—498、2112—2136、2764]
4. **P1：隔离素材描述与目标指令。**K 章把源人物、环境、风格细节写入 H3 短句，和其他模块的参考图独占外观原则需要转换层；单图推测链及 G 章实现度评级应保持证据标签，不升级为已验证保证。[S2：867—910、2227—2241、2393—2412]
