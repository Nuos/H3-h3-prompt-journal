# 双图分权半身舞蹈六段：案例简评

## 核心结论

**最值得提炼的是“参考图权限拆分＋首帧动作权重新分配”方法。**图 1 负责脸部身份，图 2 负责全身外观和环境，舞谱负责动作起点；“半身肖像感”转换为镜头距离要求。它可形成参考素材绑定和开场姿态检查子技能，并为六段舞蹈提供模板。但当前文本没有跨任务回归，也未把六段接合状态和全曲音频裁切映射完整结构化，不能视作已稳定运行的长舞 skill。[S1][S2]

## 3. skill 化判断与最小落地步骤

可先封装“参考权限编排器”：输入图像编号及属性授权、首帧舞谱、时长、拍点与镜头偏好，输出每段自包含的参考绑定块与动作段落。检查器应确认每段都声明身份来源、姿势来源、音频来源和镜头职责，避免复制时漏项。[S1][S2]

长舞流程还需增加全曲时间到 local 时间的映射，以及段尾/段首状态表：支撑脚、朝向、手位、动量、镜头位置。验收至少覆盖首帧姿态泄漏、动作中切镜是否续接、足部动作是否可见、段间是否重置。这些是建议的封装与验证工作，当前案例没有对应脚本或测试集。

## 4. 主要缺口与优先级

1. **P0：补齐跨段接合契约。**Seg01 尾部是手臂内收、脚回位、对侧肩启动；Seg02 开头仅指定新的压膝起势，未逐项绑定上一段的支撑状态。其余分段同样不能仅靠“持续运动”推定无缝。[S2：302—310、471—487]
2. **P1：统一开场时间口径。**总述要求从第一帧动作开始，但 Seg03 第一个具体动作时间为 0.468s；Seg01 则在 0.000 定新姿位、0.255 才写脚尖动作。应说明前置时间承载预载、呼吸还是延续态，避免重新出现静止开场。[S2：57—61、174—192、697—711]
3. **P1：把风格约束参数化。**冷白/银灰、金色唯一强强调、固定半身距离是本片设定；替换图 2 时，应明确新参考的灯光与固定调色发生冲突时谁优先。[S2：26—44、86—119]
4. **P1：补证据后再谈稳定。**README 的“模型不能再推断整图继承”等句子不是模型机制证明。需要用不同姿态参考图做对照，并记录模型版本、参数和生成后失败情况。[S1：27—31]
