## 方法来源与适用范围

把参考图允许继承的属性、禁止继承的姿势和开场动作来源逐段写清，防止每次生成先复刻照片站姿再起舞。

本方法由原案例文本、逐案评估和 H3 官方协议共同整理。原案经验、评估发现与本次补齐的数据/检查接口须分别表述；案例作者的成功报告不等于本次实测。原稿快照保留原貌，冲突由本文件及技能入口裁决。

- 六段111BPM、73.378秒、单人、半身和冷白教堂是原案设定；迁移需参数化。
- 连续舞蹈不等于单镜头，原案安排多次Motion Cut。
- 原稿没有完整官方六字段；本技能依当前guide规范化，不照搬分散自定义块当官方API字段。
- 现有资料没有跨任务姿态泄漏回归；权限清晰度是设计产物，不是对模型内部机制的证明。

## 条件分支与冲突处理

| 条件 | 执行动作 | 案例/评估依据 |
|---|---|---|
| 脸部图带明显手势和头部倾斜 | 保留脸部身份，排除手势、头角与构图；由舞谱给新动作入口，不设置为精确首帧。 | README.md:18-25 |
| 第一拍在0.468秒才开始 | 为0–0.468秒定义承接态的支撑转换或预载，不能空白等待后才起舞。 | review:44 |
| 后段拟从新站姿起步 | 对比前段支撑、手位、朝向和镜位，修改后段入口以接住实际出口，或明确采用叙事断接而不称无缝。 | review:43 |
| 图2是暖色室内而旧模板是冷白教堂 | 优先当前用户明确的环境/光照授权，删除旧调色锁或标为有意风格改动。 | review:45 |

## 失败表现与修复

| 失败表现 | 修复步骤 | 依据 |
|---|---|---|
| 先复刻照片站姿再跳舞 | 除去精确首帧绑定，提供0秒起正向动作和属性授权表；只加一句否定不足以填补开场。 | README.md:10-31 |
| 六段各自连续但拼起来支撑脚跳变 | 补段尾/段首结构化状态，按照同一字段逐项匹配。 | review:39,43 |
| 写了复杂脚步却全程只拍胸像 | 把关键脚步的相机下降/后退窗口写进同一时间线，再回到半身。 | prompt.md:83-84,222 |
| 高光镜头变成静止肖像 | 把高光设为动作链的瞬时技术峰值，切镜继续未完成轨迹。 | prompt.md:284-310,1499-1506 |

## 迁移示例

**任务**

10秒半身舞：图1是手托下巴的脸照，图2是暖色咖啡馆全身照。两图只锁外观与场景，音频首拍0.350秒，6秒在转身中切镜。请避免照片姿势开场。

**预期处理示例**

授权图1脸部结构与肤质，拒绝托下巴、头角和静态构图；授权图2体型、服装、发型、咖啡馆与暖光，拒绝站姿。0–0.350秒从左脚承重、右脚尖轻触地开始膝预载，右手由腰侧向外启动，首拍完成第一次换重心，不先摆照片姿势。4.5–5.2秒展示关键交叉步时相机略后退并降低，随后回到肩颈、躯干和手部完整可见的半身。6秒在右向转身尚未结束时切到侧前三分之二视点，保留右转方向、支撑脚和手臂弧线。10秒按用户选择的动中结束策略收片；保留咖啡馆暖光，不套用原案冷白教堂色板。

示例是编排示范；其中任务给定参数和演算不代表当前已经读取了对应媒体，也不代表一次 H3 推理已完成。完整生成端交付仍需按输出模板选择正确字段和真实素材绑定。
