# 双图分权半身舞：身份、首帧动作与镜头职责分离

把参考图允许继承的属性、禁止继承的姿势和开场动作来源逐段写清，防止每次生成先复刻照片站姿再起舞。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **两张图片的属性权限**：记录脸部身份、发型、服装、体型、场景、光向各由哪张图提供，哪些姿势、手位、朝向和构图不继承。
- **首帧舞谱/交接态**：给从0秒起的支撑脚、膝预载、重心方向、手臂起点与目标；后段优先继承上一段出口，而非每段新建无关站姿。
- **音频与全局映射**：提供每段真实音频、全曲起止、BPM/首拍和片段时长；无全曲偏移时标明仅有局部数据。
- **镜头风格与可见范围**：指定半身距离、手持响应、肩颈/手部边界、重要步法是否需要短暂展示以及当前图2与调色方案的优先级。

## 执行流程

1. **编制逐属性授权表**：把图1脸部身份和图2全身/环境授权列成明确映射；姿态、头角、手位、朝向和静态构图各自标出继承/不继承。不以整张图完全保留覆盖更细的权限。
2. **重新指定动作起点权威**：首段由舞谱定义首帧连续动作，后段由上一段接合态定义。明确0秒到首个拍点之间的重心预载、膝弹或上一动作余势，填补原案0–0.468秒等未写具体动作的区间。
3. **补齐长曲时间与段间接口**：按真实音频区间生成全局/局部映射。为每条段缝记录支撑脚、朝向、手位、动量和相机位置；同一句持续运动不等于这些值已经匹配。原六段总长73.378秒仅作回归样例。
4. **编排连续舞句**：将膝压—回弹—换重心的持续层与2/4拍舞句结合，动作按准备、启动、展开、重拍、吸收、接续展开；密度增加仍共享一条动力链，不把每半秒变成无关姿势。
5. **翻译肖像感为摄影机职责**：把半身摄影感落实为物理距离、脸肩颈躯干和手部可见范围；允许相机提前、延迟或短暂等待。技术关键在足部时短暂降低/后退，让支撑看见，再回到肖像关系，不机械追每个肢体。
6. **设计动作中切镜与高光观看位置**：在未完成动作内切镜，写清相同肢体路径、方向、重心与动量如何续接；技术高光是运动峰值，不是停摆摆拍。连续舞蹈可以包含多次切镜，不等于一镜到底。
7. **处理画面政策和结束态**：依据当前参考和用户要求选定光向/配色权威；旧案冷白银灰金色不得覆盖新的参考。若任务沿用动中结束，在真实音频末点结束动作，不添加照片姿势或人工变暗；若用户另要定格则显式改结束策略。
8. **输出官方参考提示词与检查**：在Subject定义中汇合两图的不同属性来源，音频单列定义并注明1:1复用条件；用六字段Ref2VA和逐镜detailed_description。检查每段绑定、0秒动作、足部可见窗口、切镜续接和段缝状态；效果需实际生成后核验。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **ID-01**：每张图片必须同时说明授权属性和不继承属性；身份参考不自动成为首帧姿态参考。
- **ID-02**：禁止照片姿态后，必须给出正向动作来源；0秒至首拍的预载/余势不可留白。
- **ID-03**：后段开场与前段出口逐字段配对，不能用各段新的dance-ready position代替跨段连续性。
- **ID-04**：半身感限定相机距离和可见范围，不授权复制照片的头角、手位、身体朝向或静态构图。
- **ID-05**：关键足部动作须有实际可见窗口；半身偏好与全身技法冲突时调整观看位置，不写看不见的技术验收。
- **ID-06**：Motion Cut保持同动作、方向、肢体轨迹、重心与动量；高光峰值不自动要求停住。
- **ID-07**：全曲与局部音频必须有可追溯映射，局部数字不能被当成全曲测量；六段时长仅为案例样本。
- **ID-08**：旧案冷白银灰/金色及动中结束是可选片风格；换参考图时必须声明与新光照的优先级。

## 输出与检查

- **双图属性权限表**：脸、发型、服装、体型、环境、光向、姿态、构图的授权/排除与冲突优先级。
- **连续时间与接合表**：全局起止、局部拍点、0秒预载、段间支撑/朝向/手位/动量/镜位接口。
- **肖像舞镜头与提示词**：舞句、关键足部可见窗口、动作中切镜、高光观看位置及官方Ref2VA正文。
- **首帧泄漏及连续性Gate**：参考角色检查、动作空白检查、段缝一致性和实际输出待核验清单。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
