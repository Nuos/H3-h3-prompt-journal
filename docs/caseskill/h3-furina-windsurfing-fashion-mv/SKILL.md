# H3 分层参考与帆板写真 MV 高潮编排

把源案例的三层参考架构和文字高潮控制转为可迁移的制作契约，修复“同一定妆图作为三段不同起始状态”、独立片段无状态交接及配乐重制后节拍漂移的问题，并明确哪些结果仍须观看生成视频和量测音频才能判定。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **当前人物与装备资产**：列出人物身份图、服装/多视角图和帆板装备图的实际文件、用途、可见特征与缺项。人物身份、衣服、鞋、板体、桅杆、boom、帆和索具分别核对；不可见结构写 unknown，未提供文件写 missing。源角色的蓝眼、冠饰和蓝白配色不自动继承到新任务。
- **分段摄影参考与权限**：分别提供前两段的摄影指导图，说明构图、主体尺度、跟拍方向与摄影机高度；第三段是否沿用源案例的无摄影图策略须明确。指导图的箭头、版面和文字不是场景内容；若图文运镜冲突，先选定或重做同一个摄影意图。
- **输出长度与生成模式**：记录成片长宽比、编辑时间线 fps、每段 generation_duration、edit_duration、局部/全局窗口与实际输入模式。标准 H3 每次生成 4–15 秒、24FPS；45 秒成片需要多个生成任务再装配。精确首帧约束与多图参考不能只靠在 Ref2VA 文本里写 FIRST FRAME 就视为同一能力。
- **运动与跨段状态**：给出运动类型、允许动作、板航向、身体重心、手握 boom 的位置、脚位、帆角、风向、浪相位与摄影机相对位置。提供前段批准的实际 OUT 帧或逐项状态记录；未生成时标 planned，不伪装成已检查的连续性。
- **音乐与事件证据**：提供完整原音轨、测量过的 BPM/拍号/重拍/乐句时码及来源，或声明只有音乐设计目标。源文约 128 BPM 和局部 3 秒/9–10 秒窗口不能当成当前音频的实测结果；本任务没有音频时不创建假 Audio 标签。
- **外部配乐与交付接口**：明确完整视频版本、提取音频版本、交给 Suno 或其他工具的完整参考轨、返回配乐文件与版本、最终时长和同步容差。工具能力与素材尚未核验时只输出交接计划，不虚构 Suno 参数、生成结果或固定时长承诺。

## 执行流程

1. **核验素材与选择真实输入模式**：逐个登记人物、装备、G1/G2 摄影图和音轨的可用状态。本案例仓库文字列出五个媒体文件，但当前快照没有这些文件，不能据此声称已观看原片或量测 128 BPM。以实际接口选择 Ref2VA 或首帧模式，按 4–15 秒、24FPS 建立生成切片；成片 45 秒不等于一次生成 45 秒。
2. **为三层参考划定控制范围**：人物图负责身份与外观；装备/多视角图负责服装结构、鞋和板/桅杆/boom/帆/索具；当段摄影图只负责机位、构图、尺度和运动方向。人物图若确实作为首帧，其初始构图也会生效，不能同时宣称它完全不影响构图。Picture 1 与 Picture 2 对服装存在差异时逐属性裁决，不写互相冲突的全保留。禁止把 turnaround 版面、箭头或多个人物视图生成成场景。
3. **建立三段的 IN/OUT 接口**：以高速帆板→更大浪区→浪峰跳跃和收尾分配叙事职责。每段独立携带同一角色和装备定义，并填写 IN/OUT 的板航向、速度等级、脚位、握杆、重心、帆角、浪的位置/相位、风与摄影机状态。第二段 IN 接第一段已批准 OUT，第三段 IN 接第二段的浪前预备态。定妆照只可承担身份职责；要求精确接续帧时提供真实接续素材并使用支持该约束的模式。仅凭文字续接仍须输出后核验，不能同时要求三段从同一棚拍图精确开场又处于三个不同运动阶段。
4. **递进前两段而不提前消耗终极动作**：第一段用近/中景长焦构图、侧向跟拍、适度加速、水花和克制的视角变化建立角色与运动；结束仍保留前进趋势。第二段逐渐增加涌浪尺度，让浪壁进入可读背景，展示身体重心和帆角调整，停在正式腾空前。每段可以有自己的局部能量点，但最终段才承担全片最大高潮；源第二段 3 秒处写有 cut，须按当前目标决定是明确切镜还是连续移动，不能擅称整个方案一镜到底。
5. **文字主导第三段的完整跳跃链**：第三段保留人物/装备参考，移除摄影指导图并重写机位和构图。动作顺序为接近浪壁、上浪、预备、板体离水、空中主视觉、下降、板体重新触水、继续滑行、写真收尾；源 7–8 秒离水、9–10 秒主视觉、11–12 秒回水是该 15 秒段的计划窗口，不是实测运动学。不得靠悬停、倒放或冻结人物与海浪延长高潮。英雄窗口停止激进运镜，允许稳定的随动保持人物、板和帆可读；时间不足则重排预备或延长合法生成切片，而非省略回水。
6. **把音乐功能转换为可核验事件**：建立局部时间、全局时间、来源、音乐功能、可见动作和摄影状态的事件表。无音频时 128 BPM 或用户指定节拍仅为 planned；3 秒 Drop 与 9–10 秒峰值是叙事目标，不自动等于精确拍点。mini-turnaround 指音乐转接，可触发轻微运镜变化或起跳预备，不是要求人物转面。将主视觉中心、板离水、板触水分别登记，避免把它们挤成一个无法读取的瞬间。
7. **输出每段符合官方格式的提示词**：多参考任务按顺序使用六个英文字段 subject_definitions、summary、retention_analysis、detailed_description、overall_soundscape、non_diegetic_music；为当前实际资产定义稳定标签，summary 标明 reference generation，逐项说明保留角色/装备或仅转移摄影关系。正文先写风格再写无时间戳的 [Shot 1]，只有真正切镜才新增带时间戳的 Shot；连续动作事件写在同镜内部。三段均写完整开场状态，不引用“上一段模型已记住”。若选择 T2VA/I2VA/FL2VA/L2VA，改用 integrated_multimodal_description、overall_soundscape、non_diegetic_music 三字段，并同步调整实际输入，不混用两个协议。
8. **全片装配后交接完整音频并再次对位**：先记录三段选择、裁切窗、接缝和全局偏移，完成完整视频版本，再提取完整参考音频交给外部配乐工具。Suno 返回的音乐是新版本，不假定长度、Drop 或峰值时码保留。对实际返回轨重新量测，建立原视频事件时间→新音乐事件时间→差值→修正动作→复验的表；根据听感和动作连续性选择调整配乐或视频剪辑。区分现场水声/风声与观众配乐，记录是否有独立轨或只有混音；不凭空宣称已分离 stems，替换配乐时也不叠加重复音乐。
9. **以可见证据验收和记录边界**：检查人物/装备身份、双手与 boom、脚与板、桅杆与帆连接、风驱动发丝布料、水花与触水因果、两道接缝及英雄构图可读性；再按已声明容差复核最终音轨的峰值/落点。没有生成视频时这些均为待验收项。第三段移除摄影图的效果只作本案例经验；若需要比较，固定其余输入与模型设置制作保留/移除两版并记录结果，比较方案属于工程补齐，不宣称已经进行。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **FWM01**：把人物身份、装备结构和当段摄影关系分别赋予参考权限；不复制多视角版面或图示箭头，并先解决人物图与装备图的服装冲突。
- **FWM02**：源策略第三段只移除摄影指导图，仍保留人物与装备参考；这是为当前高潮重新设计镜头，不是跨段记忆清除或所有任务都应减少图片。
- **FWM03**：独立生成的片段必须显式交接运动和构图状态；同一静态定妆图不能同时充当三个互不相同的精确开场帧。按实际模式处理接续素材，文字开场指令仍须结果核验。
- **FWM04**：三段按建立高速运动、逼近更大浪壁、最终受控腾空递进；第二段不得提前完成最终跳跃，第三段回水后不再新增主要动作。
- **FWM05**：高潮保持帆板运动及装备连接：上浪→离水→空中→下降→板触水→继续滑行；landing 是板体回水，不是人物跌落水中。源动作不含后空翻、复杂旋转或海啸水墙。
- **FWM06**：Hero Shot 稳定的是摄影构图和运镜强度，人物、帆板、布料和海浪继续运动。主视觉需同时看清人物、帆、板与离水间隙；近景长焦不等于摄影机物理距离必须极近。
- **FWM07**：区分原文报告、当前设计目标与实际音频测量；mini-turnaround 是音乐转接。没有当前音频不得编造 BPM、重拍或最强重音时码。
- **FWM08**：完整视频先装配，完整音频再交给外部配乐重制，返回音轨必须重新对齐全片事件；不把 Suno 重制视作固定时长或保留原始拍点的保证。
- **FWM09**：源三段自由格式提示词需按实际模式迁移为官方 Ref2VA 六字段或基础模式三字段。标准生成每片 4–15 秒、24FPS；多段成片总时长、剪辑帧率和裁切时长单列，不能冒充一次生成能力。
- **FWM10**：参考图等权、撤图更有效、Suno 更连贯均保留为源作者的经验或意图，不写成模型内部机制或已验证保证；源资产缺失和实际未执行的部分必须明示。

## 输出与检查

- **资产与参考权限表**：实际文件/版本、局部标签、人物/装备/摄影/声音职责、保留范围、明确排除、缺失或不可见信息、每段是否启用。
- **三段状态与时间表**：段落职责、generation_duration、edit_duration、fps、局部/全局窗口、IN/OUT 状态、接续证据与缺项；计划状态与实际批准帧分列。
- **逐段官方格式提示词**：每段完整独立的 Ref2VA 六字段英文输出，或按真实模式切换后的三字段输出；正文有可见动作、摄影和声音因果，第三段明确无摄影参考而保留角色/装备来源。
- **动作—摄影—音乐事件表**：Drop、预备、板离水、可读主视觉、板触水、释放及收尾的局部/全局时间、planned/measured 来源、动作状态与摄影状态。
- **装配与配乐交接单**：片段选择、裁切、全片版本、完整参考音频、外部重制任务、返回轨版本、各声层职责，以及新音乐事件/原视频事件/偏差/修正/复验的对位记录。
- **验收及证据边界**：两道接缝、装备接触、波浪和风、水花因果、主视觉可读性及最终音画同步；未实际生成、媒体缺失、未测量音频和源作者经验单独列明。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
