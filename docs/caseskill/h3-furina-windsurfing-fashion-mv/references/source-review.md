## 3. skill 化判断与最小落地步骤

建议输入角色/装备参考、各图权限、三阶段动作目标、高潮事件和音乐方案；输出各段提示词、状态交接表、完整剪辑表及最终音频同步报告。把 Suno 重制设置为显式外部步骤，记录输入音轨、输出版本和二次对齐结果。[S1][S3]

最小验收应覆盖参考越权、装备断连、高潮时主体可读性、段间运动接续和最终配乐落点。静态文本符合时间顺序，只证明编排意图，不能代替这些成片检查。

## 4. 主要缺口与优先级

1. **P0：补足跨段起始状态。**每段均要求从图 1 开始，却又分别要求承接高速前进、接近大浪。三个独立生成任务不会因提及前段就获得其末状态；应明确每段首帧来源、板体朝向、重心、浪体位置和动作阶段。[S3：287—311、540—563、782—806、1141；S5：107]
2. **P1：固定最终声音时基。**视频完成后重制整轨配乐是清楚的制作顺序，但新音乐不保证仍在原 3 秒、9—10 秒落点。保留“最终同步剪辑”并增加拍点映射和允许偏差。[S3：1207—1236；S5：87—95]
3. **P1：参数化参考权限与验收。**不要把作者关于参考“等权”或去图后的效果解释为已知模型内部机制；将保留/取消摄影图写成可比较的配置，并记录对照结果。[S1][S5：14、83—107]
