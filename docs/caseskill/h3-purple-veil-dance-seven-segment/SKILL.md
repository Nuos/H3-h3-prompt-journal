# 紫纱亭舞：主动力轮换、实物交接与服装显色

用每段主导机制和可见的肢体/衣料出口连接独立生成片段，在明确的服装可见性、音乐相位和色彩目标下编排具体动作。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **参考分权表**：分别指定人物/服装/环境图片、动作文字来源、分段音频及其参考或复制角色，明确是否附动作视频。
- **音乐时间依据**：提供实际音频标识、切割manifest、BPM/拍号/首拍和可核实歌词onset；没有manifest时将既有数字标为作者记录或用户输入。
- **不变外观与可见性**：列服装材质/色彩、面纱是否始终遮挡，以及允许可见的轮廓范围；只锁用户指定属性。
- **动作与交接要求**：给分段意图、主动力候选、承重/高度变化、首尾交接物和最终收势，区分舞蹈表达与逐字表演歌词。

## 执行流程

1. **建立资产与权威边界**：把图片设为身份/服装/场景的可选权威，把音频时间表设为节奏依据；若仅借动作不借原画面，则转写可见动作并标出未附视频，不声称模型直接读取了视频。
2. **校准每段全局与局部时长**：从全局边界相减得到真实局部时长，再从同一全局首拍及高精度拍长计算局部事件，最后才格式化小数。原案SEG03必须结束于13.300而非13.550；SEG05应覆盖13.800而非13.483，不能为保留旧稿悄悄改音频切点。
3. **设计主动力分布**：逐段选一个主导组织机制，如腰轴、脊柱提沉、膝承重、肩臂路径或呼吸顿挫；其他部位跟随。末段若汇合多种圆形动作，明确先后顺序，不把所有质量词同时列成大纲。
4. **先写首尾实物交接**：在交接表记录具体左右肢体/袖边、空间高度、运动方向、支撑脚和视点。下一段开场必须能看见该对象；开场表、正文首镜与总览同步。尤其不得以腰部特写承接头部高度过帧袖手。
5. **展开分时序编舞与物理支撑**：每句动作写脚部触地、重心、膝髋腰肩臂腕和衣料余势的顺序。用AAB-C、位移步、幅度升级等组织变化；弓步要求膝不触地时明确双脚支撑和伸腿脚尖接触，避免含糊lowering toward knee。
6. **统一面纱与歌词表达**：若锁定全程遮面，歌词中的揭纱/敬酒/跪疤转换为手臂几何、重心和方向变化；选定仅轮廓可见或局部五官可见中的一种，整片统一，不允许一边写五官永不可见一边安排眼部显露。
7. **形成服装显色实验计划**：根据当前材质和参考光向设置主体与背景的明度/色温分离、主体中调纹理和低姿态补光。紫衣暖金主光方案是原案经验；先选择风险最高的一镜试色，记录模型、参数及结果再决定是否批量。未实际生成时只交付试验计划。
8. **转写官方提示词并审计**：以Ref2VA六字段封装逐镜动作，使用detailed_description和明确切镜时间。音频仅参考节奏且后期铺原曲时写audio reference，不冒用fully_copy；将交接、显色、面纱、时长和源证据检查单放在模型正文之外。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **PV-01**：段内具体动作的先后、路径、支撑与出态优先于spiral/wave等质量词堆叠。
- **PV-02**：主动力轮换按段落计划执行；复合高潮按顺序展开，不将全部部位同时设为主动力。
- **PV-03**：匹配剪辑必须匹配具体交接物、左右、空间高度和运动方向，且对象在后段首镜可见。
- **PV-04**：全局边界决定局部段长；所有动作区间必须覆盖且不越过该长度，首拍和歌词时间各自保留来源。
- **PV-05**：全程面纱锁与眼睛/上脸显露不能并存；按任务选定可见性政策后同步正文与交接表。
- **PV-06**：侧弓步的支撑脚、伸腿接地和膝不触地条件要显式，不能靠低位形容词代替。
- **PV-07**：紫衣显色方案仅为案例假设/作者经验；通过小规模输出核验后再推广，不称为所有材质的色彩定律。
- **PV-08**：音频节奏参考与最终信号复用分开；无歌词manifest时不声称已经实测对齐。

## 输出与检查

- **音乐与分段manifest**：全局区间、真实局部时长、首拍/歌词事件来源、局部换算、末端覆盖。
- **主动力与交接矩阵**：每段主导机制、跟随部位、左右肢体/衣料交接物、位置高度、方向、首镜可见性。
- **可见性及显色方案**：服装不变量、面纱允许可见范围、主体与背景光色关系、代表镜头试验与待验证指标。
- **逐段H3正文与Gate报告**：官方字段提示词、清晰动作时间线、音频角色、越界/漏时/交接/遮面检查。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
