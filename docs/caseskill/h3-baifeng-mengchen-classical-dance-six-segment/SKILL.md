# 白凤蒙尘：动链反推与双生成匹配剪辑

把进入路径、承重、惯性和出态反推为具体编舞，让局部特写服务动作信息，再以明确源片入出点连接复杂生成结果。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **视觉权威与动作起点**：明确图1控制的人物/服装/环境范围，并区分实际首帧与身份场景参考；后段给上一段真实出口。
- **音乐与分段**：提供源音频、全曲窗口、BPM/拍号/首拍依据、局部时长和是否仅复用原音轨；未测数据标记为输入估计。
- **动链来源与叙事机制**：给可用动作链版本/正文、身体高度与支撑点变化、旋转和恢复意图；没有外部动链库时只采用随案可读动作，不假装调用未提供模块。
- **生成与剪辑环境**：记录实际模型/平台支持时长、输出fps、是否允许整段重复采样、计划接缝时间及额外素材余量；不从原案例猜平台能力。

## 执行流程

1. **固定输入和导演稿版本**：把原案例文本作为只读档案，另建当前任务导演稿和变更记录；参数化主体、环境、画幅、BPM及段数。记录所有生成任务实际引用的图片/音频，而非依赖前段记忆。
2. **建立音乐分段坐标**：先列全局起止、真实时长和局部锚点，再编排动作；拍点用于重心落点/方向转换，不要求每拍换全新姿势。动作可跨拍发展，时间估计与波形实测分别标注。
3. **反推动作链与身体层级**：为每链填写入态、启动部位、支撑手脚、重心路径、峰值、惯性和出态；在站立、低跪、坐姿扭转、半转及受限起身之间安排不同机制，衣袖和头发只随身体延迟运动。
4. **先解决段际状态接口**：先写边界表再写正文。原案SEG02出口是低位交叠前臂，SEG03可提交稿应从此状态进入，不能重置为参考图站姿。SEG03真实末镜为低位支撑停拍；默认让SEG04从同一低位构图和承重态接起，删除并不存在的上一段手掌特写宣称。
5. **按新信息设计局部特写**：用支撑脚说明转动来源、掌心说明承重、发丝遮挡后揭眼、腕回缩说明动作被截；写每次特写进入与回到全身的路径。镜头随下降/扭转/恢复运动，Dolly Zoom等效果只在关键动作必要时使用，不为堆术语而插入。
6. **建立双生成取用方案**：保留完整导演稿时，默认同一完整时间窗和整段音频生成两份候选，再分别取前半与后半；记录每份源片duration、local_in/out、source_audio_start及最终timeline位置。若平台不支持整段时长，保留原稿档案并明确编译两个派生执行稿，各自重映射local时间和入口，不能称为未拆原文直接执行。
7. **定义接缝核对与音乐连续**：在计划接缝附近比较支撑、姿态、手轨迹、旋转方向、相机运动和自然遮挡，记录实际选帧及fps。1–3帧容差必须换算秒数；原音轨在最终时间线连续铺放，不因换源片而重启，必要时丢弃重复生成音轨。
8. **输出官方提示词与分层验收**：参考图与音频任务采用完整Ref2VA六字段；导演稿动作章节和真正切镜分开编码，不能让每个动作章节自动变成Shot。先检查文本时间/接口，再凭实际生成素材检查承重、发丝遮挡、光色和剪辑接缝；未生成时保留待验证状态。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **BM-01**：动作链必须写入态、动力、承重、路径、峰值、回收和出态；动作名或形容词不能替代过程。
- **BM-02**：段内特写改变观察信息，段间匹配保持动作状态；二者分别设计。
- **BM-03**：档案原文与当前可提交修订稿分别保存；旧SEG03入出态冲突必须在实际正文和边界表同时修复。
- **BM-04**：双生成方案必须给出两次真实输入、生成时长、取用区间和最终位置，不能只写完整原文不拆或前后各生成一次。
- **BM-05**：平台时长限制从当前运行时核实；原文12.455秒双生成选择不是H3统一只能生成半段的证据。
- **BM-06**：同一音乐源的连续窗口在剪辑处不重启；实际接缝以帧率与选帧记录定义。
- **BM-07**：参考图的身份/环境权威不能与跨段动作起点混淆；没有精确首帧用途时不强制整图首帧复制。
- **BM-08**：甩发揭眼、低位起身及反向截断都要有具体支撑和运动因果；不得用新增人物、道具或无因抖动替代本任务的身体表演。
- **BM-09**：原案0.25–0.55秒特写、最多一次全转、无对白/口型是片风格规则；迁移时按任务保留或调整。

## 输出与检查

- **动作链与镜头表**：全局/局部时间、入态、支撑、动作因果、主机制、特写信息和出态。
- **原稿档案与可提交修订稿**：只读来源、工程变更说明、官方Ref2VA正文及准确的段间接口。
- **双生成执行/取用清单**：每次输入图/音频/提示词版本、生成时长、source local in/out、目标时间、fps及接缝余量。
- **匹配剪辑与验收记录**：身体/手轨迹/相机共同相位、实际选帧、音轨连续、缺陷和待生成验证项。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
