## 2. 多维简评

**方法论。**不仅列动作名，还追问启动部位、支撑、重心、惯性和出态，并允许动作跨拍发展。六段具有不同动力机制，避免将节拍误写为逐拍换姿势；歌词也未作为必须照字面表演的对象。最后的检查表与生成后人工剪辑构成较完整的制作方法。[S1：40–68、118–142]

**输入输出。**每段以同图和裁剪音频独立生成、局部时间归零，通用模板具有明确占位符。但模板仍硬编码 Song Yu、105.25 BPM、竖屏、单人等案例参数；封装需把这些提为输入，保留无对白和不新增人物等本任务约束的来源。[S2：29–55]

**跨段状态。**SEG01→02、04→05、05→06 明确匹配手腕或眼部细节。关键缺口集中在 SEG03：其开头仍写“从图中可见站姿开始”，而 SEG02 末尾要求低位扭转的交叠前臂；SEG04 又要求继承“SEG03 结尾的承重手掌特写”，但 SEG03 末镜实际只写低位静止、相机保持，并未安排该手掌特写。边界表的描述未完全落实到可提交正文。[S2：172、196–204、231–240、272–279、470–471]

**可复现性。**双生成手工剪辑给出全曲 33.916 秒／段内 6.958 秒的明确切点和前后动作，优于仅说“后期衔接”。然而一条 12.455 秒原文究竟如何驱动两次生成的输入窗口、时长及时间重映射仍未明确；“平台单次生成时长受限”没有平台/版本说明，不能推广为 H3 统一限制。[S1：84–95；S2：245–257]

## 3. skill 化判断与最小落地步骤

建议建立音乐舞蹈 MV 主流程原型，动链和摄影机分别作为可替换参考模块：

1. 将主体、画幅、BPM、音频窗口、动链版本、段长及局部时间映射提为输入。
2. 生成“入态→动作链→镜头信息→出态”段落表，再编译各段提示词；禁止先写正文再凭概述补接缝。
3. 对两次生成分别记录实际提示词、音频裁剪、时长和取用区间；明确保留整段原文时的执行办法。
4. 静态核对时间覆盖和边界状态，再用生成结果核对承重、发丝遮挡、接缝与音乐连续性。

## 4. 主要缺口与优先级

- **P0：统一 SEG03 入出态。**保留原文的档案需要与实际可提交版本区分；修正 SEG02→03、03→04 的正文及边界表。[S2]
- **P0：明确双生成执行映射。**给出两次生成真实输入和剪辑入出点，避免把“完整原文不拆”误当成已可自动执行的分段方案。[S2：245–257]
- **P1：补齐版本与回归。**锁定动链库版本、平台/模型参数及实际剪辑帧率；“前后 1–3 帧”须结合帧率解释，并用边界样本验证。[S1：59–68；S2：254]
