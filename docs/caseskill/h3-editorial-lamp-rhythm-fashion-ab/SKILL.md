# 台灯五章音乐时尚片与受控A/B变体

把音乐、灯态、动作和摄影统一到可复算的计划时间轴，同时把A/B真正固定的条件与改变的变量分开；依据实际正文而非误标文件名路由，保留资产、身体和材料连续性。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **Picture 1与参考授权范围**：确认单图中的成年人物、服装、房间、同一台灯、台灯初态、可用空间和初帧构图；图像missing时保留占位。正文只描述变化，不重复臆造外貌。原模板要求的不透明舞蹈内层若图中不可见，标unknown并需要明确服装设定依据，不能宣称已从图中确认。
- **变体与比较目标**：选择cute_jump、dark_skirt_throw或用户自定义Hero；声明faithful_variant保留真实正文差异，还是controlled_ab主动统一摄影等控制项。根据正文映射p83文件到可爱跳跃、p84文件到暗奢甩裙，不按文件名词义选择。
- **音乐来源与节奏参数**：给定生成配乐的目标BPM／拍号／小节数，或实际可听音轨及onset数据。案例124 BPM、4/4、31拍是新建音乐计划，未量测前状态planned，不标为detected或已精准同步。
- **Hero机械与衣料条件**：确认可抛甩的既有裙结构、可完成跳跃的站立与落地区域、服装内层和画幅。跳跃的双手不触裙、双脚后折靠拢；甩裙先抓握与蓄力。若服装／空间不支持所选动作，标资产不兼容并另拟改编。
- **生成与剪辑规格**：记录官方模式、4–15秒生成范围、标准24FPS、成片时长、镜头切换允许范围，以及声画同步容差与实际验收方法。灯开关是初态加四次切换，保持未量测与已量测两个表。

## 执行流程

1. **以正文内容建立正确版本入口**：扫描两版音乐调式、Moment09准备与Moment10动作三项联检：p83-dark-luxury-skirt-throw.txt实际上是A major可爱跳跃；p84-cute-backfolded-jump.txt实际上是E minor暗奢甩裙。中文文件跟随各自正文。生成语义化variant_id与源路径表，保留原文件名用于溯源，不复制README错误标签。
2. **冻结参考资产与允许变化**：用Picture1锁人物、服装结构、房间和同一台灯的位置；将计划灯态ON/OFF及其自然曝光差异列为明确例外，修复全程曝光不变与熄灯的冲突。首帧必须从实际图像构图接续，若并非三分之四中全景，增加可行过渡或标明调整方案。图中没有台灯、动作空间或内层依据时先列missing／unknown。
3. **计算拍格、灯态与独立过渡时间**：先算beat=60/BPM、bar=4*beat，再建立五个状态区间与四次切换。源124 BPM下31拍=15秒，切换在第8/16/24/28拍，即约3.870968/7.741935/11.612903/13.548387秒。保留精确值、显示舍入值、24FPS目标帧和误差；1.3、2.6、12.25等Moment边界标free_transition，不能误称整拍。
4. **提取真实公共骨架与差异清单**：公共表保存图像绑定、灯态、时长、Moment时间窗及动作阶段；逐版单列音乐、身体细节、视线、焦点与ROLL。暗奢在02用Dutch、04反向roll、06和09可选roll；可爱02/06/09明确无roll，04仍有含混的逆时针camera correction。faithful_variant显式保留差异；controlled_ab另立统一roll清单并记录删改，不能宣称原版逐字相同或只改调式和Hero。
5. **逐段写身体支撑与摄影响应**：每个Moment写支撑脚→重心→骨盆→躯干→肩臂→手端，配发起／行进／重音／刹停／释放，保证前后状态直接可达且不回中性站姿。区分侧蹲起身、侧步点地或后划腿、着地轻弹、紧凑提膝与最终离地跳跃。相机每段给起终位置、景别、触发、短路径、停止点与回正，离散状态之间明确切镜或实际移动，不能把十段写成无界连续绕行。
6. **将Hero与时间悬置转成可观察动作**：Moment08保持上一动作结构和自然呼吸／发丝微动，允许的微视差不等于最终hard lock。Moment09按变体分别抓裙蓄力或屈膝摆臂，禁止提前释放。Moment10在计划重拍同时触发灯亮和动作，机位后退／微升提供完整轮廓；跳跃必须下降落地，甩裙必须手先发力、布料滞后。bullet-time feel只保留峰值可读、身体短稳定、衣料惯性，不写长时间悬浮、字面慢动作或机械冻结。
7. **编译双版并审计差异**：由同一共享表生成每版H3正文，变体只读取对应动作与音乐；在controlled_ab中固定roll预算、景别、转换和时间，只开放指定变量。清理可爱版global rule残留foot sweep与本段toe point矛盾，关闭会破坏灯态计数的额外strobe blink，或把它明确作为独立编辑变体。输出before/after与新增工程规则，不能称原案已做严格对照实验。
8. **按实际成片验收**：生成前检验31拍时长、灯态全覆盖、四次切换、动作差异、roll回正和Hero边界。生成后读取真实音乐onset与灯亮变化帧，分别量测声画误差、离地／落地／布料滞后和末段锁机；记录多次运行再讨论稳定率。当前未运行H3，只交付计划与待验收表。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **R1**：按音乐调式和Hero正文识别版本：源p83文件=可爱A major后折腿跳跃；源p84文件=暗奢E minor双手甩裙，文件名和README标签相反。
- **R2**：五章灯态是ON→OFF→ON→OFF→ON，共五状态、四次切换；初态ON不算一次切换。同一盏灯及房间保持，熄灯使用原房间残余照明，不新造光源。
- **R3**：124 BPM／31拍／15秒及灯点是计划数学关系，不是生成音轨实测。保留整拍、细分和自由过渡标签，并记录24FPS舍入误差，不宣称小数时间恰好落在原生帧边界。
- **R4**：受控A/B须逐项审计摄影差异；原文暗奢02/04/06/09和可爱版并非同一roll规则。统一roll预算属于显式改编，不能假称原两版只在三个层面分叉。
- **R5**：每段动作有明确支撑与发起→行进→重音→刹停→释放，连续段身体结构不同且状态可达；轻弹脚不离地，提膝不是踢腿，最终跳跃不提前泄露。
- **R6**：跳跃版双手高举而不抓裙，双脚向后靠拢且落地；甩裙版先握裙蓄力、手向外发力、裙边滞后。二者不能拼成同一Hero动作链。
- **R7**：ROLL绕光轴、短促且有触发，使用后回正；discrete camera states要说明切镜或连续路径。Moment08近静止微视差与片尾hard lock不同，不能混写。
- **R8**：bullet-time feel不是字面慢动作或真实冻结；以短暂可读峰值、正常下降／制动、衣料残余惯性表达，并给实际时长。没有证据不能承诺自然跳跃长时间悬停。
- **R9**：参考图提供视觉资产，正文集中描述变化；全程保持资产需显式允许计划灯态造成的照明变化。未知内层、缺台灯或不支持Hero的裙结构不得伪称图中已存在。
- **R10**：配乐与整体声场分列，开关click只对应四次实际切换；额外strobe、快门声、随机灯闪或提前Hero会破坏该变体的计数和因果，必须删除或另列变体。

## 输出与检查

- **语义版本与源文件映射**：variant_id、真实调式／配器、Moment05/06/07/09/10动作、各版roll允许位置、原路径和错误文件名注释。
- **共享节奏与灯态计划**：精确拍号／拍位／秒值、显示值、生成帧、量化误差、灯初态及四切换、自由过渡边界、计划与实测状态。
- **每版H3提示词与变更表**：公共资产和时轴、逐段身体／摄影／声音、独立Hero链、faithful或controlled路由标记；列明统一摄影等工程修改。
- **成片验收表**：实际onset、灯态变化帧、身体重音、roll回正、跳跃落地或布料滞后、片尾锁机和A/B差异，未生成时留missing／pending。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
