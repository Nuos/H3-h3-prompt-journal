# 贴纸厨房喜剧：媒介边界、道具归属与四镜因果链

把二维角色、真实物件和真人动作分成清楚的媒介与权限层，再以带时间的道具交接和可见因果组织笑点，防止角色立体化、动作抢占或道具状态自相矛盾。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **角色图与媒介契约**：提供角色参考、必须保留的轮廓/配色/服装/平面性，以及允许暂时变化的表情、泪、肿包、鼓嘴和二维特效。图片不自动把厨房或真人手变成卡通。
- **真实环境与参与者**：说明实拍风格的厨房、锅/灶/凳子位置、POV方向、真人手的数量和动作职责；不得因换镜复制额外手或道具。
- **道具状态与所有权**：记录盐罐开口、封盖是否存在、盐流入口/出口、每时段持有人；给出锅铲翻炒、轻敲、舀食的连续用途。
- **喜剧时间和声音**：给总时长、四阶段或其他明确因果结构、实际切点、最低可读时间及容差；确认环境声、对白与配乐是否允许。

## 执行流程

1. **划分恒定媒介与临时表演**：将Subject的二维平面身份、轮廓和配色写入主体定义及保留关系；把表情/眼形/局部夸张形变列为允许动作。厨房、锅、盐和人手保持实拍材质，不从角色图片继承全景画风。
2. **建立正向道具规格**：先写透明、敞口、无遮挡开口和盐流路径，再用有针对性的禁止项排除盖、帽、软木塞或透明封口。保持开口状态贯穿相关镜头；不要把穷尽禁止措辞当形式验证。
3. **按阶段赋予动作权限**：Shot 1由贴纸双手持罐并亲自倾倒，真人手只持铲翻炒；Shot 2明确允许另一真人手接罐并记录随后放置位置。全片不碰罐会与夺罐矛盾，必须改成倒盐阶段内的局部约束。
4. **列四镜头因果链与内部动作预算**：写清取罐→开口朝锅→可见盐流→停止倒盐→人手接罐→轻敲反应→舀同锅咸食→送入口→吃下→夸张倒下。原10秒例有0/3/5/8秒四Shot起点；为密集的首3秒补内部窗口，超载时扩时或减少次级反应，不跳过因果。
5. **检查接触、空间与道具连续**：逐镜核对盐从开口进锅、握持从贴纸到人手、同一锅铲移动到头部/锅/嘴、凳子与倒地方向。区分锅和炉灶、蒸汽和烟；人手轻敲只触发夸张卡通反应，不生成真实伤害细节。
6. **限定卡通变化和停止范围**：短暂红肿包、旋转眼、泪、鼓嘴、X眼、星星和白色灵魂效果都属于同一贴纸表演，不另生实体角色或把贴纸整体膨胀为三维。8秒的freeze按瞬间僵住/姿态刚性处理，随后微颤与跌落仍可发生；最终hold明确是构图/角色姿态还是整帧冻结。
7. **生成官方Ref2VA正文**：真实图片只作Subject身份来源，除非当前任务明确指定首帧。采用官方六字段、任务前缀、有效retention值；风格句在Shot 1前，后续真实切镜才带3/5/8秒格式时间。三处切点形成四镜头，不把三次喜剧反应误写成三镜。
8. **核对声场与验收证据**：沿用原案时保留厨房环境/烹饪声，禁止对白、唱歌和旁白，配乐字段用N/A；这不属于整段无声。静态记录只能核对时间与状态文本，二维保真、接触和真实笑点切点须生成后检查。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **SK-01**：仅角色保持二维贴纸媒介；厨房、蒸汽、盐、锅和真人手保持实拍，不把角色图的画风扩散到全景。
- **SK-02**：恒定身份与允许的暂时卡通表情/形变分开；鼓嘴、肿包、X眼和星星不构成整体三维化或新主体。
- **SK-03**：倒盐所用罐口全程无遮挡，盐从实际开口流进锅；封盖禁令补充正向几何，不替代可见动作路径。
- **SK-04**：人手不碰罐只约束Shot 1倒盐阶段；Shot 2夺罐必须有明确许可和所有权转移，不能互相冲突。
- **SK-05**：原10秒结构为四镜头、三切点3/5/8秒；每镜头动作有可读时间，毫秒记法不是实测时间准确性保证。
- **SK-06**：先倒入盐再喂同锅食物；同一锅铲和真实人手各司其职，接罐后的放置与再操作必须连续。
- **SK-07**：瞬间僵住、刚性姿态微颤、随后跌落和最终保持构图分别定时，不能用全片冻结禁掉后续反应。
- **SK-08**：环境声存在时overall_soundscape写厨房声，只有配乐缺席时non_diegetic_music为N/A；不得把无对白/无音乐误作绝对静音。
- **SK-09**：媒介纳入身份、封盖否定清单属于案例方法；不声称身份指令必然优于风格指令，或一次样本证明所有混合媒介有效。

## 输出与检查

- **媒介与角色职责表**：二维/实拍归属、固定身份、允许变化、每阶段行动者及禁止行为的作用域。
- **道具状态和所有权表**：盐罐开口、位置、持有人、盐流；锅铲在翻炒/轻敲/舀食/送入口各阶段的连续状态。
- **因果分镜与内部时间预算**：真实Shot数量、切点、动作窗口、接触先后和最终保持范围；标明原参数与新增调度。
- **英文H3提示词及验收清单**：官方模式字段、明确图片权限、声场策略，附逐镜二维外观、道具交接、动作路径和切点验证项目。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
