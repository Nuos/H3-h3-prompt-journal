## 方法来源与适用范围

把二维角色、真实物件和真人动作分成清楚的媒介与权限层，再以带时间的道具交接和可见因果组织笑点，防止角色立体化、动作抢占或道具状态自相矛盾。

本方法由原案例文本、逐案评估和 H3 官方协议共同整理。原案经验、评估发现与本次补齐的数据/检查接口须分别表述；案例作者的成功报告不等于本次实测。原稿快照保留原貌，冲突由本文件及技能入口裁决。

- 原案是10秒、9:16、第一人称厨房喜剧；四镜头包含三次后续笑点，不把README的three-beat误译成三镜头。
- 给道具加持有人/放置位置、给首镜分配内部时间和区分冻结范围，都是本次为修复原案缺口作的工程补齐。
- 作者关于身份锁较强、否定清单消除先验的解释不属于官方模型机制保证；本次没有观看或生成结果媒体。
- 示例中的轻敲、X眼和白色灵魂为卡通喜剧表达；动作主体、媒介和接触仍需在实际生成后验收。

## 条件分支与冲突处理

| 条件 | 执行动作 | 案例/评估依据 |
|---|---|---|
| 要求角色永远不变，又要嘴鼓起/眼睛变X | 保持配色、轮廓语言、服装和二维媒介，明确许可局部暂时动画变形及恢复/终态；不以不可变身份把表演全部禁止。 | prompt.md:21-31,71-99；review:34 |
| 全片人手不碰盐罐，同时要3秒夺罐 | 指出冲突，缩小前条至0–3秒倒盐阶段并在3秒后转移持有人；保留两段叙事目标。 | review:38 |
| 首3秒动作无法清楚辨认 | 先分取罐/举罐/倾倒/收势的内部窗口；若负荷仍过高，提供扩时或减少表情/装饰的方案，明确改变的是工程时序而非原稿事实。 | review:28,39 |
| 用户只要一个不切镜版本 | 保留四阶段因果链但改为同一Shot内动作时间，删除切镜锚点；原四镜结构是案例选择，不是H3硬限制。 | prompt.md:37-101；按当前任务迁移 |
| 结束hold但还要旋转星星与漂浮效果 | 把hold限定为摄影构图与倒地姿态，允许特效运动；若要字面静帧，则所有可见运动一起停止并另说明后期定格时长。 | prompt.md:95-101；工程消歧 |
| 缺少角色图 | 先交付职责/道具/时间表及带缺项标记的Ref草稿；未收到图不虚构已锁定的角色外观。若用户允许新设计，可独立选T2VA。 | README.md:5；official reference truthfulness |

## 失败表现与修复

| 失败表现 | 修复步骤 | 依据 |
|---|---|---|
| 贴纸变成圆润三维公仔或厨房变成卡通 | 把二维媒介限定到Subject，真实环境单独描述，保留角色外观同时允许仅二维表达的局部变形。 | README.md:21-35；review:16,34 |
| 盐穿过盖子或真人代替贴纸倒盐 | 明确无遮挡开口及可见盐流，逐时段写持有人和动作发起者；删除任何与开口冲突的封盖。 | prompt.md:45-55 |
| 3秒后真人手不敢接罐，故事卡住 | 将Shot 1人手不触罐限定为倒盐阶段，并写接罐瞬间、放置位置和后续空出的手。 | review:38 |
| 嘴里直接出现食物、敲头和落地没有原因 | 恢复舀食→移动→触口→吃下和僵住→颤动→倒下的可见路径，减少装饰动作给因果留时间。 | prompt.md:69-101 |
| 音轨完全静音，或把最后hold变成全画面长时间停住 | 分开无对白、无配乐、环境声，以及瞬间僵住、构图保持和后期静帧；按用户目标选择。 | prompt.md:85-109 |

## 迁移示例

**任务**

用一张二维贴纸图做10秒竖屏真实厨房喜剧：倒盐、3秒夺罐轻敲、5秒喂咸食、8秒夸张倒下；只要厨房声。

**预期处理示例**

参考图只定义Subject 1的身份与二维平面媒介。记录四Shot为[0,3)、[3,5)、[5,8)、[8,10)秒；按24FPS计划切点为72/120/192帧边界，这只是计划不是实测。新增首镜内部预算：0–0.5秒贴纸抓罐，0.5–1秒举起，1–2.5秒倾倒且盐流入锅，2.5–3秒回正并露出表情。人手不碰罐仅生效至3秒；3秒真人左手接罐并放到灶旁台面，右手保持同一锅铲，轻敲后返回锅内；5–8秒同一铲舀食、移到嘴前并由贴纸吃下。8秒瞬间僵住后短暂微颤、X眼、后倒，最后保持倒地构图，二维星星仍可转动，真人环境仍自然活动。角色平面性固定，但允许同一角色暂时鼓嘴与变眼形。输出Ref2VA六字段，声场为自然厨房/翻炒声，无对白和配乐，non_diegetic_music为N/A。未实际取得角色图或生成视频时，不报告媒介保真或切点准确性已通过。

示例是编排示范；其中任务给定参数和演算不代表当前已经读取了对应媒体，也不代表一次 H3 推理已完成。完整生成端交付仍需按输出模板选择正确字段和真实素材绑定。
