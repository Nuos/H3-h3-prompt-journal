## 2. 多维简评

**方法与输入输出。**以一张角色图生成10秒四镜头短片，六字段提示词已给出；关键可复用点是“哪些属性始终不变、哪些物理关系允许卡通化”。盐流必须从罐口进入锅中、真人手不代倒，构成具体因果和职责约束。[S3：21–55]

**动作与时间。**叙事顺序比孤立动作清单完整，关键笑点有时间锚。但0–3秒包含取罐、抬举、倾倒、倒完和表情变化，尚无内部时间分配；毫秒格式只是文字精度，没有给出实测切点误差或逐帧验收。[S3：37–101]

**验证及泛化。**README 有结果描述，目录未保存模型/参数及多样本结果表；本次不以其文字结果替代媒体核验。词汇增补已明确“穷尽否定”不是形式验证，说明材料有自我限定。可迁移到二维角色与实拍交互，不能未经测试泛化到任意媒介组合。[S1：80–89；S5：91、103–107]

## 3. skill 化判断与最小落地步骤

建议参数化角色媒介、真实环境、允许的夸张形变、道具开口/持有人、笑点事件及时间窗，输出“角色职责表＋道具状态表＋分镜提示词”。先检查身份属性与临时卡通表情的边界，再用倒盐、交接、喂食和跌落四种交互做回归。该流程属于建议，现有目录没有可执行 skill 包。[S3]

## 4. 主要缺口与优先级

- **P1：保留规则作用域。**“人手不碰盐罐”只适用于 Shot1 倒盐阶段，Shot2 必须接管；原文已分镜描述，封装时须把这一转移保留为带时间的权限，不能抄成全片禁令。[S3：53、59]
- **P1：明确镜头与时间验收。**补每镜头起止、动作最小可读时间与切点容差；检验二维外观、真实接触和盐罐状态是否贯穿。[S3]
- **P1：补对照证据。**以不同角色/道具验证“媒介纳入身份”的实际收益；词汇注释不得被误当成验证器或更多实验。[S5]
