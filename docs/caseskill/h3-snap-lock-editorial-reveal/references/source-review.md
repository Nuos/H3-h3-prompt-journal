## 2. 多维简评

**方法清楚但适用面较窄。** 两态相机及 5.30 秒事件表比“快速上摇后停住”更明确，适合离散快照式揭示。8fps 以上转折采样是作者的检查建议，并非保证捕获所有短事件的通用阈值；还应查看事件附近原始帧。[S1][S2]

**输入分工好，时序仍依赖具体素材。** 毫秒区间便于检查覆盖与冲突，但更换 Audio 1 后不能沿用这些固定触发点。“三次冲击”集中于 2.420–2.500 秒，必须先明确输出帧率和各冲击占帧，文本强调“可辨认”并不构成可辨认性证据。[S2]

**材料存在版本分歧。** 中文提示词没有保留英文完整毫秒事件表，改写为通用“Snap→Lock→Release”，并增加加速/减速和表演衔接指导；英文则强调 burst 即刻启停、无缓入缓出。中文文件适合学习，不能直接当成逐项等价执行稿。[S2][S3]

**复现与反推结论须分开。** README 的成片结果和“跑通提示词证明源片结构”均是作者论述；相似生成结果本身不能唯一确定源片的拍摄/剪辑机制。缺少音频事件标注、生成配置和多次结果记录，中文释义也不增加独立实验数量。[S1][S4]

## 3. skill 化判断与最小落地步骤

建议输入视觉参考、音频事件表、帧率和目标时长，输出统一的相机状态表：起止帧、构图、绝对 roll、运动类型及允许的人物微动。先检查状态互斥、时间覆盖、冲击帧预算，再生成提示词与逐事件验收表。此为建议的封装路线，当前案例未提供可执行编排与回归包。
