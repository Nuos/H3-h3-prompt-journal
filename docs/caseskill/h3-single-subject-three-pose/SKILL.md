# 单人三姿态锚点与近身连续飞行摄影

把姿态图作为连续动作的途经状态，分别规划人物状态和相机空间路线，处理参考属性冲突、运动阶段作用域和路径可读性，形成可审校的15秒连续镜头方案。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **同一人物的三姿态参考**：核对三图是否同一身份、服装和环境；逐图记录Pose 1/2/3的支撑、躯干朝向、四肢、头部。明确哪图主导身份/服装/场景及另两图的姿态权限；存在差异时不把三种外观同时声明为唯一真值。
- **允许移动空间与遮挡**：记录人物活动范围、衣摆与头发可能扫过的区域、背景障碍和可见间隙。未给空间尺寸时标记clearance为missing，以外轮廓绕行为保守路线，不声称已经计算真实净距。
- **时间、路线与速度偏好**：给出总时长、姿态到达时间、相机途经部位、机位高低和镜头运动强度。高速是本案例创作目标，必须与动作可辨认及路线可行性一起检查。
- **结尾构图与参考模式**：明确第三姿态最后露出哪些身体部位、保持多久，以及图片是身份/姿态参考还是强制首帧/末帧。用户要求精确末帧时确认有对应素材；缺少则输出目标构图而非伪造末帧。

## 执行流程

1. **建立单人三图属性权限表**：给三张图绑定同一主体ID和三个姿态ID，检查脸、发型、服装、身高比例与场景差异。为身份、服装、环境、姿态、初始机位分别指定来源；默认方案可建议图1主导身份和场景、图2/3提供姿态，但必须明确这是一项编排选择。若图像实际是不同人物，先解决身份冲突，不能声称原案允许自动融合。
2. **从三姿态推导连续人体动作**：描述Pose 1的支撑与重心，通过腿部重置、躯干旋转、肩臂移动和头部调整到Pose 2，再用相容的动作到Pose 3。把约5秒与9.5秒的锚点到达作为原案可调整时点；姿态经过时需可识别，不能用溶解、形变或瞬间替换，也不加入与姿态结构无关的舞蹈。
3. **划分人物动作和相机职责**：人物保持正常尺寸并自然完成动作；相机是不可见微小视点，视觉上的巨大人体来自近距离透视和视差。相机因腿、手臂、肩、头发进入路线而改变自己的位置，人物不为摄影机闪避。不要生成蜜蜂、无人机、可见相机，也不要让人物缩小、飞起或把整幅图缩放当作摄影移动。
4. **为每段写相机起点、路径与避让**：按脚踝外侧→小腿外侧弧→膝外侧→腰躯干→肩外侧→头侧→脸前三分之四→半身后撤建立连续路线。每段附相机开始/结束区域、朝向、可见部位、相邻段接点和一项主要避让；身体或衣料遮住窄缝时改为较宽外侧弧线。用明确起止方位或角度区间描述环绕，区分环绕角度与人脸三分之四视角，不把“近、快、敏捷”写成真实算法。
5. **把七阶段与独立终态对齐**：以15秒案例为初稿：0–2.5秒下半身起飞，2.5–5秒到Pose 2，5–7.5秒向上绕行，7.5–9.5秒到Pose 3，9.5–11.8秒上身/头侧弧，11.8–13.5秒脸部接近，13.5–14秒沿连续空间路径后撤，14–15秒半身保持。将“持续高速/不等待”仅施加于飞行阶段，最终保持是合法终态。转向和后撤时间不足时减少转折或提前减速，不同时宣称无限速度反转和自然动量。
6. **检查可见性、参考一致性和降级路线**：逐段确认人物关键姿态有足够露出以便识别，相机与身体运动不会让整段只剩遮挡或模糊；脸部接近不改变身份，不靠极端鱼眼制造体积。先保留两段姿态过渡与一个外侧路线，再逐步增加近身改向。若狭小场景没有通道，取消穿缝、扩大绕行或降低路径复杂度，记录未验证几何条件。
7. **生成正式正文与分层验收**：按 references/h3-official.md 的参考模式组织正文；15秒可作为生成片段，若用户要求更长故事则拆成4–15秒片段并记录人物姿态、相机位置/方向及参考交接。输出人物状态表、相机路径表、终帧条件和missing清单，用 scripts/audit_plan.py 做计划结构检查。原案无音频时间轴，无用户需要不强加BPM；实际姿态命中、穿模与终帧仍需生成后审片。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **P1**：三图指向同一人物的三个姿态，姿态是连续经过的锚点，不是三个身份或静态轮播画面。
- **P2**：人物正常运动且保持正常尺寸；相机负责绕行避让，微小视点只体现为透视、视差和空间移动。
- **P3**：每个中间动作必须自然导向下一参考姿态；人物动作和相机路径分别描述且时序对应。
- **P4**：近身路线绕过身体、衣料和头发；没有可确认间隙时使用外侧弧线，不以不可见相机为由穿模。
- **P5**：持续高速及不冻结仅适用于飞行段，末尾14–15秒半身保持是独立终态。
- **P6**：参考图不一致时先定义身份、服装、场景和姿态的属性优先级，不同时锁定冲突属性。
- **P7**：靠近与后撤是相机空间位移，保持透视和前后景视差，数字缩放不能代替。
- **P8**：提示词中的预判和避障是创作行为规范，未提供碰撞求解、净距计算或生成稳定性保证。

## 输出与检查

- **三图参考权限与姿态表**：主体ID、Pose 1/2/3、身份/服装/场景来源、支撑与四肢/头部配置、冲突和missing。
- **人物—相机并行时间表**：每段人物起末状态、身体中间动作、相机路径、可见部位、避让原因和相邻段接点。
- **H3正文与终态**：连续近身摄影描述、参考绑定、飞行规则作用域、空间后撤和第三姿态半身保持。
- **降级与验收清单**：姿态命中、人物身份、连续路径、穿模、可见性及终帧；给窄缝外绕和少转折版本，区分文本检查与实际审片。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
