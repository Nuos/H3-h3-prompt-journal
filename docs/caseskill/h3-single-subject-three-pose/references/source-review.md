# 单人三姿态近身飞行：案例简评

## 核心结论

本例可提炼为**多姿态锚点与连续近身摄影路径协同**的专项原型：人物保持正常尺度，摄影机以微小视点穿行，三张参考姿态作为途经状态。方法具备时间分段和避障描述，但未形成可执行几何约束、参考冲突处理和稳定性验证。[S1][S3][S5]

## 1. 模块构成

| 功能模块 | 作用 |
|---|---|
| 单人多图锚定 | 同一人物的三种姿态作为连续表演途经点，避免三人或轮播图解释。 |
| 相机与人物双线运动 | 隐形微小视点高速近身穿行；人物持续作细微、自然的展示动作。 |
| 七阶段时间线 | 15秒内从腿脚起飞，经三个姿态、上身和面部，最后拉回半身展示。 |
| 空间与运动约束 | 以绕开肢体、利用空隙和连续改向表达避障，排除穿模与瞬移。 |
| 译注与概念澄清 | 中英文说明、提示词和词汇表解释视点尺度、路径与表演的区别。 |

## 2. 多维简评

**方法论与输入输出。** 输入不是三段孤立姿势，而是同一人物的状态序列；输出为连续镜头。阶段时间、路径和主体活动密度均已展开，因此具备模板结构。三张图若身份、服装或环境不一致，文本未给明确的属性优先级或拒绝条件。[S1][S3：1—44、235—581行]

**动作与镜头。** 相机主动穿行，人物负责自然调整，避免将镜头运动误写成人物缩小或飞翔。人物动作密度与高速相机同时存在，文本通过躲避说明减小冲突，但“避开”仍是生成描述，并无距离、碰撞体积或路径求解器。[S3：130—233、641—704行；S5：105—107行]

**验证与泛化。** 适合单人时装展示、多姿态串联；对多人、狭窄环境或强遮挡尚无证据。作者结果总结不能替代多次运行记录；中文版本与词汇说明属于同一方案的解释资料。该例没有音频时间轴，封装时可保留为纯动作／镜头模块，无须强加音乐卡点。

## 3. Skill 化判断与最小落地步骤

建议输入统一身份的姿态序列、允许移动区域、镜头途经点、节段时长与结尾构图，输出相机路径表、人物状态表和提示词。先检查参考一致性与各阶段可见部位，再限制单次路径复杂度；验证姿态到达、连续性、穿模和终帧，不把文字物理约束视作真实模拟器。

## 4. 主要缺口与优先级

1. **P1：保留规则作用域。** 避障段写“Never stop”，终段明确14—15秒保持构图；封装时应把持续高速限定在飞行阶段，将末尾停稳设为独立终态，避免提取公共规则时丢失上下文。[S3：229、577—579行]
2. **P1：补参考与空间契约。** 确定哪张图主导身份／场景，并把路径中的“近”“快”“窄空隙”转为可调范围或保守替代路线，降低不同服装和姿态下的碰撞风险。
3. **P1：补复现记录。** 当前缺模型版本、运行参数和跨姿态组合回归。先测试少量转场，再叠加高速近身路径，以定位人物动作与镜头路径各自的失败来源。
