## 方法来源与适用范围

把“快者连续做、慢者观察后再做”变成有身份、起止、计数窗口和可见判据的双主体关系，使异速效果可以被计划和复核。

本方法由原案例文本、逐案评估和 H3 官方协议共同整理。原案经验、评估发现与本次补齐的数据/检查接口须分别表述；案例作者的成功报告不等于本次实测。原稿快照保留原貌，冲突由本文件及技能入口裁决。

- 原案3∶1、双人、蝴蝶步、近景环绕、纯器乐属于本案例的组合，不是全部H3任务默认配置；本技能保留其关系机制并允许用户替换。
- 动作事件表、窗口边界归属及观察前导是本次为补齐评估缺口加入的工程接口，原案例没有可执行调度器。
- 数学排程能证明计划中的次数关系；实际生成可能遮挡、跳步或同步化，仍需媒体验收。
- 一张图可以提供两个内容主体；从图中提取身份不自动复制其构图、姿势或屏幕左右位置。

## 条件分支与冲突处理

| 条件 | 执行动作 | 案例/评估依据 |
|---|---|---|
| 用户只说快者三倍，未定义动作 | 先选一个有可见起止的完整循环并标为编排假设；列出完成数窗口和执行时长，必要时让用户修改这些创作参数。 | review:30,37,43 |
| 要求先看再模仿，同时要求全片每一瞬间均为精确3∶1 | 分别处理观察前导与计数区间；解释首次完成前的比值无定义，用明确窗口验收。如果用户坚持从首帧计数，需要指定已在进行中的动作初态和窗口，而不能用计数表掩盖矛盾。 | review:31,37-39 |
| 只有腰上构图，但要求验证完整交叉脚步次数 | 保留镜头要求，改为可见的完整上身/髋部循环只在用户允许时使用；否则提出扩大景别或更换判据的具体冲突选项，完成其余计划。 | review:32,44 |
| 源人物图的姿势不适合连续异速开场 | 将图片限定为身份服装来源；精确首帧用途另行提供，不继承不适用站姿。 | prompt.md:3-10；official Ref2VA reference roles |
| 用户要整段音乐精确原样复用，又要求叠加新脚步声 | 若完整最终音轨保持不变则fully_copy且不追加；若保留音乐加新声则使用相应部分复用关系并说明音频层。 | prompt.md:151-171；official audio retention rules |

## 失败表现与修复

| 失败表现 | 修复步骤 | 依据 |
|---|---|---|
| 只写三倍速度，两人仍同步动作 | 把相同循环的独立起止、观察延迟和完成数窗口显式展开，不只重复速度形容词。 | README.md:12-26；review:37 |
| 慢者晚起步，却随后以相同速度追上 | 给出慢者更长执行时长并禁止为合拍而压缩后续单元；保留必要的自然动作加减速。 | prompt.md:20-41,76-100 |
| 近景看不到脚，却把步数填成已验证 | 改用画面内判据或经任务允许扩大景别，实际媒体缺失时计数结果保持待验证。 | review:32,44 |
| 环绕后把画面右侧人物误换成慢者 | 把Subject与服装/外观绑定，初始左右不作为永久屏幕槽位。 | prompt.md:3-10,120-148 |
| 开头或窗口边界出现2∶0、重复计数却仍报3∶1 | 明确前导是否计数及事件完成归属，逐个列出边界事件；没有慢者完成时不计算有限比值。 | review:37-43；工程补齐 |

## 迁移示例

**任务**

设计12秒双人异速近景，一张图含两个角色，先有3秒观察前导，再以可见的手臂开合循环比较3∶1；连续近距离环绕，纯器乐。

**预期处理示例**

定义快者Subject 1、慢者Subject 2，两者同源Picture 1但身份独立。一个循环从双手靠近胸前开始，向外打开再回到同一胸前位置才算完成；肩臂全程入画。0–3秒快者示范两个1.5秒循环，慢者观察，前导不计入比例。3–12秒快者每1.5秒完成一次（4.5/6/7.5/9/10.5/12秒，共6次）；慢者每4.5秒完成一次（7.5/12秒，共2次）。两个4.5秒统计窗各为3次对1次，共同边界完成事件记入前窗一次。慢者3秒起模仿已经看过的同一循环，两个循环之间不加速追赶。整段一个连续Shot，近景绕行不新增切镜；音乐纯器乐。上述时长和计数是本任务的新增调度方案，不是原案已有参数；未提供可核验素材时身份与音乐资产保持待提供，未生成视频前不报告真实比例通过。

示例是编排示范；其中任务给定参数和演算不代表当前已经读取了对应媒体，也不代表一次 H3 推理已完成。完整生成端交付仍需按输出模板选择正确字段和真实素材绑定。
