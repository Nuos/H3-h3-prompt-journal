# 双人异速舞蹈：案例简评

## 核心结论

**可提炼为“双主体相对动作进度”的规则模块。**案例把“快与慢”展开成动作计数、连续性和观察后模仿三层约束，有明确的复用价值；但“一个动作”的边界和统计窗口尚未定义，不能把 3∶1 的文字要求当成已验证的稳定控制能力。[S1][S3][S4]

## 2. 多维简评

| 维度 | 判断 |

## 3. skill 化判断与最小落地步骤

适合作为多主体编排器中的异速预设。建议先把动作拆成有开始、完成条件的编号事件，再定义观察者延迟、两人各自事件时长、统计窗口与比例容差；输出配对事件表和提示词。动作计数必须选择画面内可见的依据，或允许短暂更宽构图。[S3]

本例的 3∶1 是动作完成数关系，不直接等于每个身体部位的瞬时速度比。至少验证不同动作和比例后，才能提升为可独立调用的子技能；当前更适合 S1 规则素材。

## 4. 主要缺口与优先级

1. **P0：定义计数单位。**“三个动作对一个动作”缺少动作起止、循环边界及测量窗口；否则无法判断模型是否满足比例。[S3：44—74]
2. **P1：让镜头支持验收。**明确以可见的膝、髋、躯干事件计数，或补充允许脚部入画的镜头例外，解决动作判据与景别的脱节。[S3：103—148]
3. **P1：约束经验结论。**README 关于模型不能回避比例的表达，应按作者解释理解；补充实际计数和失败样本后再谈稳定性。词汇文件已有相关边界提醒。[S1：20—24、64—68；S4：47—56、107—109]
