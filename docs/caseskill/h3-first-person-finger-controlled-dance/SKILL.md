# 第一人称手势命令与舞者身体同拍响应

把前景手与舞者之间的控制关系写成可检查的命令—身体事件表，同时修复原案十条命令与结尾三条的歧义、镜头几何冲突和“立即响应”缺少容差的问题。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **视觉参考与构图优先级**：获取舞者、环境、光线及初始机位参考；记录能否看清前景手和全身、是否确有天花板。只有静态图时不声称已获原音、动作或空间声学测量。
- **命令序列与收尾策略**：提供最终有序方向列表，显式选择结尾三连是追加、替换末三条还是取消。输入含十条主体加结尾三条却未说明时，将歧义列为missing并给两种时长方案，不自行宣称原案一定是十或十三条。
- **音轨、拍点和容差**：提供实际音轨/拍点或用户指定的BPM、起拍偏移、总时长与允许响应帧差。未提供音轨时先写提议节奏，标记audio/onsets为missing，不用参考图推导音乐。
- **舞种与动作幅度**：指定可替换的舞种、UP/DOWN的身体高度变化及左右重心/躯干/髋部可见位移；装饰动作必须服从方向映射。

## 执行流程

1. **建立两主体关系与参考权限**：将前景操作者的连续前臂—腕—掌—食指记为控制主体H，将舞者记为响应主体S。参考图按实际内容约束人物、房间、光线和初始构图；明确H发出可见动作信号、S根据当前命令响应，这是预先生成的视频编排，不是运行时输入系统。
2. **固定屏幕坐标和四向身体定义**：UP是舞者通过躯干伸展和重心上移提高身体高度；DOWN是屈膝降髋，不是相机下降。LEFT/RIGHT以画面左右为准，要求重心、躯干、髋部整体向同侧移动；面对镜头时不改成人物解剖学左右。用可见整体位移排除只有髋部小抽动的替代动作。
3. **将命令与结尾合并为唯一列表**：先消解十条主体命令和LEFT→RIGHT→UP结尾的追加/替换关系，再生成单一带编号的序列。每条含direction、gesture_start、body_start_target、completion_condition、允许帧差和下一条前的身体状态。不得同时保留两个相互冲突的总数，也不得添加与命令无关的旋转、走动或自由舞步。
4. **建立音乐时间轴和可验收同步**：优先使用实际音头；只有BPM时按用户指定节拍和偏移提出时间网格，并标明不是实测音头。将手势开始与身体响应开始绑定同一时刻，动作在当前命令窗口完成；容差作为用户或方案约定，不冒充H3性能。缺音轨/起拍时先输出未绑定表，不编造。若超过15秒，按完整命令边界分4–15秒生成片段并保存末态。
5. **核对高机位、前景面积和全身几何**：针对实际图片检查明显俯视、天花板、近距离和全身入画能否共存。案例手占10–18%是画面面积，人物70–80%是画面高度，1.0–1.2米是该构图设想；分别记录，不能混量或作为所有任务固定值。出现冲突时保留控制手可见、脸躯干不被挡及完整必要身体部位，提出调整机位/视场/距离或天花板要求的明确选择。
6. **加入服从控制的舞种和稳定收尾**：只在对应方向动作内部加入肩部、腰部、表情和自然发丝变化，不让装饰编舞抢拍或改变方向。保持右下手部活动区域及连续手臂结构，使用轻微手持感但不通过拉远解决构图。最终命令UP完成后进入明确保持时段，手仍在边角，禁止结尾又启动新命令。
7. **输出正文与逐命令检查清单**：按 references/h3-official.md 的适用字段组织提示词、场景声和音乐；声场写作可合理设计但不能“继承静态图的原音”。用 scripts/audit_plan.py 检查计划字段，再逐条列出方向错误、提前/延迟、位移不足、手遮挡、人物出框和结尾总数错误的审片标准。所有同步结果需实际视频帧测量。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **F1**：手是可见动作提示，舞者身体响应当前手势；两个主体的关系必须明确写出。
- **F2**：LEFT/RIGHT统一采用屏幕坐标；UP/DOWN改变舞者重心高度，不能用相机运动或比例拉伸替代。
- **F3**：左右响应包含清楚的重心、躯干和髋部整体位移，单独细小摆髋不算完成命令。
- **F4**：先确定结尾三连是追加还是替换，生成唯一编号总序列再绑定拍点。
- **F5**：同步是同一命令窗口内的起始与完成关系；明确拍点、允许帧差及无提前响应，不能用“同拍”代替验收。
- **F6**：前景手保持连续人体结构与不遮脸躯干；画面面积、人物高度和物理距离分别检查，不能相互替代。
- **F7**：强俯视、大量天花板、近距离和全身占比需结合实际参考图验证，有冲突时显式调整而非叠加保证。
- **F8**：舞种可替换，装饰动作服从命令映射；一手一舞者属于本案例构图，不是模型人数限制。

## 输出与检查

- **参考与构图表**：操作者手、舞者、屏幕坐标、图像权限、手面积与人物高度度量、几何冲突和missing列表。
- **唯一命令时间表**：命令编号、方向、手势起点、身体起点、完成条件、容差、结尾策略与总条数。
- **H3提示词与音频条件**：参考绑定、连续机位、方向响应、服从控制的舞种、末姿保持及声场/音乐方案。
- **审片清单**：按每条命令记录实际起始帧、方向、位移、遮挡、出框和通过/修订；不声称已自动完成视频检测。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
