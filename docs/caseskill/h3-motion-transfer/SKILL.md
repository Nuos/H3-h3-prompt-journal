# H3 人物优先的多参考动作重建

把人物/世界锚、非外观运动提取、目标音频重定时和工作流预检组成可复用流程；将自然语言编排顺序、真实节点运行和生成后视觉验收明确分开。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **图像人物与世界参考**：给出Picture1实际文件、用途与可用地面/空间；该案例默认图1同时拥有身份、衣着、环境和光线。若用户分开人物与场景资产，先显式改参考职责表。
- **动作参考视频**：给出Video1文件和截取时窗，提取首帧机位/身体朝向与后续准备—发起—展开—重音—恢复。源人物、服装、背景、灯光不作为输出外观。
- **目标音频与时间证据**：给出Audio1文件、目标窗口及实测节拍/乐句表；没有测量资料时标missing，不填写虚构BPM或宣称重定时已完成。
- **运行能力和工程资产**：若请求执行，提供实际H3模式、模型/编码器/VAE、节点版本、GPU资源、workflow、目标fps和规格。若只写提示词，运行字段标未执行，不要求安装或下载模型。
- **续接参数**：仅续段需要上一段视频、接续帧范围、噪声策略、目标裁剪点及音频裁剪点；帧和秒要有同一fps/时间原点。

## 执行流程

1. **建立互斥参考职责表**：分配图像→人物、衣着、世界，视频首帧→机位几何和开场身体机制，视频后续→动作和相机行为，目标音频→时序。对每个作用域写允许继承和禁止泄漏项；参考未见时保留missing而非凭案例素材补齐。
2. **先做可行性与能力预检**：比较图1支撑面、人物体型/衣服活动范围、可用行进和运镜通道与源动作需求。按实际部署限制决定时长/分段，8–9秒只保留源配置经验；无能力资料时不承诺更长或更短的通用硬上限。
3. **构造开场几何与身体状态**：从Video1首帧仅提取身体朝向、承重、肢体配置、景别、相对距离/高度、画面占比和边距；先在图1世界中定义目标人物，再安排相机和开场姿态。该顺序是编排约束，不宣称模型内部按多阶段生成。
4. **提取并重组动作机制**：按准备、发起、加速、展开、重音、恢复、过渡列出承重脚、骨盆/躯干、手臂路线与速度变化；另列摄影机轨。保留机制和因果链，避免逐帧外观复制或动作间重置站姿。
5. **映射目标音频时间**：把动作峰、恢复和转场映射到已有目标音频节奏证据；不整体加速/减速源视频来冒充重建。先检查身体在给定时间内能否完成，必要时减少动作或按乐句拆段，记录新旧动作事件映射。
6. **可选审计工作流有效参数**：若交付ComfyUI配置，沿连线读取活动分支，区分widget旧值与实际输入，核查节点mode、模型实际选择名、端口语义和资源存在性。案例Duration9经节点131表达式得226帧，按24fps计约9.417秒，不是124帧；宽高由115选择器控制，0.4MP/16:9的内置表为864×480，最终尺寸仍需实际节点验证。
7. **可选统一音频和续接裁剪**：核查155音频节点mode=4，首段136接ref_video_audios而续段191接ref_audios，不能仅凭Audio1文字假定独立音频已生效。续接说明22帧、213视频裁剪26帧和212音频1秒不一致，先以同一时间点统一视频/音频裁剪，再进行声画同步验证。
8. **区分提交前与生成后验收**：提交前检查职责、缺失输入、动作时间表、可行性及有效配置；生成后才检查每帧人物/环境、首帧几何、源人物/场景是否泄漏、运动机制、音频时序及相机是否存在于新世界。无生成结果时后验全部记未执行，输出完整提示词与预检问题，不虚报通过。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **MTR01**：参考按身份/世界、运动/相机、时序分权；Video1人物不作为第二个输出主体。
- **MTR02**：首帧只继承相机几何和开场身体机制，不继承源外观、服装、背景或照明。
- **MTR03**：人物优先重建是提示词组织顺序，不是已证实的模型内部计算顺序或独立运行阶段。
- **MTR04**：目标音频重定时必须基于提供的BPM/事件/乐句证据；整段变速源片不等价于动作机制重建。
- **MTR05**：8–9秒仅属案例经验；可用时长以当前模式和真实部署能力为准。
- **MTR06**：工作流参数优先沿连线求有效值，不能将1344×768和124帧旧widget直接报告为实际输出。
- **MTR07**：必须验证活动音频节点和ref_video_audios/ref_audios端口职责，不能仅写Audio1就认为音频已输入模型。
- **MTR08**：续接视频/音频裁剪必须共享时间原点；22帧、26帧、1秒不能不加解释地混用。
- **MTR09**：预检不能确认未生成的视频每帧身份；八项视觉/时序核对应在有输出后执行。
- **MTR10**：新世界的支撑面和机位通道必须能容纳源动作，不能仅换场景文字而忽略足部接触与运动空间。

## 输出与检查

- **参考权限与素材清单**：每个资产的文件/缺失状态、角色、允许继承、拒绝继承、实际输入端口与作用时窗。
- **动作和相机重建表**：源事件、首帧身体/几何、目标人物机制、新世界可行性、目标时点及节奏证据。
- **完整H3迁移提示词**：人物与世界约束、开场构图、动作链、相机路线、音频职责和明确边界；不用源片人物外观填空。
- **工作流预检摘要（可选）**：活动/旁路节点、实际权重与依赖、有效参数来源、帧数/时长换算、分辨率、音频端口、裁剪一致性、阻塞项。
- **前后两阶段验收表**：提交前静态检查与生成后八项结果检查分列，附素材/配置哈希、种子、失败类型和重试记录；未运行明确写未执行。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
