# 三人物遮挡接力、独立环绕与近距离群像长镜头

将“从一个人转到另一个人”变成可以核对的参考职责、角色可见性、摄影机路径和遮挡条件，保留三位人物各自的摄影待遇，同时解决原稿对完整环绕、时长、空间与末尾停止状态的竞争要求。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **三个身份槽位与图片**：把实际文件分别绑定到Person 1、Person 2、Person 3，记录各自可见的身份、发型、服装与体型依据；确认它们确实表示三个不同人物。没有图像时使用明确待绑定槽位，不编造人物性别、脸部、服装细节，也不把三张同一人的照片自动当成三位人物。
- **主环境和空间资料**：指定唯一主环境来源，登记可见地面、固定锚点、墙面家具、光照、反光面、可用机位空间及未知区域；如有平面图、尺寸或预演，记录其来源。单张图提供视觉依据，不自动提供已校准的完整三维坐标。
- **时长与环绕验收**：指定总长、画幅、每人必须经过的水平视角与垂直取景范围，区分多视角环绕弧和真正360度方位覆盖；明确单次生成一镜到底是否硬性要求，以及是否接受较短改编或经披露的隐藏接缝合成。
- **可见性与演员活动边界**：指定普通环绕只见当前人物、两次转接是否也禁止旧人物任何边缘与新人同框、最后群像何时开始；定义三人固定站位附近的微动作范围、各自独立动作和允许的接触／间距。
- **光学与声音**：提供已知视场／镜头、清晰可读需求、最终半身覆盖范围，以及静音、现场声或配乐要求；没有音频输入时不凭fashion-MV标签捏造原曲、BPM或音频复用。

## 执行流程

1. **固定身份槽位与参考权限**：建立不可随出场次序重编号的Person 1/2/3到实际图片映射，再对应三个可复用人物Subject；把主环境另建Subject，原案由Picture 1同时提供Person 1和环境，Picture 2/3只提供各自人物外观。完整写明后两张图的背景、原摄影机和源光影不导入主空间，人物需要按主空间照明合理融入，同时保持身份和服装。换环绕中心不换脸、不合并身份、不复制同一人；图片只作参考时不自动声明它是首帧。
2. **选定可验收的环绕定义与生成范围**：先选一套环绕合同：多视角弧线需显著改变相机水平位置，经过前侧、四分之三侧面、侧面与侧后方；真正360度则需在固定空间基准下围绕人物站位完成完整方位覆盖，不能用人物自转或垂直升降替代。原案正文支持前一种覆盖描述，README另称360度，执行稿不能同时沿用。未被用户固定时默认按正文制作明确标名的多视角弧线版；用户明确要360度则保留并重做空间／时间预算。原案20秒可保留为概念分镜，标准H3单次输出按已核验4–15秒范围另制候选；严格20秒单次一镜到底标为当前已核验范围不支持，不能悄悄剪接或缩时后称原要求已满足。
3. **联合检查站位、视场、路径与终帧**：以主环境固定锚点定义世界前／右／上，提出三人相近、互不接触、不重叠且非共线的候选站位；站位和动作活动范围从开场延续到群像。为相机每个关键位置记录高度、朝向、近身距离、可见身体范围、相邻人物的遮挡／出框原因、与身体和墙／家具的净空。把普通环绕、两次遮挡、最后仅短后拉容纳三人放在同一个布局里检查，并计入镜子、反光面、边缘肢体和独立微动作。缺图或尺寸时输出待预检方案，不宣称已求得可行几何；不能把已隐藏角色删除来回避遮挡，也不能用无依据的房间改造替代主环境。
4. **建立在场、可见与被揭示的状态表**：所有阶段present集合始终为三个身份；普通环绕的visible集合依次为{Person 1}、{Person 2}、{Person 3}，每人从一开始就占据自己的站位。分别列出两个转接窗口的旧遮挡者、新揭示者和允许可见部位。若用户坚持任何身体局部也不能双人同框，必须检查遮挡退出与新人显露是否真的不重叠；未证实时保留待核验，不能把看得到的旧人肩缘自动算作不存在。只有用户允许转接例外时，才允许短暂旧人遮挡边缘加新人；该例外不扩散到普通环绕。最后群像窗口允许Person 3→Person 3+2→三人全体，角色槽位和位置不变。
5. **设计三段独立环绕和两条连续接力路径**：按各人物分别写水平弧线和垂直路径：Person 1由脚升到头，Person 2由头降到脚，Person 3由脚升到脸并为最终构图完成必要的回向。完成条件先于新人物揭示，不能用正面上下扫描冒充环绕；公共“到头才完成”条款不得覆盖Person 2的向下路径。每个接缝保存相机位置、高度、观察方向、速度趋势与焦点，下一中心用连续曲线接入，不把“reset orbital center”解释成重置摄影机。第一接力可选Person 1已有肩／背／发缘等高位遮挡；第二接力相机已在低位，优先选实际存在的下腿／鞋或衣缘形成遮挡，不能瞬间跳到肩背后再回Person 3脚部。低位表面不足以遮挡时重做高度与转接预算，而非凭空添加长裙。
6. **建立唯一时间表并保留结尾预算**：将orbit、occlusion/reveal、final pull-back/settle分成互不重叠且总和等于总长的运动阶段，所有阶段仍在同一个Shot中。若整理原案20秒概念稿，采用其总节奏表作为唯一执行时钟：0–6.5第一环绕，6.5–7.5第一接力，7.5–13第二环绕，13–14第二接力，14–19第三环绕，19–20最后群像；同步修正Person 2/3的6.5/13.0章节起点，删去竞争的结尾约2秒陈述。若要求2秒群像就重新分配前段，不挤掉Person 3。先保留三人的角度覆盖与末尾窗口，再调整姿态细节和可读速度；如果预算仍不够，明确需要改变时长或环绕合同，不能让“完成优先”无限超时。
7. **安排独立模特微动作与真实光学变化**：三位人物分别安排换重、肩部、手腕或头部的微调，活动范围留在已规划站位附近；不集体同步、不为避开镜头而搬位、不主动挥身体制造转场。靠相机路径形成遮挡并检查人物活动后仍有净空。强调随位置变化的透视和近远层视差，快速近身段允许自然运动模糊和焦点变化，但需要识别脸时保留可读窗口，避免极端近脸透视把身份破坏。tiny camera描述视角感觉，不生成无人机、昆虫或摄影师道具。
8. **让短后拉成为可核对的最终空间揭示**：第三人完成约定弧线并到脸部后，安排有限的减速／转向区间，再短距离物理后拉；把原稿“立即反转动量”改成有连续速度变化的路径，不瞬时换向。固定现有站位、镜头和画幅后核对后拉能否依次纳入Person 2、Person 1，保持Person 3主要前景及三人头至腰／上躯干可读。不能用数字变焦、复制人物或偷偷移动站位补齐群像。末尾在近距离半身构图处稳定，明确这段停止相机是全局高速运动规则的终止例外；人物仍可有各自自然微动作。最终同框是画面目标，不是此前每时刻都保持同一三维场景的证据。
9. **编译单镜头Ref2VA并分层审计**：输出Ref2VA官方六字段：subject_definitions、summary、retention_analysis、detailed_description、overall_soundscape、non_diegetic_music。人物Subject和环境Subject权限闭环，summary按实际选择reference generation及确有音频时的音频类型；整体风格放在[Shot 1]之前，全部路径阶段留在[Shot 1]内部，不为换人物新增Shot。用英文正文和连续局部时点表达遮挡机制，合并重复负向清单，保留身份／环境／可见性／路径的关键禁项。用scripts/audit_plan.py进行其能力范围内的结构检查，另外列空间预检与实际视频待核验项。没有成片时不得报告环绕完成、零穿模、严格单人可见或20秒生成已经成功。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **OL01**：三个身份槽位各自绑定实际参考；Picture 1兼管主环境，Picture 2/3只管各自外观，角色顺序和环绕中心变化不重编号、不换身份。
- **OL02**：三人始终在场与当前可见谁分开；反射、剪影和局部肢体也属于可见内容，转接残留遮挡边缘的许可要显式定义。
- **OL03**：多视角环绕弧和完整360度采用不同验收，不能以垂直扫描、人物自转或前侧到后侧的片段冒充整圈。
- **OL04**：站位、相机路径、视场、身体活动净空和最终半身群像必须联合检查；单张环境图不等于已校准三维空间或已证明可行布局。
- **OL05**：换环绕中心保持摄影机轨迹连续；P1高位结束接P2头部，P2低位结束接P3脚部，遮挡表面必须符合当前高度与真实服装。
- **OL06**：转接单独占用时间，不与下一正式环绕重复计时；保存最终群像预算，完成优先不能变成无上限超时或牺牲第三人。
- **OL07**：人物在有限站位范围独立微动，摄影机绕开人体；近身视差和遮挡来自空间运动，不靠人物故意挡镜、原地摇摄或身份形变。
- **OL08**：结尾采用有减速转向窗口的短物理后拉，在近距离半身群像停止；停止相机不冻结三人，最终同框不证明全过程物理连续。
- **OL09**：原案20秒一镜到底保留为概念要求；已核验标准H3单次4–15秒，较短改编或多段拼接都必须明示对原要求的变更。
- **OL10**：Occlusion-Linked Orbital Long Take是案例方法名，不是H3接口参数；一个连续镜头只有一个Shot，译文与作者成功陈述不能当成新增实测结果。

## 输出与检查

- **身份与空间契约**：三个固定人物槽位到实际素材／Subject的映射、独立主环境Subject、参考权限、可见锚点和未知区域、站位与微动作范围。
- **环绕与显隐计划**：明确弧线或360度验收、三次水平／垂直路径、每阶段present与visible集合、转接例外许可、遮挡表面、接入机位和反射／净空待核验项。
- **唯一时间轴和最终群像方案**：每个环绕、转接、制动、后拉与稳定窗口，原案冲突修复、总长核算、三人相近摄影待遇、最终身体覆盖与现有站位的相容性。
- **单镜头Ref2VA与执行边界**：六字段英文提示词、一个Shot内连续阶段、实际声音策略、概念20秒与已核验范围内候选的明确标记；文本审计、待空间预检和待生成回归分别报告。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
