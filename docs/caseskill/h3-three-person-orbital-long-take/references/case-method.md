## 方法来源与适用范围

将“从一个人转到另一个人”变成可以核对的参考职责、角色可见性、摄影机路径和遮挡条件，保留三位人物各自的摄影待遇，同时解决原稿对完整环绕、时长、空间与末尾停止状态的竞争要求。

本方法由原案例文本、逐案评估和 H3 官方协议共同整理。原案经验、评估发现与本次补齐的数据/检查接口须分别表述；案例作者的成功报告不等于本次实测。原稿快照保留原貌，冲突由本文件及技能入口裁决。

- 此技能聚焦三人、同一主环境、两次遮挡接力和最终近群像原型。三人是该案例任务结构，不是H3通用人数上限；其他人数需要重新编排角色槽位、显隐与时间预算。
- 原始README、README中文、英文提示词、1599行逐段译注、50项词汇增补及review均全文读取；翻译中的三分之四应改为四分之三侧面，不把旧译视为额外生成实验。
- 默认多视角弧线、权威时间表、低位第二遮挡、有限制动转向及转接显隐合同属于明确的工程修订；它们不能被表述为原稿已经具备的参数或验证成果。
- 正文的Person 2/3新中心是构图与运动参照变化，空间路径保持连续；人脸身份、房间坐标和人物在场集合不因此重置。
- 完全360度、三人固定近邻、单人严格可见和短后拉群像是否共同可行取决于具体几何与视场。文本不足以直接判定必然可行或必然不可能，不能替代实际空间预检。
- 标准H3的4–15秒范围与原案20秒有实际差异；本技能允许完整20秒概念设计，但不声称无需另行验证即可单次执行。较短候选与有接缝合成都须保留变更记录。
- 原材料没有可供本次检查的图片、音频、视频、相机标定或重复生成记录；命名突破、训练语义被污染等是作者解释，不是已证实的模型机制、接口特性或效果统计。

## 失败表现与修复

| 失败表现 | 修复步骤 | 依据 |
|---|---|---|
| 第一人形变成第二人，或第三人使用第一人的脸和服装。 | 固定三个独立素材槽位与人物Subject，分别描述受参考约束的身份；揭示通过相机位置变化发生，不能把图片编号当时间上替换同一人物的帧。 | prompt.md:4–22,167–207,553–576 |
| 镜头到第二人时背景切成第二张参考图的房间，或人物保留不一致的源光影。 | 主环境单独定义且贯穿全片；Picture 2/3只作为人物外观来源，按主空间光源、地面、尺度与阴影重新整合角色，不复制其背景或源机位。 | prompt.md:28–94；vocabulary-expanded.zh-CN.md:7–23 |
| 运镜只从脚扫到头，却称完成360度；后两人只得到短暂露脸。 | 分别检查水平相机位置与垂直取景；选定弧线或360度标准，按同一覆盖标准为三人留预算，不让时间被第一人和过渡耗尽。 | prompt.md:275–330,1107–1126；review:38–39 |
| 其他人在背景、画缘或镜面中提前出现；转接时能看到旧人肩缘但仍声称严格单人。 | 逐阶段查允许可见集合和实际部位，把反射与身体局部计入；调整布局、视场或机位，或明确转接例外。未验证严格显隐就报告未验证，不删除隐藏人物来假装通过。 | prompt.md:100–138,1189–1207；vocabulary-expanded.zh-CN.md:25–41 |
| 遮挡后相机高度／朝向突变，P2脚部镜头突然跳到肩，再跳到P3脚。 | 接缝记录连续位置、观察方向、速度与焦点；选当前高度真实存在的遮挡表面，或给额外升降明确路径和时长。改变环绕中心不能重置摄影机。 | prompt.md:367–387,598–614,664–735 |
| 短后拉仍只有第三人，或一拉就成为远景全身群像。 | 把已有站位、画幅、视场和最终头至腰范围一起重新检查；调整获准的候选布局与路径，不靠数字变焦、人物瞬移或凭空生成补齐。终帧只说明画面结果，不证明整条空间已连续。 | prompt.md:780–925,1391；vocabulary-expanded.zh-CN.md:91–92；review:40 |
| 最终摄影机瞬时反向或一直后退，三个人又全部冻结成照片。 | 在最后阶段明确减速转向、有限后拉和停止时点；相机停止后人物保留各自微动作，不把全局高速和人物不冻结混写为同一个对象的命令。 | prompt.md:796–806,905–979 |
| 把20秒作者报告写成官方可执行参数，或把两段拼接包装为一次真实无切镜生成。 | 对照4–15秒标准范围，保留概念方案并标明改编或合成分支；没有运行或成片则只报告文本与计划层，不宣称已复现成功。 | README.md:61–70；review:30；references/h3-official.md |

## 迁移示例

**任务**

用三张不同模特图做15秒16:9时装长镜头，图1提供同一房间，其余只管人物。采用前侧到侧后方的多视角弧线，不要求360度。普通环绕只见一个人，转接允许旧人的不露脸身体边缘短暂掠过。三人原地微动，最后近距离半身同框，全程静音；站位可以设计，但尚无房间尺寸。

**预期处理示例**

固定Person 1/2/3分别绑定图1/2/3，另以图1绑定Environment Subject；图2/3背景和源灯光不导入。先给待实景预检的非共线近邻布局：Person 3在最终构图前方，Person 2在其后方一侧，Person 1在后方另一侧；具体间距由同一房间可用净空及最终视场确定，未提供尺寸就不填伪实测距离。唯一时间表为0–4秒Person 1脚至头的水平环绕弧，4–4.75秒以其已有肩缘绕出并接到Person 2头部；4.75–8.75秒Person 2头至脚弧线，8.75–9.5秒沿其实际下腿／鞋边的低位遮挡接到Person 3脚部；9.5–13.5秒Person 3脚至脸弧线，结束前完成有预算的回向。每个普通环绕仅相应一人可见；4–4.75和8.75–9.5秒只允许已授权的旧人边缘加新人，不把该例外扩散到其他阶段。13.5–13.8秒连续制动转向，13.8–14.6秒短后拉，依次揭示Person 2、Person 1，14.6–15秒稳定在三人头至腰的近群像，人物各自微动。Person 1调整承重，Person 2微调手腕，Person 3调整头部，不集体同步或为挡镜搬位。全部阶段留在[Shot 1]，summary为reference generation；没有Audio标签，因用户明确全程静音，两个声音字段均为N/A。这是可提交时长范围内的候选提示词计划；仍需核对低位表面是否足以遮挡、环绕中反射／意外露出、三人最终能否仅靠短后拉入框，不把未完成的几何预检写成已通过。

示例是编排示范；其中任务给定参数和演算不代表当前已经读取了对应媒体，也不代表一次 H3 推理已完成。完整生成端交付仍需按输出模板选择正确字段和真实素材绑定。
