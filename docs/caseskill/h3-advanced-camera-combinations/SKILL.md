# H3 动作触发的物理运镜组合编排

将案例的十个固定范例转为有场地前提、阶段语义和连续性验收的运镜选择流程，同时保留人物动作主导镜头响应的局部创作纪律。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **动作链与人物参考**：提供本段单一表演者、连续动作链及身份/服装参考职责。只有占位符时登记 missing，不声称已查看图像；姿势与相机不从身份照自动继承。
- **片段规格**：提供总时长、宽×高或明确宽高比、是否连续拍摄。原文“Vertical 4:3”有歧义，不能直接作为尺寸参数。
- **场地与摄影机条件**：提供可用前后侧向空间、地面状态、遮挡物、近景距离与身体动作幅度，判断绕侧、超越和贴地升起是否可行。
- **节奏证据**：接收已测 onset/重拍时间表或明确结构性时间安排。未提供音频测量时可编排时长预算，但须标为未核验音乐同步。

## 执行流程

1. **确认局部创作契约**：将单人、上半身优先和最多一两步位移作为本案例模板的默认边界记录。若用户任务是多人舞台大位移，交给相应编排流程，不将本库限制推广到全部 H3。明确输出按连续阶段还是实际硬切。
2. **按动作与空间选择组合**：根据任务选择：侧向连续上身动作优先01，主体真实前进可用02，近景收束用03，需看脚步用04/08，从屈膝升起用05，有真实遮挡用06/09，折返用07，先静后动用10。记录所需空间、可见性与遮挡条件，不满足则换组合或缩短路线。
3. **展开五要素与双轨表**：为每一阶段写出摄影机相对身体的起点、操作者实际行走/升降路径、具体人物触发事件、终点及最后构图；补镜头高度、距离与光轴目标。人物轨和相机轨使用同一时间域，动作峰与已知重拍对应。
4. **修复原范例冲突**：组合07以正文明确的背后起始为默认，改称背后跟随—停机—人物横越—转身重获；若用户要正面起始则重新算路线。组合10声明前置静态建立与微推进为例外；若要求全段由人物动作触发，删除预先微推进。将原 SHOT 标签改为连续阶段，除非用户明确要求剪辑。
5. **重定时而不伪造节拍**：用目标时长重新分配阶段，校验区间相接且总长精确覆盖。原11.5秒/11.2秒仅作示例。明确触发发生、相机启动、动作峰、相机到位和恢复节点；没有音频测量时不得声称峰值已与音乐精准1:1同步。
6. **补足遮挡和换侧的真实路线**：06必须在遮挡消失前到达合理新机位；09若要从一侧出现在对侧，写清经过身体前方或后方的路线和用时，空间不足改为同侧揭示。贴地镜头写出抬机过程，禁止只用镜头俯仰或数码缩放替代距离/高度变化。
7. **组装完整段落并验收**：将输入职责、局部公共规则、选定组合、时间表和段末动作钩子一并输出，不只截取组合正文。检查无未解释跳位、持续动作未被散步替代、相机锁定后不漂移，结尾身体/手臂方向能够承接下一镜。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **ACM01**：用起点—物理路径—主体触发—终点—最终构图展开运镜；术语可以保留为索引，执行正文不得只靠术语或角度数。
- **ACM02**：每次前后、升降、换侧均写实际位移及光轴目标，不用数字变焦或未描述的瞬移代替。
- **ACM03**：人物与相机共用时间轴；只有实际音频数据支持时才把时间点标为已核验重拍。
- **ACM04**：本库 SHOT 默认解释为同一镜头内的连续阶段；实际硬切需要显式另行声明。
- **ACM05**：组合07按正文采用背后起始，标题前方起始不再与正文混用。
- **ACM06**：组合10的静态建立和先行微推进必须标为局部例外；严格动作触发任务取消该预先移动。
- **ACM07**：单人、上半身优先、一两步位移是案例局部条件；不宣称去掉角度数字本身已被证明提高 H3 稳定性。
- **ACM08**：独立粘贴输出必须同时携带参考职责与所需公共规则，且用明确宽高比代替含混的“Vertical 4:3”。

## 输出与检查

- **运镜决策与前提表**：选用组合编号、适用动作、可用空间、遮挡条件、未满足条件和已采用的简化。
- **人物—摄影机连续阶段表**：start/end、人物起始与动作峰、相机起点/路线/光轴/到位、continuous_phase 或 hard_cut、音乐证据状态。
- **完整 H3 片段正文**：包含参考职责、场景、完整动作链、物理机位、同步关系和段末钩子，可单独阅读；审计说明放正文之外。
- **修复与待核验项**：记录07方位、10例外、宽高比、时长改动及未测音频/未提供资产，避免把工程修复冒充原文。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
