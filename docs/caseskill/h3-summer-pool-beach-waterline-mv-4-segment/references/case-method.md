## 方法来源与适用范围

建立人物参考与场景重建分权的多片段MV工作流，避免相机阶段变成多余切镜、服装和色调跨段漂移、道具接触脱节。

本方法由原案例文本、逐案评估和 H3 官方协议共同整理。原案经验、评估发现与本次补齐的数据/检查接口须分别表述；案例作者的成功报告不等于本次实测。原稿快照保留原貌，冲突由本文件及技能入口裁决。

- 55秒与四段是案例结构，迁移时保留方法并重新计算分段。
- 身份一致不代表图像中的姿势、场景和机位必须继承。
- 原案Part3缺retention_analysis、部分保留段使用newly_generated等自定义写法；迁移到官方六字段时应补齐合法标签关系。
- 四处硬切是段内统计，不含3个独立任务拼接边界。
- 机位和动作计划不保证像素级身份、准确到帧的切点或接触关系，实际结果必须检查。

## 失败表现与修复

| 失败表现 | 修复步骤 | 依据 |
|---|---|---|
| 8秒或水线5/10秒发生多余切镜 | 从Shot列表删掉阶段标记，把动作变化写在原Shot内，独立核对cut数量。 | README.md:78-107 |
| 地面相机跟着人物站起或生成画内手机 | 明确固定画外光学视点和站起出画，再按唯一硬切进入下一镜。 | prompt.md:194-202 |
| 身份保持但服装随机变化/换装被禁 | 把身份与衣物逐项分权，指定每个场景的许可，删除矛盾保留句。 | review:41 |
| 毛巾悬空仍在擦发，下一段座位和手位跳变 | 逐阶段写接触、释放和安置位置，用前段出口约束后段入口。 | prompt.md:146-152,196-206 |
| 水线消失或泡沫完全覆盖脸 | 保持相机相对水面高度、限制俯仰并保留自然前景缝隙，按可见性而非标签验收。 | prompt.md:252-266 |

## 迁移示例

**任务**

保留原四段结构但换成同一位男性人物，所有镜头衣服不变、统一冷中性，音轨1:1复用。第三段8秒和第四段5/10秒不要切镜。

**预期处理示例**

保留source窗口0–10、10–25、25–40、40–55；对应4段时长10/15/15/15秒。段内cut分别为[5]、[5,10]、[3]、[]，phase为Part3[8]、Part4[5,10]。段内8镜头4cut；三处段际硬切另列，最终共7cut。图1锁定该人物身份和指定衣物，删除原文白色罩衫适配权；湿发/湿衣只改变物理状态。Part2出口与Part3入口统一同一座位、双手毛巾位置与擦发方向；Part3地面相机在0–3秒固定，3秒cut后8秒仅转为后退跟拍。统一冷中性并删除暖金色强制句。音轨fully_copy，不添加新水声；水线泡沫作为前景而非人物附件。

示例是编排示范；其中任务给定参数和演算不代表当前已经读取了对应媒体，也不代表一次 H3 推理已完成。完整生成端交付仍需按输出模板选择正确字段和真实素材绑定。
