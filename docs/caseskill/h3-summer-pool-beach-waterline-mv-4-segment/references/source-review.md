## 2. 多维简评

**具有可迁移的组织方法，但仍以作品示范为主。** 身份保持与场景重建分权、将特殊视角写成物理几何、将镜头内阶段与切镜分别编码，均能迁移到其他人物 MV；尚未提供根据输入条件自动选择机位或调整动作难度的规则。[S1]

**时间与剪辑结构较明确。** Part 3 的 3 秒是真实切镜意图，8 秒仅是横移转后退跟拍；Part 4 的 5、10 秒仅为同一镜头阶段。八镜头、四处硬切统计是四个独立任务内部的统计；最终拼接时的段际边界仍须另设剪辑清单。[S1][S2]

**空间描述强于音乐分析。** 高位倾斜构图分解为机位、光轴、滚转和海岸线关系，水线段把泡沫作为前景而非人物附着物。这些可直接成为机位验收字段。音频则主要提供分段窗口与总体节奏，没有逐拍/重音事件表，因此不能把整数切点解读成已经测得的音乐卡点。[S2]

**稳定性边界写得相对诚实。** README 明确提示词不能保证脸部一致、逐帧切点或身体动作正确。正文有“exactly”一类生成目标，但这不改变其需输出验收的性质；本次未验证实际视频表现。[S1][S2]

## 3. skill 化判断与最小落地步骤

建议先抽取“身份权限表、场景表、镜头表、切点表、段际衔接表”，每个镜头仅引用适用的机位模板。将硬切、连续运动阶段、段际剪辑分别使用不同事件类型；编译前核对镜头数、时间覆盖、首尾动作与可见服装状态，输出每段自包含提示词及人工检查清单。再用身份图与场景变化较大的样本测试低机位、人像遮挡和水线保持。[S1][S2] 此为封装建议，当前未提供可执行编排器或回归记录。

## 4. 主要缺口与优先级

1. **P0｜统一全局色调。** README、prompt 总述要求冷中性低饱和；Part 1 却要求暖逆光、暖日照、金色反射，Part 2 也有暖日光。需要明确允许局部暖光还是整片统一冷调，再统一各段的实际生成文字。[S1，14 行；S2，3、30、44、58、70、152、188 行]
2. **P0｜明确服装权限。** Part 1 允许按场景适配服装，并指定白色罩衫；Part 2–4 多处要求保留原服装。身份一致与服装一致不是同一字段，应列出各镜头允许改变的项目。[S2，20–22、64、98–113、176、238 行]
3. **P1｜补全跨段及验证数据。** 将 Part 2 擦发结尾与 Part 3 开头坐姿、毛巾位置等状态写成对接表；给出模型版本、生成参数、实际切点偏差与失败修订记录。音效是否仅复用原音轨也应在四段统一。[S2，152、184–206、216、270 行]
