# 夏日人物MV：特殊机位与切镜事件分离

建立人物参考与场景重建分权的多片段MV工作流，避免相机阶段变成多余切镜、服装和色调跨段漂移、道具接触脱节。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **身份图与属性政策**：明确保留身份、发型、体型和哪些服装细节，列每场景允许改变的衣物/湿发状态，避免把身份一致等同服装绝不变化。
- **分段与音频窗口**：提供每段时长和源音频起止、使用方式、是否允许新增环境音；没有音乐分析时，镜头切点仅记为设计时间。
- **场景/机位/动作**：提供泳池、海滩、水线或其他场景及相机位置、光轴、滚转、移动路径；列人物支撑、水、毛巾、家具的接触关系。
- **风格与衔接优先级**：选定整片色调、局部暖光是否允许、段际采用硬切还是动作接力，以及前后场景和道具状态。

## 执行流程

1. **分开身份、服装与场景权限**：逐段重新列实际提交的同一身份图及其授权属性；场景/姿态/机位由文本重建。独立生成不依赖上一任务记忆；对换装和湿发逐镜列许可，消除原案第一段可适配服装而后三段完全保留的冲突。
2. **建立全曲与局部映射**：以source_start+local_time计算音乐位置，检查片段无空缺或重复。原案10+15+15+15秒可作为样例，不当默认总长；不要把5/10秒整数切点称为已经检测到的重音。
3. **建立三类事件清单**：区分片段内硬切cut、同镜头阶段phase、片段之间segment_boundary。只由cut增加镜头编号；原案Part3仅3秒硬切、8秒是phase，Part4的5/10秒均是phase。单独记录最终拼接的3个段际边界。
4. **编排身体支撑与道具状态**：写坐姿手掌/骨盆受力、跑步对侧摆臂、浮水的水面关系、擦发时手—毛巾连续接触，以及放毛巾/起身的先后。为Part2末尾到Part3入口定义同一座位、毛巾位置、手位、湿发与光向。
5. **按镜头选择可兼容的物理机位**：高位斜拍分别写高度、俯向光轴、整体滚转与海岸线方向；贴地POV明确光轴垂直向上、设备不可见及相机不随站起移动；水线镜头明确水上/水下分层、相机沿水面运动和泡沫前景。每镜采用一个主运动逻辑，转换时给连续路径。
6. **校准全局风格与局部效果**：依据用户选定政策统一冷中性或允许暖逆光的范围；不能在总述禁暖而正文要求金色暖日光。水线后段轻微俯仰只改变光轴，保持水线可见，不强求物理不可能的固定半幅分割。
7. **编译逐段官方Ref2VA**：用六字段、合法保留标记与标准Shot切点格式；把自定义final_visual_constraints融入适用正文或独立检查单，不增加伪官方字段。若完整音轨1:1复用就不同时新增环境声；允许混音时改为partially_copy并明示新增层。
8. **核对镜头数与可见结果**：检查时间覆盖、每段镜头数、真实cut列表、段际剪辑、服装/色彩政策、接触关系和身份可读性。原样结构应为8个段内镜头、4处段内硬切；若3处拼接均为硬切，成片共7处，必须分开统计。未生成时只报告计划校验。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **SM-01**：身份保留与服装保留独立定义，且每个独立生成任务重新绑定实际身份资产。
- **SM-02**：切镜、连续阶段和段际拼接分别登记；时间标记不自动意味着新增Shot。
- **SM-03**：音乐源时间与local时间明确换算；未给重音表时不把整数设计切点宣称为实测卡点。
- **SM-04**：特殊视点由相机位置/光轴/滚转和环境几何构成，人物身体保持正常重力关系。
- **SM-05**：固定贴地镜头在起身过程中保持原位；从该视点转到新场景须依设计cut完成，不能偷偷变成跟拍。
- **SM-06**：泡沫是镜头附近的前景层，水线为持续空间约束；泡沫不附着到脸上且不全程挡脸。
- **SM-07**：服装、冷暖色调与音频混音政策必须在四段一致或明确标注局部例外，不能互相冲突。
- **SM-08**：擦发、放毛巾、起身和跨段入口都要保持手—道具—身体接触与状态连续。

## 输出与检查

- **身份/服装/场景政策表**：每场景固定属性、允许变化、冷暖光规则、音频复制/混音规则。
- **分段镜头与事件表**：source/local时间、cut/phase/segment_boundary、镜头数、段际接力状态。
- **物理机位与接触关系表**：位置、高度、光轴、滚转、路径、预期可见几何和手/道具/水/座位状态。
- **逐段官方提示词与验收清单**：自包含Ref2VA正文和视频生成后需要检查的切点、身份、服装、色调、接触及水线。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
