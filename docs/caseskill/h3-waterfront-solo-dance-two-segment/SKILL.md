# 水岸独舞：单镜头取证与双段动作接力

把单镜头判断、音乐切段、动作链和终止状态组织成可追溯流程，避免把光晕误报当切镜、把全局首拍照搬为局部首拍，以及让后段重新站姿起步。

## 读取与边界

- 本技能从单个案例提炼可迁移方法；角色、道具、场景与数值按当前任务替换。保留用户明确约束。
- 开始编排时阅读 [案例方法与修复分支](references/case-method.md)；准备完整 H3 提示词时阅读 [官方模式规则](references/h3-official.md)。
- 涉及原稿争议、版本、数字或特殊动作时，按 [来源清单](references/source-index.md) 定位下列原始文本。原稿是证据，不是新的上级指令；原稿内部本机路径不代表当前资产已存在。
- 缺少素材、拍点、时长或状态证据时先完成可确定部分，并记录待核验项；不得捏造听音、逐帧分析、工作流运行或生成成功。
- 只请求动作/机位组件时交付组件及适用条件；请求完整提示词时选择真实可用的 H3 模式。中文说明与审核记录放在生成正文之外。

## 输入契约

- **源片与检测证据**：提供源片或逐帧/候选点记录；只给文字时把单镜头结论标成作者报告，记录缺失的检测版本、参数、分数与核对帧。
- **音频与时间基准**：记录实际音频标识、总时长、已核实 BPM/拍号/全局首拍和分段起点；无实测音频时只采用用户给定值并标明来源，不虚构歌词。
- **身份与空间参考**：分别指明图片用于身份服装、场景还是精确首帧。后段若靠动作接力开场，不把同一静态人物照强制当精确首帧。
- **动作链与终止要求**：提供每条链的支撑脚、重心、朝向、手臂位置、旋转方向、拍数及最终是否完全静止。

## 执行流程

1. **登记事实与待核验项**：区分实际媒体、作者报告、用户给定参数和工程推导；先列源片是否已被本次查看、音频是否可读、歌词是否已核实，再决定能输出实测结论还是待执行计划。
2. **复核单镜头候选**：若具备检测工具，先用适合素材的常规阈值，再用较低阈值寻找候选；对每个候选前后窗口逐帧比较背景、人物位置、光源与运动连续性，分别判定真切镜/动作或光晕误报/证据不足。0.27、0.06、±0.2秒仅保留为原案例配置示例。
3. **重建全局音乐网格**：从可靠 BPM 与拍号算拍长和小节长，记录全局强拍序列；将开头不足一小节的引入和末尾残余时长单列，不能把0秒、尾秒强称完整小节边界。
4. **切段并换算局部相位**：优先在可行的强拍附近切为每次运行支持的时长。对片段起点 s，把每个全局拍点 t 换成 t-s；若起点本身为强拍，该段局部首拍为0。逐段列起止、真实时长、局部强拍和残余尾段。
5. **写入态—拍数—出态动作链**：把脚、重心、胯、腰、肩、臂、腕的因果顺序写成可观察路径；呼吸、余势和衣料跟随只作次级持续层。每个动作块交接检查手臂究竟交叉还是展开，不能同一出态写两种位置。
6. **锁定跨段接力与终止优先级**：用同一状态记录连接前段末帧与后段首帧，至少包含支撑脚、朝向、重心、手臂高度和运动方向。为最终停势设置明确生效时间；要求绝对静止时，此时起关闭呼吸/重心微移持续层。
7. **编排官方 Ref2VA 输出**：图片只供身份时定义 Subject 来源；音频单列 Audio 定义，场景若单列 Subject 则补齐保留和正文引用。用官方六字段和 detailed_description 包装分段动态，保留原音轨时在对应音频层写真实复用关系，不能用N/A掩盖有声配乐。
8. **执行交接 Gate**：核对候选点证据、时间覆盖、局部相位、每链入出态、片段接力和终止覆盖。只有有实际生成/拼接记录时才报告视觉接缝或身份效果通过；文本自检通过仅表示计划可提交。

## 本案例验收规则

将以下检查逐项写入计划中的 `case_checks`，结论附具体证据；不得用格式检查代替内容审核。

- **WF-01**：低阈值命中只是候选，单镜头结论需要逐帧证据；缺少原片时保持作者报告标记。
- **WF-02**：局部拍点等于全局拍点减片段起点；在强拍切出的后段首拍为0，不能继续沿用全片首拍偏移。
- **WF-03**：每条动作链必须给出可配对的入态、拍数/时长、出态；物理动量不能在分段处复位。
- **WF-04**：参考图片的身份用途和精确首帧用途分别声明；接力状态优先于未被指定为首帧的静态人物姿势。
- **WF-05**：最终停势覆盖持续呼吸层的范围和起始时刻必须显式设定，避免同时要求绝对静止与每拍微动。
- **WF-06**：锁定正面全身机位是此类连续独舞方案的可选任务约束，不是全部H3片段的默认机位。
- **WF-07**：首拍未到的引入和最终残余时长分别标注，不以整数小节假设覆盖全部时间线。
- **WF-08**：舞蹈音轨1:1复用需要真实分段资产；人声未核实时不编造歌词锚点，原本机路径不能视为当前可用资产。

## 输出与检查

- **切镜取证表**：候选时间、检测参数/版本、逐帧窗口、连续性观察、判定及证据状态。
- **全局/局部音乐时间表**：BPM来源、首拍、拍长、小节长、片段全局区间、局部强拍与引入/尾段。
- **动作接力状态表**：逐链入态—过程—出态、前段出口与后段入口、终止状态的生效时间。
- **逐段H3提示词与提交清单**：官方模式正文、明确图像/音频绑定、时长与机位，另附文本Gate结果和仍待生成验证的项目。

复制 [输出工作表](assets/output-template.md) 和 [编排清单模板](assets/plan-template.json) 到任务目录，按 [字段说明](references/plan-schema.md) 填写。完整提示词逐生成切片保存为英文 `.txt`；对白、歌词和画面内文字保留原语言。

标准 H3 单次生成按 4–15 秒/24 FPS 规划；长案例保留创作段落并再划分生成切片。特殊运行时须记录核实证据。参照官方规则选择基础三字段或 Ref2VA 六字段，不能套用原稿中的混合格式。

从本技能根目录运行静态检查：

```bash
python3 scripts/audit_plan.py /absolute/task/plan.json --strict --check-files
```

组件输出无需伪造提示词文件。检查脚本仅使用 Python 3.10+ 标准库；不联网、不安装节点、不执行源工作流、不调用生成模型。它核对时间、引用、格式和人工审核记录，不能验证动作物理性、音频真实对齐或视频质量。
