# H3 场景空间、人物站位与交互调度

让每个空间判断回答：**谁在何处，朝向哪里，从哪里经哪里到哪里，与谁在何处发生什么空间关系，观众必须看清哪里，依据是什么。**

实现 M3 及 M3.1／M3.2／M3.3。输出 `SpatialPlan`，三个子模块只提交自己分区的提案，M3 父模块检查并唯一接受。当前用户要求和已确认约束优先；案例方法保留作用范围。兼容的用户资料或外部输入可直接使用，不要求先执行 M1、M2 或其他兄弟模块。

## 2. 建立输入与证据边界

先确定本次只处理哪个节点和哪些镜头／阶段，保留作品、请求、基版本及来源。由 Agent 将任务转为 `M3Request`，具体最小字段依合同指南；脚本不自动理解自然语言或读取媒体。

读取稳定实体、场景结构、段落目的、动作空间需求和摄影可见性条件中与本次任务相关的部分。已有合同兼容输入可以替代上游执行。身份和空间参考许可不足时交 M2 或调用者确认，不能从源图位置自动推定目标永久站位。

分开用户陈述、案例文字、设计假设和真实观察。尺寸、镜头视场或时间未知时保留缺项；不因为需要 JSON 数值就编造测量结果。常规且已授权的可逆设计选择自行完成并注明依据；只有影响当前结论的关键事实确实缺失时才询问。

## 3. 完成职责内编排

1. **M3.1 建立空间。** 明确世界方向、人物自身左右和屏幕方向的不同参照。登记场景锚点、区域、连通和不可穿越条件。没有摄影投影依据时不把世界向左写成画面向左。
2. **M3.2 安排站位与路线。** 用稳定实体 ID 表达起位、朝向、路径和终位；把队形名称展开为每个参与者的过程。记录出画后的世界去向、交叉对象和需交 M7 排时的占用条件。
3. **M3.3 指定互动与遮挡。** 写清参与者、交互区、接触／避让对象、允许或禁止的遮挡及关键可见结果。需要改站位时向 M3.2 提请求，不在自己分区另建竞争站位。
4. **M3 核对组合。** 对照原请求检查来源和只读输入保真，再审阅语义。以父接受路径组合相容提案，保留新版本、未决项和下游条件；拒绝过期、越权或相互矛盾的提案，不暗改专业决定。

不统一限制人数，不全面禁止过中线、交叉或遮挡，不把四人舞蹈规则扩大为影视剧禁止行走。参考图的身份定位不等于目标槽位，空间可达不等于人体无碰撞，文字无遮挡不等于已完成摄影或媒体验收。

## 4. 运行离线合同工具

仅需 Python 3.10+ 标准库。工具不联网、不调用 H3、不读取图像音视频、不覆盖输入文件。

```bash
python scripts/m3_contract.py --help
```

按合同指南执行 `route`、`check`、`accept` 和 `impact`。`route` 定位明确目标和资源；`check` 检查已实现的结构及关系；`accept` 对照版本和请求后返回新的草稿；`impact` 根据登记消费者读路径识别复验范围。命令成功不证明自然语言要求已全部满足。

从 `assets/` 复制请求、提案、批次和初始状态，替换示例 ID、来源、空间及已知条件后再运行。接受报告与真正状态对象分开保存；以合同指南指定的状态字段作为下一次输入。独立子模块只读取自己的必要投影，不触发整个上游链。

## 5. 提供 H3 编排和审计交接

| 模式 | M3 重点 | 字段去向 |
|---|---|---|
| T2VA | 文字定义空间、站位和互动 | 基础三字段，主要进入 `integrated_multimodal_description` |
| I2VA | 从实际首帧空间向后发展 | 首帧对齐与基础三字段 |
| FL2VA | 建立首尾空间端点之间的连续路径 | 首尾对齐与基础三字段 |
| L2VA | 从相容前态收敛到实际尾帧 | 尾帧对齐与基础三字段 |
| Ref2VA | 只继承已授权的空间属性，逐镜落实参考作用 | 六字段，空间正文进入 `detailed_description` |

Ref2VA 六字段依次为 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music`。基础三字段为 `integrated_multimodal_description` 及上述两个声音字段。M3 提供空间语义和审计要求，声音内容由 M6 决定，M11 完成最终序列化。

四类官方 Label 分别是 `<Subject N>` 可复用内容、`<Picture N>` 具体帧位／构图／分镜锚点、`<Video N>` 视频整体结构／编辑／续接关系、`<Audio N>` 明确使用的音频信号。场景也可成为 Subject；纯外观来源图不自动成为独立 Picture。内部实体、区域、路线 ID 不属于 H3 Label，编号由 M11 统一分配。

给每个镜头完整的当前位置、方向、路径、互动和观看条件。由 M4 补动作因果、M5 补摄影、M7 补权威时间、M8 补状态、M9 补镜头关系后交 M11 编译。最终模型正文不夹带内部合同、开发规范、审计过程或未实现功能声明。

## 6. 交付与完成边界

交付本次子提案或完整空间草稿、必要的空间／站位／互动表、依据与假设、问题和责任回传、H3 字段交接及执行记录。已存在的问题不因删除字段或重复检查而消失。

分别报告结构、已实现确定性关系、专业语义和实际媒体的结果。图连通检查不证明几何避碰；缺少机位时保留投影与可见性未验证；缺少排时时保留实际路线占用未验证。M3 的 G0/G1 局部结果不升级为完整 G2、G3 或 G4 通过。
