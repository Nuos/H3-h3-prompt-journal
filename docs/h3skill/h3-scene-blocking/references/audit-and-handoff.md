## 1. 检查范围与证据层级

区分四种判断，分别记录证据：

| 层级 | 示例 | 谁提供结论 |
|---|---|---|
| 结构 | ID、类型、版本、来源引用、字段归属 | 确定性脚本 |
| 已实现关系 | 图上的可达关系、路线与起终位关联、相同范围的显式冲突 | 确定性脚本仅检查其公开声明的关系 |
| 专业语义 | 左右是否确实说明白、动作是否容纳得下、遮挡是否服务观看目的 | 当前 Agent／人工审阅，附具体依据 |
| 实际媒体 | 镜头中是否发生碰撞、关键手部是否可见、角色是否正确到位 | 实际观察／测量；归 M12 的独立记录 |

脚本成功不自动生成后两类通过标记。案例作者自述、文字提示词与已提供媒体观察分开；本包样例只证明其公开合同可以表达和检查这些关系。

M3 贡献 G0 的空间输入检查和 G1 的空间设计检查。M11 的完整 G2 编译、G3 生成片和 G4 全片验收都需要另行实际执行；不能从 M3 草稿接受推出完整关卡通过。

## 2. 三个子模块的编排检查

### M3.1 空间与拓扑

确认原点／方向约定或关系描述、场景锚点、区域、连接和不可通行条件。用世界方向描述实体关系；人物自身左右引用稳定实体；屏幕方向绑定观看条件。

没有尺度时不生成测量结论，没有已授权空间参考时不继承布局，没有真实图像时不声称已对齐首尾帧。

### M3.2 站位与路线

确认稳定实体与槽位分离、起位和终位可定位、路线有过程、相关队形变化没有瞬移。以必要投影接收上游信息，不依赖对话里未提供的“刚才那一镜”。

跨域要求分别保留：动作过程交 M4、观看方向交 M5、时间占用交 M7、状态交接交 M8、镜头边界交 M9。

### M3.3 互动与遮挡

确认接触对象、交互区、路线交会、允许／禁止遮挡的作用范围以及必须可见的结果。显式矛盾应退回，不以笼统“合理”“自然”“不要穿模”替代具体空间设计。

不能仅凭已登记“避让”就宣布实际避碰；不能仅凭 `allowed` 一词就认为当前用户已经授权。语义审阅应回查原始任务及相关来源。

## 3. 父接受与修复回流

采用子提案、父接受：

1. 调用者明确请求目标、当前作品、基版本与范围，传入该节点需要的只读信息和来源。
2. 子模块返回其拥有分区的提案、理由、来源、未解决项和跨域修改请求。
3. 使用请求对照检查确认提案没有改写来源、偷换输入投影或改变任务身份；再审阅自然语言要求是否忠实落实。
4. M3 检查同基版本、同作品、字段责任、重复提交、相互引用与组合冲突。一个批次中每个分区只有一个候选。
5. 相容提案形成新的 `draft` 状态及接受记录；接受过程不暗改子模块内容。拒绝时保留原状态和明确的修复责任。
6. 新条件、新证据或语义调整使用新请求／提案和正确基版本。只读检查可重复执行，但重复接受不产生第二次相同修订。

父接受确认结构一致性，不替代专业裁决。M3.3 建议移动角色时，由 M3.2 修改站位；M5 建议改变摄影覆盖时，由 M5 修改摄影方案。当前模块未实现的消费者只登记交接，不声称已经执行。

### 诊断返回

| 类型 | 行为 | 返回目标 |
|---|---|---|
| 缺少必需输入 | 返回缺失字段及受阻结论；已知部分可保持候选 | 调用者／输入提供方 |
| 版本或合同不兼容 | 拒绝接受，不自动迁移语义 | 调用者／版本协调方 |
| 悬空实体、未明权限 | 返回实体、属性和来源缺口 | M2 或兼容输入提供方 |
| 拓扑冲突 | 返回具体区域／连接／框架 | M3.1 |
| 站位、路线冲突 | 返回具体实体、起终位和路径 | M3.2 |
| 互动、遮挡冲突 | 返回参与对象、区域和条件 | M3.3 |
| 缺动作、观看、时间或交接资料 | 仅对应结论未验证；保留明确请求 | M4／M5／M7／M8／M9 |
| 执行错误 | 保留错误及输入身份；修复技术问题后重试 | 调用者 |

禁止无界互相调用。每轮修复记录责任方、受影响范围和停止条件；没有新证据或新提案时，不通过循环自评升级结论。

## 4. 模块交接与变更失效

| 接收方 | 交接内容 | 本模块不替代的决定 |
|---|---|---|
| M2 | 缺失实体、源内位置、空间用途许可冲突 | 身份、资产、参考授权 |
| M4 | 可达区域、移动空间、接触区及对象 | 起态—过程—结果、支撑／重心和动作因果 |
| M5 | 人物／道具位置、路径、观看约束、关键可见部位 | 机位、光轴、景别、焦点、投影核查和运镜 |
| M6 | 已知声源位置、画内／画外关系需求 | 台词、实际说话者编号、声层和原音使用 |
| M7 | 需占用的路线／区域、交会条件和先后请求 | 权威起止时间、同步和跨时间域换算 |
| M8 | 有版本的起终位、朝向、接触及允许变化条件 | 权威跨镜状态与交接决定 |
| M9 | 空间连续或允许断开所需条件 | 切点、镜头编号、生成分段和装配 |
| M11 | 已确定空间语义、素材用途和待编译字段 | 实际输入模式、上传顺序、Label、最终正文与运行参数 |
| M12 | 计划、证据、问题、失效范围和实际检查记录 | 真实媒体观察及完整关卡结论 |

按实际读路径、对象和版本登记消费者。改变某条路线，需复验读取它的动作、摄影、排时、状态和剪辑结果；无关角色与未读取该路线的结果不自动全部失效。展示标题改变不应自动要求重做全片。

本包 `impact` 根据调用者登记的读路径计算影响候选。消费者漏登记时不可能得到完整影响图；工具不自动发现仓库、对话或外部服务的隐藏依赖。

## 5. H3 交接审计

根据 `h3-label-mapping.md` 检查：

1. 当前模式确实对应基础三字段或 Ref2VA 六字段；不以 `integrated_multimodal_description` 替代 Ref2VA 的 `detailed_description`。
2. 人物／场景等稳定实体与 `<Subject N>` 分离；源图位置不等于目标永久站位。
3. 首帧、尾帧、关键帧、构图锚点与身份参考角色分开；FL2VA 的中间路径须能连接两端，L2VA 不能把尾帧误当首态。
4. 仅借源视频的空间或运动，不自动继承原角色、背景、摄影或音轨；分别遵守 M2 权限。
5. 每个镜头都能知道当前人物位置、朝向、路径、互动和可见性条件。跨镜引用保留来源，但实际独立生成正文不能只写“同上”。
6. 向 M11 提交自然语言空间描述，正式模型正文不夹带 `M3Request`、内部字段、审计结论或开发说明。

## 6. 交付内容与停止条件

交付当前范围的子提案或父状态、空间／站位／路线／互动表、来源与假设、局部审计、下游交接和未验证项。只要求单子模块时不擅自扩展为全视频创作。

完成判定是已声明范围得到可复用的结果与明确问题；未知可保留在草稿，但未知不能被表述成已完成的空间验证。需用户补充时只询问会改变当前结论的关键事实；常规、可逆且已有授权的工程选择由当前 Agent 完成。
