## 可抽取的 M3 规则

### E1：身份、参考位置和当前空间状态分开保存

**F：** S08-P L34 固定四个角色身份；L36 从上一段肩转、内向角度和穿越中心缺口的动量接续，明确不重建参考图姿势；L79–86 又发生交汇、前后层交换与前景擦镜。S12-R L30–44 则只让图像锁身份，允许重建背景、姿势、机位与路径。

**D → 编排／审计：** 给每个主体稳定 ID；分别记录参考权限、场景锚点和当前站位。变换画面左右、前后层或场景，并不自动改变身份。先接受 M2 的参考权限：首帧、布局或场景确实被锁定时，不能借用“仅身份参考”的案例去解除它们。接续段读取 M8 的入态，不复位到参考图。

### E2：写清每个主体的路径和交汇关系

**F：** S08-P L80 给出两对保护弧及半拍先后；L81 是肩部接近但无接触；L82 是前后层互换；L84 是部分前进、部分退后再外移；L85 将四条手臂线分离。S07 L589 要求明确谁动谁停及前后排层次；L648–654 包含前排跪姿、后排高位与前后排改菱形。

**D → 编排／审计：** 对有移动的主体记录起点、经过区域、目标、相对方向、交汇对象与退出方向；对不动的主体明确保持状态。交汇事件写明先后、让道或层差，不能只写“交错得很漂亮”。地标可帮助解释路线，但不足的空间尺寸不能伪装成碰撞检测已通过。

**条件：** “同一平面路径相交”不必然等于“同一时刻身体碰撞”。是否可行还取决于时间、体积与动作幅度；仅有自然语言时，应登记待验证条件，不能宣布零碰撞。

### E3：区分接近、接触和承托

**F：** S08-P L81 明确接近而不接触；S07 L636–638 的茧式交叠则包含搭肩、背对背、解旋与同伴托背，另有三点承托变体。S07 L589 也强调接触点和承重。

**D → 编排／审计：** M3 记录参与者、接触部位、目标部位、相对站位和可达条件；写明是掠过、触碰、握持还是承托。需要承重时，将接触图交给 M4 检查支撑与恢复动作；M3 的位置描述不能替代力学验证。原文未给出手、脚或承托点时，标为缺项，不虚构“原案例已经证明”的接触细节。

### E4：有意遮挡可以成立，但要保留隐藏主体的状态

**F：** S07 L632–634 的多臂造型让一人在前、三人隐藏，手臂从不同高度伸出；它直接反驳“一直看见全部身体”的全局禁令。S08-P L86 让 S4 的手臂擦过前景，其余三人在后方沿不同方向继续运动。S12-R L101–109 用泡沫和水线部分遮挡，再经自然空隙显露脸部。

**D → 编排／审计：** 登记遮挡者、被遮挡者、空间关系、遮挡阶段、隐藏期间状态和预期再显露条件。区分构图需要的遮挡与关键动作意外不可见；后者可请求 M5 换观看方向或 M3 调整站位。不能要求每个人全程可见，也不能把遮挡当作身份消失或瞬移的许可。

**边界：** S07 L615–617 包含有意逐人离场。稳定演员名单与每一时刻的可见人数是不同字段；计划内离场不是自动判定错误增删人物。

### E5：分别写相机位置、视轴和画面投影

**F：** S04 L22–28 区分物理位置、视角及透视；L579–602 的 Dutch angle 是绕光轴滚转，人物和环境共同服从投影；L609–624 说明仰视不等于低机位，L640–650 说明相机位置不动也可俯视；L726–747 给出位置、高度、距离、视轴、空间关系及主体移动后的变化。S12-R L59 同时出现高机位、滚转、海岸线对角与主体对角。

**D → 编排／审计：** 使用“世界／场景坐标—人物自身坐标—相机位置与朝向—画面投影”的区别。不能把画面倾斜自动解释为人物倾斜，也不能以人物朝向替代视轴。世界左右不因反打自动改变；画面左右可能随相机位置改变。M3 输出相对几何关系，M5 决定如何拍摄它。

### E6：相机通路和主体通路需要共同可读

**F：** S06 L4 用起始机位、实际路径、主体触发、终点和最终画面描述移动；L167–181 通过手臂遮挡进行侧移再显露；L193–210 先前跟、停住，待人物穿过原机位线，再转为后跟。S05 L182–183 同样要求真实遮挡物和连续移动后的显露。

**D → 编排／审计：** 当主体跨越相机通路时，写清谁先通过、相机停在哪里、从哪一侧继续；遮挡前后仍需能够解释主体与相机的空间位置。相机穿过身体、实体墙或不可通行区域时提出冲突；未提供尺寸时，只能做关系审计。擦镜不会自动证明剪辑连续，M8 仍须检查跨镜入出状态。

### E7：提前就位和同步运动都是有条件的选择

**F：** S05 L11–12 采用释放阶段启动、重拍前提前就位；同一文件 L161–167 又要求动作和运镜同时开始、同峰并共享时间戳。S08-P L54–62 使用错峰、镜像路径与不同幅度，不能约化为所有人齐动。

**D → 编排／审计：** M3 只登记空间事件及其先后依赖，例如“通路清空后进入”“前后层交换完成后显露”。具体提前量、半拍、事件时刻交由 M7，与 M5 的运镜选择共同确定。不得把“全部同步”“全部提前”或案例中的秒数设为模块常量。

### E8：拓扑可达与运动机制分开表达

**F：** W L41 明确起点平台、滚筒、Fishbone Reverse、连接跑道与最终弧墙属于连续线性赛道；L95 的失衡先落到障碍平台，L101–115 接续恢复、前进与到达墙顶；L135–141 则是从赛道末端落入最终障碍旁的水中。

**D → 编排／审计：** 保留区域顺序、相邻关系和“障碍平台”与“终点旁水域”的区别。M3.1 可在未定镜头时独立建立拓扑；没有实测尺寸时不补写米数，也不把“相连”写成已经验证人体能通行。攀爬、恢复、抓边、失去支撑与落水的力学由 M4 细化，跨镜位置由 M8 核对。叙事落点关系可以登记，不能假装普通步行连接已证明跌落轨迹。

### E9：物理在场人数与当前可见人数分开

**F：** O L100–138 要求三人从一开始就在同一空间，前几次环绕各只见一人，直到末次才三人同框；L144–164 又要求相近、不重叠、不接触、不排直线，通过绕过当前人物显露下一人。

**D → 编排／审计：** 保存隐藏主体的真实场景状态，将显露作为观看方向改变的条件。案例中“从画面消失”不能解释成实体被删除或瞬移。距离近而不接触仍需具体站位与投影检查；仅有文字要求时，对“绝不露边／反射”保留 M5 待验证项。

### E10：画面右侧入画不是世界右侧

**F：** R L18–27、45–54、72–81 的三个片段各自从已跨入画面右边缘的一步开始，移到中心并以姿势结束；局部约束是固定正面全身机位、单人、不离场。

**D → 编排／审计：** 将“右边缘→画面中心”登记在具有观看条件的 screen 框架中，未经相机投影信息不换算成场景世界坐标。三个剪辑段的重复入场不自动构成同一连续空间中“先出场再进场”；接续或重置由任务与 M8/M9 决定。单人、固定机位、不出场是该案例条件。

### E11：接触锚点、支撑和剪辑触发分别交接

**F：** K L3–5 区分图像的身份／场景／机位锚点和视频的时间／姿势／触脚机制；L24–33 与 L40–64 给出前腿触地、保持接触、后腿支撑及接触触发换装；L606–631 要求剪辑前后触地点、支撑腿和躯干保持，且机位能读出接触时刻。

**D → 编排／审计：** M3 保存脚与地面的接触区域、相对站位及前后空间状态约束；身体重心和承重交给 M4，接触可见性交给 M5，触发时刻交给 M7，跨剪辑状态交给 M8，实际剪辑交给 M9。这个案例不支持泛化成“所有换装都必须脚触地”。
