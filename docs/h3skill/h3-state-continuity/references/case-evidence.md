## C01：18 段剑舞——外观不覆盖当前状态

**F，README L51–61。** 图 1 在方案 A 同时约束人物与海滩环境；方案 B 只约束人物并允许更换背景，两者不能混用。武器外观取自图 1，当前时间状态另行规定：Segment 01–02 负责拔出原刀；Segment 03–18 从刀已在手、腰间只剩原空刀鞘开始，不再拔刀或收刀。原文明确写“不得覆盖当前段落的时间状态”（L60），并要求用解剖学左右手避免画面左右歧义（L61）。

**D，可迁移规则。** 分开记录 identity、appearance、prop existence/count、ownership/held-by、sheathed/unsheathed 等分量。一个参考图的外观权限不能把后续计划状态回滚到图中初始状态。每个独立生成片段需要携带当前状态；“同一把剑”不代表可以同时在手和鞘中实例化两个完整武器。支撑与握持方向应注明解剖坐标或相机坐标，不能默认为同一参照系。

**F，README L63–65。** 每段一镜到底，组间交由后期；原文写“两组两段不强制首尾帧逐帧一致”，并以反光、倒影、头发、海平线和运动模糊提供后期连接材料。

**D，边界含义。** 本案支持把独立段落的蒙太奇连接与连续动作接续分开。M8.1 仍可规定人物、服装、道具唯一性、环境等跨段不变量；它不应给每个蒙太奇边界强加相同姿态、同一镜位或逐帧一致。具体取段、匹配剪辑与转场由 M9 处理。

**不可泛化。** 18 段、Segment 03 起持续持剑、一个原刀鞘、全曲海滩以及禁止收刀均为本案约束。M8 不把这些值设为所有剑舞或所有片段的默认值。持剑计划也不自动证明道具在实际生成画面中始终可见。

## C02：身份约束——保身份不等于冻结姿态

**F，README L16–25。** 面部参考明确只授予身份和面部比例等权限；身体、服装、环境参考分别授予相应外观权限，同时拒绝把参考图的站姿当作编舞起点。短摘录：“Begin directly with the first choreographed movement specified below.”（L25）

**D，可迁移规则。** M8.1 继承明确的参考权限，按属性规定保持范围。identity 稳定与 pose、orientation、contact、action phase 按计划变化可以同时成立。不能把 `fully_preserved` 误解为人物全部可变属性永不改变；须先检查该 Label 被定义的角色范围。

**F，README L46、L50。** 动作匹配切点放在未完成动作中，并列明出镜动量和入镜延续。短摘录：“movement in progress → cut → same movement continues”（L46）。本案还要求各段在运动中结束；这是具体作品要求。

**D，边界含义。** 若边界声明 action match，M8.3 检查同一主体、同一动作阶段、运动方向、支撑关系和下一动作的接收方式；只写“保持一致”不足以建立匹配。它读取 M4 动作事件与 M7 时间地址，不新增动作或偷偷改时间。其他作品可合法静止收尾，不能照搬本案的“永不停住”。

## C03：白凤六段——正文与交接表必须相互支持

**F，README L59–80、L93、L99–103。** 身体先建立承重再继续动作；连续接续关注同一只手、运动方向、重心转移、朝向与摄影机趋势。第 3 段内部两份生成素材在全曲 33.916 秒、段内 6.958 秒寻找共同相位手动拼接，音乐不重启。此处记录的是制作设计及作者叙述，未复验实际素材接缝。

**D，可迁移规则。** 对 continuous continuation 或 action match，记录 outgoing end-state、incoming start-state、边界类型、适用分量与支持它们的正文地址。遮挡可以掩藏剪辑，但不自动解释支撑点、朝向或持物的无因变化。独立生成本身也不证明动作会接上。

## C04：触地换装——只改变获准的状态分量

**F，README L23–40、L55–58；prompt L297–329、L541–575。** 新袜饰在活动脚首次清晰接触湿石面的时刻硬切；切后脚保持接地，衣饰稳定后才开始下一抬腿。短摘录：“CONTACT → CUT → PLANTED HOLD → STOCKING STABLE → NEXT LIFT”（README L27）。后/远腿持续支撑；脚位、支撑腿、躯干、髋与机位在换装切点保持，只有获准的袜饰分量改变。

**D，可迁移规则。** 将因果触发、状态变化、保持区间、下一事件分别登记：接触事件解释服饰变化，不同时许可换脚、身体漂移、机位跳变或提前抬腿。M8.2 记录预期转换与区间；M8.3 检查所引用的接触/保持事件存在，当前边界类型及策略允许变化。时码和声画同步要求由 M7/M6 提供，M8 不自行测量接触帧。

**F，README L34–36。** 原文从 LOOK 0 写到 LOOK 6，六次转换串起七个服饰状态区间；原文列出的七种服饰定义不同。永久支撑腿则横跨这些区间保持同一个值。**不得把本案改述成袜饰已经返回先前值。**

**D，状态计数。** 对从初态开始、包含 N 次显式转换的已覆盖连续序列，有 N+1 个状态区间；区间数不等于某属性的唯一值数。多个区间可以共享一个不变量值；一般合同也允许在获准转换后返回先前值。后一点来自[冻结开发路线图 §6.3，L260](https://github.com/Nuos/H3-h3-prompt-journal/blob/608813b6e51531ac47f860bc384a454a504fe9ff/docs/skillplan/02-development-roadmap.md#L260)的合同设计，不是本案出现了重复袜饰的事实。不能按去重值数量吞掉转换、合并边界或把循环回返当作缺失状态。

**不可泛化。** 六次切换、5.17 秒、具体接触时刻、后/远腿支撑和袜饰款式均为本案参数。该案例标题或 README 的“单镜头”措辞，也不能替代当前 H3 协议对真实切点和 `[Shot N]` 的表达要求。
