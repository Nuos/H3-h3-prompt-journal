# M8 审计、责任回传与版本交接

## 1. 按证据层报告结论

| 层级 | 实际输入和执行者 | 能支持的结论 |
| --- | --- | --- |
| 技能格式 | 官方格式校验、包结构与资源链接 | 当前技能符合已核对的格式条件 |
| 合同与确定性关系 | 脚本、原 Request、Proposal、State | 已实现的字段、权限、来源、状态关系和版本检查 |
| 专业文字审阅 | Agent、案例、两侧正文与交接记录 | 指定文本范围内的连续性问题和修订建议 |
| 真实媒体 | M12 或兼容观察者、实际输出与方法记录 | 被观察媒体及属性范围内的偏差与结果 |
| 全片 | 完整装配、作品目标与实际审阅 | 该成片的叙事、节奏和连续性结论 |

格式或合同通过不产生全局 G0—G4 通过。父接受结果仍为草稿；未取得实际视频时，媒体连续性必须保持未验证。

## 2. 三个子模块的局部审计

### M8.1 策略与变化许可

- 是否按实体／属性／范围登记，不把全片所有内容一律锁死？
- 不变项、允许变化和 M2 权限是否冲突，例外是否有明确来源和条件？
- 是否继承 M9 边界决定，未擅自把失败的连续接续改成蒙太奇？
- 身份图、首尾帧、当前状态、场景和声音的权威是否分别明确？
- 案例中的人数、时长、服装、姿态、机位和持物手有没有被误升格为统一规则？

### M8.2 计划账本

- 初态及必要转换有来源，阶段与区间覆盖口径清楚，未知没有伪装成事实？
- 持物手、道具数量、剑与剑鞘、支撑接触的变化有对应动作或获准编辑依据？
- 位置、方向和时间引用正确版本，没有新增竞争的空间／时间方案？
- 返回相同状态值的后续区间仍有独立记录，没有混淆状态值数量与转换次数？
- 原计划与实际观察分开，修订保留历史版本、原因和受影响依赖？

### M8.3 边界交接

- 前镜末态、交接表和后镜初态三方文字是否一致，引用是否对应真实文本？
- 同镜／连续／匹配／蒙太奇／省略采用了适用检查，而非统一全属性相等？
- 关键相位、方向、支撑、持有关系和声音持续能否逐项解释？
- 文字未写出的特写或动作是否被错误当作存在，画外／不可见是否被误读为不存在？
- 发现实际偏差后，是否停止把旧计划状态当作已实现前提，并回传唯一责任方？

## 3. 修复归属与所需材料

| 问题 | 首要责任方 | 返回材料 |
| --- | --- | --- |
| 身份、资产、参考属性授权冲突 | M2；目标冲突关联 M1 | 实体、属性、来源版本、冲突的许可 |
| 站位、接触区域、坐标或路线冲突 | M3 | 两侧位置、坐标系、关系与来源 |
| 未抓握就持有、换手无过程、重复拔刀 | M4；状态登记回 M8.2 | 事件、前后态、缺失机制、受影响镜头 |
| 表格称有特写而正文没有 | M5／M9；状态错误回 M8.2 | 前镜末端、表格、后镜起点的逐处证据 |
| 音轨、声音身份或跨切延续冲突 | M6；编辑关系关联 M9 | 音源、事件、窗口及持续策略 |
| 检查锚点、时钟或帧口径不一致 | M7 | 原时刻、时钟／版本、映射缺口 |
| 边界类型、选窗或省略意图不明确 | M9 | 当前边界、所需保留项、竞争解释 |
| 策略与许可自身矛盾 | M8.1 | 两条规则、范围、来源和需要的裁决 |
| 状态账本与有效决定不符 | M8.2 | 原账本、来源决定、待修订属性 |
| 首尾帧／素材 Label／模式不相容 | M11，必要时 M2／M9 | 实际素材角色、模式、冲突状态 |
| 实际生成未达到原计划 | M12 保留观察，再路由专业模块 | 媒体及计划版本、观察方法、覆盖范围和差异 |

## 4. 低耦合接受与变更传播

子模块接受公开最小输入，保留只读投影、来源与原请求。父 M8 唯一接受相容提案；不通过覆盖来源、删除已有状态、静默重绑 ID 或原地改历史解决冲突。相同请求的重复检查没有外部效果；语义变更使用新提案和新计划版本。

对每个消费者登记实际读取路径和对象版本。改变持剑手应复验相关动作、可见性、接缝和后继生成任务；没有读取该状态的无关镜头不自动失效。未声明依赖保持缺口，不能靠“未命中”宣布安全。

冲突回传包含范围、责任方、当前值、预期、证据和重新进入位置。技术重试与创作修订分开；本工具不执行媒体生成，不能通过反复自检制造创作问题已解决。

## 5. H3 交接与完成声明

交 M11 的是本段必需的身份／参考权限、起态、变化事件、终态、真实边界和声音持续要求。使用五模式各自的字段及素材 Label；不把内部账本、诊断、来源 ID 或审计说明复制进最终提示词正文。

交 M12 的是计划版本、边界与属性检查范围、预期值、已知缺口、相关引用及需要观察的媒体时段。M12 尚未实现或尚无媒体时，只保留公开交接接口，不宣称已自动调用或完成 G3／G4。

方法依据见 [案例证据](case-evidence.md)，官方语法见 [H3 映射](h3-label-mapping.md)，具体自动化边界见 [合同指南](contract-guide.md)。
