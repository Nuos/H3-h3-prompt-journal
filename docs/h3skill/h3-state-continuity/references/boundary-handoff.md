# M8.3 边界交接与接续检查

## 1. 建立边界最小记录

取得边界 ID、M9 的类型与意图、两侧镜头／生成任务、M7 时钟和检查锚点、M8.1 策略、M8.2 计划状态，以及两侧正文和交接说明的来源版本。每条检查明确比较的实体和属性。

只审计一个边界时，只读取该边界需要的计划与文字。不同帧率、源片选窗和生成局部时钟由 M7 提供映射；不能把两个“最后一帧”在没有选窗依据时视作相邻。

## 2. 对照三份文字依据

| 依据 | 要核对的内容 | 不能替代的证据 |
| --- | --- | --- |
| 前镜正文的末端事件 | 实际写了哪只手、哪种支撑、什么动作相位和构图 | 交接表对末镜的概括 |
| 交接表／边界声明 | 需要维持的状态、匹配点、允许变化和接缝要求 | 两侧正文或实际视频 |
| 后镜正文的起始事件 | 是否从声明的起态发展，是否出现未解释的复位 | “上一镜应当已经完成”的推测 |

白凤六段的段间表提出具体手腕、掌心和眼部特写；应逐条回到上一段末镜和下一段开头核对。若正文没有对应的特写或动作，表格本身不能证明交接成立。记录差异及两个文本位置，回 M4／M5／M9 或 M8.2 修订具体内容。

脚本可检查结构化声明、精确引用、来源保真及明确状态关系；自由文字的含义与“该镜是否真的写了此状态”由 Agent 结合原文审阅。未执行文字审阅或媒体观察时，分别保留未验证，不能把声明的通过当作已执行审阅。

## 3. 根据边界比较状态

- **同镜与连续接续：** 检查必要的身份、物件数量、持有关系、支撑、方向和动作相位。机位变化可以改变屏幕位置或景别，必须保留空间和摄影依据。
- **动作匹配：** 检查被选定的动作相位、运动方向和关注对象；服装、场景或时间是否允许变化由对应策略决定。相似姿势不自动证明力学或剧情连续。
- **蒙太奇：** 检查选定的连接要素与其持续范围；不强求所有位置、姿势和道具状态相等，也不把“蒙太奇”当作免除身份／权限检查的口令。
- **换场或时空省略：** 说明省略范围及必要线索，核对仍需维持的身份、道具归属、已发生事件或声音关系。缺少明确编辑决定时，不猜测省略已经获准。

前后状态相同也可能存在错误：重复表演已完成事件、音乐重新从头播放或正文暗含另一次换手，均需要语义审阅。状态不同也可能合法：授权的场景／服装切换或动作相位推进应保留。

## 4. 给出能执行的接缝要求

用具体实体、属性、相位和范围表达要求。例如“右手保持握住同一剑柄，前镜结束时剑尖仍向身体外侧移动；后镜从该运动继续”，比“无缝衔接”更可核对。示例是文字设计，不证明生成片实现了这一轨迹。

利用手、衣袖、发丝或环境细节遮挡接缝时，明确遮挡出现在哪个镜头和动作，交 M5／M9 确认可见性与剪辑方式。不能新增不存在的遮挡或要求所有作品都使用相同转场。镜头变化不会替代必要的身体与物件过渡。

声音按 M6 的连续／结束／跨切策略处理，M7 提供时间；M8 检查音轨身份和持续关系，不重新裁切音频或改写台词。案例中连续母带、不重启音乐的条件不推广为所有作品禁用声音变化。

## 5. 发现问题后回到唯一责任方

M8.3 形成交接诊断和修订请求，不能直接更改 M8.2 账本。需要改连续性策略时回 M8.1；需要改状态时回 M8.2；需改动作／机位／时间／编辑时交对应责任方。修订后使用新版本重检真实依赖，保留旧诊断。

如果已有 M12 观察偏离计划，不能沿用旧计划末态作为“已生成”的接续起点。报告差异、覆盖范围和处理建议；未知媒体属性保持未知。只有实际输出及其观察足以支持时，才能对该媒体边界作出媒体层结论。

公开记录和脚本支持范围见 [合同指南](contract-guide.md)，原案出处和已知冲突见 [案例证据](case-evidence.md)。
