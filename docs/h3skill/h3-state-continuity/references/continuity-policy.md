# M8.1 连续性策略与变化许可

## 1. 从属性和范围建立策略

对每个与本次任务有关的实体／属性确定持续范围、来源、约束和例外。身份、服装、道具外观、道具状态、场景和声音可以有不同范围；“同一人物”不推出“全片同一姿势、服装或地点”。

| 维度 | 必须回答的问题 | 决定来源 |
| --- | --- | --- |
| 身份与外观 | 谁持续存在，哪些可见特征继承，哪些外观获准改变？ | M2 身份与属性权限；M10 风格意图 |
| 道具 | 道具有几件、在哪里、由谁及哪只手持有，是否出鞘／收纳？ | M2 稳定道具；M4 操作事件；M8 计划状态 |
| 接触与身体 | 哪一肢体承重、何处接触、朝向及动作相位需要保留？ | M3 空间和接触区域；M4 动作机制 |
| 场景与环境 | 持续的是同一空间、相同视觉主题，还是获准换场？ | M2 权限；M3 场景；M9 边界 |
| 声音 | 哪个声源／音轨继续，是否允许结束、重启或改变？ | M6 声音语义；M7 时间；M9 编辑关系 |
| 叙事事实 | 哪个对象已被交付、信息是否已知、哪个动作已经完成？ | 用户或 M1／M4 的明确事实，按任务另行审阅 |

叙事事实接口属于框架设计，现有舞蹈案例不能证明完整剧情连续性自动判定能力。

身份图只保留获准属性；本段当前状态来自有效计划及其事件依据。剑舞方法论把道具外观与状态分开，半身舞案例把身份图姿态与动作起点分开。案例中的具体持剑手、服装或“全片不换景”只能在相应作品范围使用。

## 2. 按边界类型选择检查

| 边界 | 主要保留项 | 允许变化的前提 |
| --- | --- | --- |
| 同镜连续过程 | 身份、物件关系、空间和动作因果 | 变化经过已声明的动作／环境事件；不能用“允许变化”跳过过程 |
| 连续动作接续 | 必要支撑、握持、方向、位置关系和相位 | 新机位或景别来自摄影／剪辑决定；身体变化有接续过程 |
| 动作匹配剪辑 | 指定动作相位、运动方向、关注对象及其他持续项 | 场景、服装或时间变化有明确许可和匹配依据 |
| 蒙太奇 | 主题、身份或任务明确指定的连接属性 | 非连续空间、姿态、时间及服装按范围获准改变 |
| 换场／时间省略 | 身份、叙事与道具事实中仍需持续的部分 | 省略什么、变化如何成立、是否需要视觉／声音提示明确 |

边界类型由 M9 或用户提供的兼容编辑决定声明，M8 不能因连续性失败把它偷偷改成蒙太奇。18 段剑舞的组间连接允许后期视觉桥梁，不要求每对片段逐帧首尾匹配；白凤六段则明确要求相关舞句接续。二者按作品和边界范围并存。

## 3. 为允许变化建立可审计依据

每项允许变化至少说明：作用实体／属性、范围、原规则、来源与版本、触发事件或边界、允许的结果、仍需保持的其他属性。只写“可以变化”“蒙太奇免检”不能满足要求。

例如，获准在触地切换服装不同时授权更换人物、增加肢体、重置支撑脚或使道具消失。许可控制“可以改什么”，动作／编辑依据解释“如何、何时发生”。无法从上游决定解出冲突时，返回 M2／M4／M9，不自行给规则设置隐藏优先级。

发现同一范围的“不变”与“允许变化”冲突时，保留两条来源及其有效版本，要求责任方明确裁决。独立子模块可以接收兼容外部输入，但来源声明不自动证明该输入获授权或真实。

## 4. 编排与审计出口

形成适用范围明确的策略，交 M8.2 登记状态，交 M8.3 选择边界检查项。H3 表达交接包括需要持续的可见特征、必要状态及允许变化的事件；内部权限表和审计过程不进入最终模型正文。

核查：持续范围是否过宽；参考图是否越权成为首帧；蒙太奇是否保留了任务要求；变化是否越过 M2 权限；声音是否擅自重启；原规则冲突是否被隐去。精确数据合同和脚本支持范围见 [合同指南](contract-guide.md)，方法出处见 [案例证据](case-evidence.md)。
