## 稳定证据记录

### E01

**三层结构与细节服从主链（F）。** S02M 行 20–59，章节 2/20–5/20；S07P 行 17–56。源文本区分呼吸／重心／节奏底层、主动作链、头眼指腕细节，允许局部停顿而不要求每个部位不停运动。可推广：给动作主链和必要细节分工；不可推广：把古风舞脚步、重心、身韵、手臂、眼神的次序当成所有表演的强制生理顺序。

### E02

**动作名称需要完整物理过程（F）。** S02M 行 40–59，章节 4/20–5/20。源文本要求发力、路径、支撑、重心轴、展开、峰值、惯性、回收，并以转身、跳跃和地面动作说明完整过程。可推广：入态、过程和出口完整；条件项按动作选用，不要求每条视线反应都有脚步或跳跃。

### E03

**密度与主题有条件适用（F）。** S02M 行 61–80，章节 6/20–7/20。慢、快、甜美段落的动作密度只是该方法论的估计；整支舞可重复、变形和回收动作主题。可推广：容量要容纳动作完成，慢动作不等于空白；不可推广：把每八拍动作数变成所有类型和模型都保证满足的阈值。

### E04

**身份、外观和动作状态分开（F；作者对重复道具风险的解释属于 A）。** S03M 行 39–65、132–171。晴天与幻想版本的参考权限不同，不能合并；已有道具外观不等于当前是否出鞘、由谁持有。后段从连续动作状态进入，不重置为参考图的初始状态。可推广：引用权限和当前状态分别核对；不可推广：从一个版本推定另一版本最终一定归鞘。

### E05

**唯一道具、解剖学手别和出鞘前提（F）。** S03M 行 132–171；S03P 行 118–145。指定版本只有一把刀与一个鞘，后段应从已持裸刃／空鞘状态开始，持物手以身体左／右而非屏幕左右标记。可推广：持有者、握点、数量与动作前提连续；不可推广：所有剑舞都只允许单人、单刀或不归鞘。版本与时间冲突另见 E14。

### E06

**身体与剑路共同构成动作链（F）。** S03M 行 194–203；S03P 行 125–141。源文本采用蓄势、重心启动、扩张、峰值、制动、恢复和下一入口，并描述足部支撑、躯干、肩肘腕、刀路与余势。可推广：道具路径不能脱离身体和握持；海滩、特定 BPM、无对白和音源限制均保留案例作用域。

### E07

**窗口完整性与有意循环（F）。** S07P 行 42–64。动作库要求窗口容纳进入、启动、重音、制动／平衡和下一入口，提供局部耗时估计，也列有明确的两拍循环。可推广：容量不足要重排或调整动作；不可推广：秒数估计、转圈上限或全程镜身同步是普遍规律，或所有循环都应被禁止。库其余条目未在本轮语义阅读，不能声称整库 74 条链逐一校核。

### E08

**目标性表演、受阻与重新选择（F）。** S10R 行 59–82；S10P 行 123–134、327–340。源文本通过失衡后的支撑找回、局部身体改向、被中断的动作链和未完成恢复表现受限状态；相应版本禁止增加可见施力者、额外手、绳索或笼。可推广：情绪／意图要有可观察的动作机制；不可推广：任何戏剧场景都不得出现第二人或可见约束物。

### E09

**地面支撑转移与跨段接续（F）。** S10R 行 59–82；S10P 行 465–475。源文本包含降低重心、掌撑、地面姿态、半跪与起身的接续；匹配提示中明确手掌、前臂、肩、骨盆的支撑路径。可推广：每一阶段的进入和负载变化应可说明；不可推广：所有地面动作都按同一路径完成，或触地切换的固定后脚支撑适用于地面舞。

### E10

**停顿可以是表演结果（F）。** S10P 行 335–340、395–408。源文本使用安静呼吸、脚部调整、视线、手和有意静止表达张力与自主性。可推广：区分有意静止和动作缺失；不可推广：任何结尾都必须静止，或任何舞蹈都必须持续移动。

### E11

**非承重触地、固定支撑与参考权限（F）。** S14P 行 1–66、153–219、596–635。源文本将身份图、动作／计时参考和音频分工；后侧脚保持主要支撑，近侧脚小幅抬落并点地，近脚不成为主要承重腿。可推广：触碰、负载与保持分别描述，动作来源不自动赋予身份／背景权限；不可推广：所有抬腿动作都固定同一支撑脚，或本轮已验证动作迁移准确率。

### E12

**接触成立、保持、切换完成、释放的因果次序（F）。** S14P 行 37–66、153–219、596–635。源文本把服装切换限定在第一次清晰脚跟／脚掌接触，并要求保持到切换稳定，再释放进入下一抬腿。可推广：动作、剪辑、外观状态和时间的依赖应分清；不可推广：接触必然导致换装、固定 2.070 秒是所有任务的时间点，或切点证明了身体承重。

**道具接触与可见反应（F；作者效果描述仅 A）。** S-COMEDY README 行 1–128，全文由 parent 阅读。父代理确认其中有动作链、道具触镜和眼神反应，可作为一般表演／反应／接触编排的文本依据。本包只抽取“接触与反应须有因果关系”，不宣称已复核该案成片或作者所谓成功验证，不扩展未读取的 prompt.txt 细节。

## plan-boundaries

### P01：冻结职责与内容边界

`docs/skillplan/01-core-framework.md` 的 M4 条目（行 176–189）规定人物表演、动作链、物理因果及戏剧／舞蹈／剑舞等内部策略；相关字段归属与接口见行 330、353–354、391 附近。M4 唯一拥有 ActionPlan，描述执行者、对象、前提、过程、接触、结果、后续条件与策略；M8 提交权威状态，M5／M6／M7／M9 各自拥有镜头、声音、时间和剪辑。计划用于职责与接口，不用作案例效果证据。

### P02：三个子模块与按需路由

`docs/skillplan/06-modularity-routing-principles.md` 的 M4 分层条目（行 210 附近）冻结 M4.1 表演事件与前提、M4.2 动作机制与交互过程、M4.3 结果与动作接续。一个字段分区一个权威写入者，依赖不等于每次必须执行全部模块。计划来源快照与许可由 [provenance-and-license.md](provenance-and-license.md) 记录；本文没有另创 M4.2.1 等核心子模块。

### 现有验证缺口

`docs/skillplan/03-source-evidence.md` 与冻结职责共同限定证据层次。戏剧中的角色目标／信息、听者反应、同一句对白不同意图、对白走位与声画联动需要额外验证；本轮也没有语义阅读多人编舞和动作迁移案例。本包可检查这些请求的事件／权限／状态接口，但不声称具有该类任务的生成回归成绩。历史案例集数量与当前全目录库存数量不能互相替代。

## 推荐的文本回归场景

以下是设计性测试，不是已经运行的 H3 结果。运行器的实际测试清单另以实现及测试报告为准。

| 测试 | 应检查的结果 | 依据 |
|---|---|---|
| 慢速展开含一次快速制动 | 区分动作阶段；不能将所有过程强制同速 | E02、E03 |
| 只有“优雅旋转” | 缺少支撑、路径、制动和出口应报缺项 | E02 |
| 已持裸刃却再次拔刀 | 前提冲突；不得新增刀或复位状态 | E04、E05 |
| 多版本最后是否归鞘不同 | 先选择版本，不能混合两个终态 | E04 |
| 掌撑到半跪再站起 | 验证支撑／负载变化及后继入口 | E09 |
| 固定后脚支撑且近脚点地换装 | 保持接触到切换完成后才释放 | E11、E12 |
| 同一事件要求原地点地和迈步承重 | 范围冲突；不把触碰等同负载转移 | E11 |
| 抑制动作后的有意停顿 | 保留目标性停顿，不报为普遍禁止项 | E08、E10 |
| 道具接触后出现眼神反应 | 接触先于反应；不以并列画面替代因果 | E13 |
| 单人输入临时出现第二舞者 | 保留实体范围并转上游核对 | 单人案例作用域＋P01，D |
| 仅许可动作来源却复制其服装／身份 | M2 权限冲突，不能假称参考迁移通过 | E11＋P01，D |
| 拔刀两处时间不一致 | 登记来源冲突并交 M7 | E14 |
| 对白中的听者反应 | 可检查事件接口，结果标记无真实生成验证 | P01，D／U |
