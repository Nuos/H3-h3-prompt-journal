A→B 被明确指定为同一时空、同一未结束动作的连续接续。因此，检查范围包括主体和道具身份、数量、持有关系、出鞘状态、空剑鞘位置、运动方向与动作相位，以及必要的空间与支撑关系。不能为了容纳“再次拔剑”而将边界改判为时空省略或蒙太奇。［R1、R3、R5］

| 属性 | 本边界的策略 | 权限／证据 |
| --- | --- | --- |

## 二、B 组：舞蹈主题蒙太奇

### 1. 连续性策略

该边界保留同一舞者身份，以“手向上展开”的视觉母题联系两个段落；不要求同一物理动作、相同姿势或相同支撑点连续。服装与场景分别有明确变化许可，不能将其中一项许可错误扩展为身份也可变化。［R1、R3、R5］

| 属性 | 策略 |
| --- | --- |
| 舞者身份、脸和身体比例 | 持续保留 |
| 服装 | 获准从蓝衣变为红衣 |
| 环境 | 获准从海滩变为石廊 |
| 姿态与支撑 | 允许站立切到已低跪，不要求在片中补演下跪过程 |
| 动作联系 | 保留向上展开／舒展的母题；不预设速度、关节角度或物理动作相位完全相同 |
| 道具 | 文字未描述道具，不能将未描述自动登记成“已核验无道具” |
| 背景群众 | 尚未决定，保持未知，不替创作者补定有或无 |
| 音乐 | 保留同一曲目的已选相邻窗口 |

### 2. 必要状态账本

| 位置 | 可登记的计划状态 | 未知或不应强加的条件 |
| --- | --- | --- |
| B1 末端 | 同一舞者，脸与身体比例保留；蓝衣、海滩；站立，双手在胸前向上展开 | 精确朝向、运动速度、手部屏幕位置、道具状态、背景群众未提供 |
| B2 开始 | 同一舞者，脸与身体比例保留；红衣、石廊；已经低跪，手指向上舒展 | 不自动补出从 B1 站立到 B2 低跪的连续物理过程；具体跪姿接触细节未提供 |
| B1→B2 边界 | 主题蒙太奇；身份与向上母题保留；服装、环境和姿态按许可改变 | B 组模式、时长及作品时间映射未提供，不能沿用 A 的 Ref2VA 或 [0,6]／[6,12] |
| 音乐 | 同一曲目的已选相邻源窗口 | 具体素材、源入出点与实际听感未验证 |

“未知”不等于不存在或保持不变；“允许跳变”也不等于放弃所有持续项。这里有依据的持续项是身份特征、母题和既定音乐关系。［R1、R3、R4］

### 3. 逐边界结论及外部检查说明

B1→B2 的已知计划与主题蒙太奇策略相容：

- 蓝衣→红衣、海滩→石廊均有分别授权，不构成连续性错误。
- 站立→低跪是该边界获准的姿态／支撑跳变，不需要人为补一段下跪动作。
- 双手向上展开→手指向上舒展，在文字层面提供共同方向母题；没有资料证明实际剪辑中的手形、位置、节奏已经匹配。
- 脸与身体比例必须继续保留；媒体未提供，无法评价生成中是否达成。
- 未提供 B 组交接表，不能声称已经完成三份文件的一致性对照。［R1、R5］

外部检查说明“所有跨段边界必须保持前一段最后姿势、服装和场景完全一致”不适用。它将一组并非所有边界都需要的条件提升为普遍规则，与本次用户的蒙太奇编辑决定及明确变化许可冲突。即使对 A 的连续接续，也应检查具体状态、事件和镜头关系，而不是机械要求画面所有属性一律不变。适当的检查应先识别边界类型，再核对该范围内的持续项、变化许可及其证据。［R1、R3、R5］

因此，B 的结论是“已知文字与所选策略相容”，不是“实际视频通过”，也不是代替父 M8 完成接受。

## 三、制作者转述：A 最后 0.5 秒可能换到左手

### 1. 当前可以得出的结论

目前只有制作者转述，没有媒体 ID、结果版本或可查看文件。这条记录可作为“待核验偏差线索”，不能记录为已经观察到的左手持剑事实。版本 1 仍明确要求 A 结束时右手持剑；前文确认的正文／交接问题也仍然存在。［R1、R2、R6］

不能接受“把原计划末态改为左手、继续沿用旧右手交接表、把原边界标为通过”的处理：

1. 将旧计划倒改为左手会抹去版本 1 与结果之间本应保留的比较基线。
2. 即使未来批准左手作为新计划末态，旧表仍是右手，B 的动作前提也须重新审查，不能据此得到一致的边界。
3. 没有来源清晰的观察，既不能宣称生成结果符合计划，也不能断定发生了真实换手而非遮挡、镜像、视角误判或其他情况。
4. 即使未来确认结果右手持剑，也不会自动消除版本 1 的重复拔剑与镜头登记冲突。［R1、R2、R4—R6］

### 2. 后续判断需要的记录

| 记录 | 用途 |
| --- | --- |
| 媒体 ID、生成结果版本、可查看文件或稳定定位信息；条件允许时保存文件摘要 | 唯一定位被讨论的结果，避免混淆不同生成候选 |
| 对应工作 ID、计划版本、实际使用的提示词／引用素材版本及生成任务对应关系 | 确认该结果是否真的执行版本 1，不能仅凭相同片名推断 |
| 实际时长、帧率／时间基、局部时间与作品时间映射、是否裁切／变速／镜像等编辑记录 | 定位“最后 0.5 秒”，避免把未确认的媒体时间直接套入计划时间 |
| M12 或符合该职责的观察记录：观察者／方法、媒体版本、时间窗口、覆盖属性、结论和不确定项 | 将转述转为可追溯证据 |
| 必要帧／片段中的持物手、剑与剑鞘、动作相位、可见性和遮挡说明 | 区分解剖学左／右与屏幕左／右，识别是否真的换手，以及是否存在可解释的转换 |
| 如评价实际 A→B 接缝，还需 B 的对应媒体版本及装配切点 | A 的单段观察不足以证明两段拼接成功 |

只有实际媒体确为未裁切的 6 秒片段且映射一致时，“最后 0.5 秒”才可具体登记为局部 [5.5,6]，并映射到相应作品区间。现在应保留原转述范围，避免伪造精确时间证据。［R2、R4—R6］

### 3. 核验后的处理路径

| 条件／选择 | 后续动作与记录 |
| --- | --- |
| 偏差未确认或观察覆盖不足 | 保留待核验状态，记录可见性与不确定性，不据此修改计划或宣布通过 |
| 确认结果左手持剑，但继续执行右手方案 | 保留版本 1 与观察证据，提出重生成／修正请求；新结果另设版本并重做必要观察 |
| 由 M9 改选片段或调整切点 | 先证明所选窗口能提供所需末态，再记录源入出点、作品映射与交接更新；若影响既定音乐窗口，回传 M6／M7，不能静默移动 |
| 创作者明确批准采用左手方案 | 基于有效基版本提出新计划。M4 解释必要的换手事件与动作接续，M8.2 更新相关状态，M5／M9 更新镜头和切点，M11 更新编译输入；同步复核 B 初态与表格，父 M8 再接受 |
| 转述被证实有误 | 保存相应观察及覆盖范围，关闭该偏差线索；原有文字问题仍按其各自修订记录处理 |

旧计划、旧交接表和原问题应作为历史保留；它们不能在与新方案矛盾时继续充当有效当前记录。新版本解决的是新方案的一致性，不会把旧版本的问题追溯改成“原边界通过”。［R2、R4—R6］

影响范围优先定位于 A 末态、A→B 交接、B 初态及依赖这些状态的动作、剪辑与编译输入。B 组蒙太奇等未读取该状态的内容不应自动重做；缺少依赖登记时，也不能宣称已经证明所有其他内容完全不受影响。［R2、R6］
