- 模式：Ref2VA。人物和原有剑／剑鞘的外观来自 Picture 1，图片里剑仍在鞘中；用户只授权继承这些外观，不要求继承图片中的静态姿势。

- 片段 B：局部时间 0–6 秒。正文写“从 Picture 1 的完整姿势开始，右手握住腰间剑柄，再次拔出剑，然后沿身体外侧完成一条剑路”。

## B. 舞蹈主题蒙太奇

- 同一位舞者在两个场景中出现。用户允许 B1 的蓝衣海滩切换为 B2 的红衣石廊；脸和身体比例保留，环境与服装分别更换。
