# M8 实现审阅与修复闭环

## 范围

本记录区分代码／合同审阅、实际反例、来源核对和最终执行结果。它不构成 H3 推理或媒体认证。原方案、案例与旧模块没有参与修复写入。

## 已处理问题

| 发现方式 | 问题 | 本轮修正与核验 |
| --- | --- | --- |
| 根侧代码审阅，作者回归 | 父请求仅有 `continuity_brief` 时，列出子路由后不应直接宣称各子模块可调用 | 逐子返回 `missing_inputs`、`call_ready`，父状态为 `requires_child_inputs`；保留 `invocation=not_invoked` |
| 根侧代码审阅，作者回归 | `/contexts` 不在依赖变更路径中，会漏掉明确读取上下文的消费者 | 将其纳入 `impact` 的路径交集；未注册语义依赖仍不宣称自动覆盖 |
| 代码审阅及过程负例 | 仅精确引用一个 M4 记录还不足以说明该记录对应当前转换 | `ActionAdapter` 必须说明对应端点、相关变化属性与过程；无关动作绑定拒绝，动作物理真实性仍待专业审阅 |
| 根侧实际复现，作者修复后回归 | M8.2 可将其他镜头的策略许可借给当前转换 | 取独立 M8.2 夹具，仅把两个状态的 `shot_id` 改为 `unrelated_shot_a/b`，原请求和策略保持不变，旧实现返回 `failed=false, diagnostics=[]`；现对显式策略强制存在且核对两端镜头，返回 `transition_policy_shot_binding` |
| 合同回归 | 非边界转换附带悬空 `policy_id` 也必须处理 | 对任何显式 `policy_id` 检查存在性；重复值正例使用合法回程策略，避免依赖上述错放通过 |
| 来源分工的只读集成复核 | 开发报告将剑舞依据写成未列入已读证据的“方法论／提示词” | 改为实际已读 README 选段 |
| 来源分工的只读集成复核 | 重复状态值规则放在换装案例行中，可能被理解为原案服饰发生回返 | 明确原案六次转换／七区间；允许回到旧值来自冻结路线图的 D 类合同规则 |

区间单位疑问经合同确认：`unit` 固定为 `seconds`，其他单位会先被形状检查拒绝；未添加无必要的重复逻辑。中文证据片段按 Python Unicode 码点、左闭右开范围检查，专门保留 UTF-8 字节位置误用的反例。

## 独立只读审阅

独立审阅者读取合同与运行器，未修改文件、未执行发布，最终未确认尚未闭环的阻断问题，也未新增实际复现的缺陷。其确认范围包括：已接受上下文采用 `accepted=True` 处理历史投影版本并拒绝未来版本；区间单位固定为秒；父路由逐子登记缺项。此结论是限定范围的代码审阅，不能改写成另一套独立执行的测试结果。

他镜策略借用的实际反例、最终 43 项单测和 13 项便携性检查仍归根侧执行记录。审阅中未完成验证的观察版本疑点没有被列为已证实缺陷，也没有被宣称已经充分验证。

独立文字试用见 [semantic-review.md](semantic-review.md)，其读取范围与执行时间保存在原始材料中。该试用的最终 SKILL 入口 SHA-256 与发布入口一致；它没有执行 CLI 或生成模型，不能将本轮脚本测试效果倒填为试用当时完成的工作。

通过含义限定为合同形状、显式状态关系、来源／版本绑定及本轮文字审阅。自然语言全文语义、图像内容、动作物理、真实接缝、声音同步及完整项目关卡均不在这份执行证据中。
