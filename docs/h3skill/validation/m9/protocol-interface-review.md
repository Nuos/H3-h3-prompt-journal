**范围：** 固定 H3 原文、冻结 M9 责任、既有 M7／M8 的公开合同及 M9 文档交接。该审阅不代表跨模块程序已经实际调用或媒体已通过。

## 依据

- 输入仓库 `36987c56ade886aacfb166a21d6560925c97c330` 中 M7 的 `ReadonlyRecord`／`Mapping` 和 M8 的 `EditBoundary`／`EditValues`。

## 结论及落实

| 事项 | 可确认的风险或差异 | 本轮处理 |
| --- | --- | --- |
| M7 编辑绑定 | `ReadonlyRecord.source_version` 是非空字符串，与整数版本通用投影不同 | 审计指南登记准确目标形状，要求显式适配与来源绑定；不宣称原生对象直连 |
| M8 编辑边界 | 严格要求 boundary_id、boundary_type、from_shot、to_shot、invariants、match_attributes、approved_changes、cue | 不把 M9 EditGraph 整包代入；持续项／变化许可缺失时返回待补，不捏造语义 |
| 基础与 Ref2VA | 主字段及字段数不同 | 逐模式、逐字段映射，保持三字段与六字段区别 |
| 首尾帧首行 | FL2VA 与 I2VA／L2VA 括号形式不同，末镜与时长属于当前目标 | 明确交 M11 按原模板序列化，不做统一格式替换 |
| 真实 Shot | 官方编号表示切镜，不表示动作阶段、画格或后台运行次数 | 每任务保留局部序列和全片稳定 ID 对照，M7 提供局部切点 |
| 视频关系 | 仅参考 cuts／rhythm 并不构成 editing／continuation | 按实际素材作用选择 summary 类型及 Video 定义 |
| 声音阶段 | 后期铺底不自动成为当前模型 Audio 输入，整轨与部分复制语义不同 | 生成任务指南和映射明确按作用阶段处理；M6／M7／M11 负责相应声音语义、时序与表达 |
| 特定转场 | 官方正文中的叠化、淡入淡出、擦拭需用户明确指定 | 映射保留该条件；后期候选桥接不自动变成模型内特效 |

## 能力边界
