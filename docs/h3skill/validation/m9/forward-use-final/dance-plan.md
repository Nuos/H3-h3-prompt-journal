# 16秒舞蹈：两任务生成与剪辑规划

本稿确认制作结构；后端能力、源片与接缝效果尚未验证。成片只在9秒切镜，6秒保持连续观察。

## 一、五种单位对应

| 单位 | 本案对应 |
|---|---|
| 动作阶段 | A1：0–4秒向右跨步；A2：4秒至转体完成时刻，保持同一次转体；A3：完成后至16秒，呼吸与衣料余动。完成时刻须晚于9秒。 |
| 分镜画格 | P0、P6规划S1的构图与阶段；P16规划S2终段状态。三张图都不是指定首尾帧。 |
| 镜头 | S1占成片0–9秒；S2占9–16秒。6秒运镜转向发生在S1内部。 |
| 生成任务 | G1承载S1，G2承载S2；分别提供完整上下文。 |
| 编辑实例 | E1选用G1的候选9秒片段，E2选用G2的候选7秒片段，顺接成16秒。 |

A2跨越镜头、任务和编辑实例；画格数量不决定镜头或任务数量。本案镜头与任务恰好一一对应，不能推广为通则。

## 二、镜头与编辑结构

S1中，0–4秒向右跨步，4–9秒同一次转体持续发展；6秒摄影机由侧移转为后退，不插入切镜、重新起势或时间跳跃。S2从9秒的较近观察位置接住正在进行的转体，完成后持续记录呼吸与衣料衰减至16秒，不能以静止画面代替余动。

9秒是后期组接的真实切镜，也是两任务交接点。匹配项目包括转向、转体进度、朝向、角速度、支撑脚与接触关系、四肢位置及衣料运动趋势。允许观察距离变近；更换机位角度、跳过动作或重做转体均未获指定。身份、服装、场景、光照应连续。

## 三、两个独立生成上下文

**G1：**单独绑定身份照片与镜头节奏视频，注明照片只约束舞者身份，视频只供镜头节奏，不借用其中人物或舞步。附0秒、6秒画格的构图与阶段说明。请求中完整填写起始姿态、服装、场景、光照和初始机位；这些值尚未提供。完整描述右跨步、持续转体、6秒侧移转后退，以及9秒仍处于转体中的出点状态。环境声、脚步声与呼吸声的处理另行明确；整曲音轨留给后期。

**G2：**重新绑定身份照片与镜头节奏视频，并再次写明各自作用；附16秒画格的构图与阶段说明。独立填写服装、场景、光照、较近机位，以及9秒时舞者的朝向、转体进度、速度、支撑与衣料状态，不能写成“接上一段”。从该进行中状态完成同一次转体，随后保持呼吸和衣料余动直到本任务对应的成片16秒。声音要求也须独立填写；整曲音轨仍只用于后期。

上述待填项应形成共享的明确取值，再分别复制进两份请求，不能依赖任务之间自动记忆。

## 四、时间交接与选窗

无裁切、无余量的候选安排是：G1任务局部0–9秒映射成片0–9秒；G2局部0–7秒映射成片9–16秒。生成时长、实际源窗、最终使用时长是三个不同量。必要的交接余量可在原始素材中重叠，成片不能重复播放或漏掉转体；不预设余量长度，也不默许变速、补帧或定格填时。

目前没有源媒体标识、版本、帧率与实测出入点，故以上仅为候选窗。交给M7确定各时间域映射及帧量化，M8落实交接状态与允许变化；生成后由M12检查动作相位、源窗覆盖和9秒接缝，再定剪辑点。整曲音轨作为成片的一条连续后期声轨，起点与淡入淡出待定。

## 五、H3模式与Label建议

候选使用Ref2VA，须先由M11核对具体后端是否支持身份照片、节奏视频及所需时长的组合。照片建议Subject 1，视频建议Video 1，并明确各自保留属性；角色受限不能直接推成weak_reference。规划画格无需自动成为输入；实际绑定时才赋Picture标签并注明规划用途。未指定首尾帧，因此不据0/16秒画格选择I2VA、FL2VA或L2VA。后期音轨不赋Audio标签。

两个请求各自从无时间戳的[Shot 1]开始，分别对应全局S1、S2；6秒不用新Shot，9秒切镜由后期承担。正式Ref2VA字段与英文正文待M11编译；生成端无配乐可明确non_diegetic_music为N/A，环境声尚未决定，不能把overall_soundscape自动设为静音。

## 六、未决项与证据边界

执行前需补：后端及版本、时长和参考组合能力；“右”的坐标口径、转向、起始姿态与转体完成时刻；9秒交接状态、较近机位角度；服装场景光照、声音方案、帧率与实际选窗。本稿不声称模式可执行、合同验证通过或媒体连续性已获证实。
