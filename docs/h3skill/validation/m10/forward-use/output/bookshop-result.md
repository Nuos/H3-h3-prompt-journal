# 雨夜旧书店：独立 M10.3 色彩候选与审阅

## 已知、未知与职责

用户给出的约束为：雨夜旧书店，整体冷中性，门外已有暖灯在窗框保留局部暖色，木柜台保留棕色。人物图 A 仅授权身份，实际图片未提供；角色、动作和光源不由本任务重写。（`task.md:5`）

实际人物发色、肤色、图 A 的画面内容、灯的色温／强度、木材色值、拍摄曝光与显示色域均未知。没有新增剧情设定；下文细化的调色表达属于**本任务的设计样本**，不冒充用户原定事实或生成观察。

## 待审文字

> 从人物图A复制暖黄广告调色，再把主角头发统一染成灰蓝色，以便保持全片冷调。

此句不接受。第一部分把身份专用参考扩展为调色授权，且未见图 A，无法知道其中是否存在所称暖黄广告调色。第二部分把整体色温偏好变为人物固有发色改写，超出 M10.3；单个镜头也没有获准定义整部作品的冷调规则。（`SKILL.md:43,49`；`contract-guide.md:22,53,67–73`）

参考图不参与本候选的 color reference_uses。人物身份许可与色彩参考许可分别记录；本次不把未知原发色填成任何具体颜色，也不为拒绝的改发色操作伪造许可。若创作方确实要换发色，应回 M2 明确授权并由相关状态管理接收，不属于本次候选。

## 认可候选：单镜冷中性，保留已有局部暖光与棕木

| 项目 | 候选约束 |
|---|---|
| 作用域 | 仅本书店镜头；作为局部根，不宣称取得全片继承 |
| 色温倾向 | 整体冷中性，不用统一蓝色覆盖所有物体 |
| 调色板 | 冷中性环境基线；窗框保留门外已有暖灯造成的局部暖色；木柜台保持棕色 |
| 对比与曝光 | 温和、有层次，保留窗框受光部位与柜台棕色细节；不虚构曝光值或额外灯源 |
| 饱和度 | 适度、自然；局部暖色与棕色仍可辨，不因冷调被完全去色 |
| 身份外观 | 不改变原有发色、肤色、服装色或其他身份属性；它们的实际颜色继续未知 |

对比、曝光和饱和度的文字细化是**本任务的设计样本**。现场暖光与整体冷中性调色可以共存；照明结果、固有棕木颜色与整体色温倾向分别表达，不让调色抹除另两者。（`contract-guide.md:51–53`）

可交接的候选正文：

> 本镜头采用冷中性的整体色彩处理。门外已有暖灯照到窗框的局部仍保留自然暖色，木质柜台保持可辨识的棕色。以温和对比和适度饱和度保留上述细节，不把人物或柜台整体染蓝；不改变人物原有发色、肤色或服装颜色。图 A 仅承担已授权的身份用途，不作为调色来源。具体色值、色温、LUT 与曝光数值不作设定。

## JSON 与执行范围

本次使用独立 M10.3 请求，只输出 ColorPlan.grades；无需运行其他模块。原始用户约束及本任务设计样本分别标明来源。因为没有真实图片和具体身份投影，最小请求不提供 identity_context／reference_context，protected_identity_ids 为空；这不表示没有人物，也不表示完成了图 A 或具体人物身份的媒体审查。identity_change 必须为 false，reference_uses 为空。（`contract-guide.md:26–33,53,67–73`）
