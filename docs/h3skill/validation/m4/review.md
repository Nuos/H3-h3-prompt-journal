# M4 实际审阅与文字使用记录

日期：2026-11-05。对象：`h3-action-performance` v0.1.0，合同 1.0.0。读取仓库基线：`545a99015cfa00a6f07ee05d1d0f21e09d89d46c`。

## 1. 审阅范围

主开发者检查了技能入口、三个专业规则、案例证据登记、H3 模式与 Label 映射、公开合同、注册表、脚本、测试源文件和实际运行结果。两次文字使用由分别启动且不继承开发对话的 Agent 执行：只收到技能入口、任务输入路径、产物位置与读取范围限制；没有提供测试源、其他试用答案或预期评分。它们可以按入口读取必要资源，实际读到的文件和哈希由各自的 `read-manifest.json` 保存。

本记录不是外部第三方认证，也不是无技能对照实验。没有测量宿主自动触发率、H3 成功率或媒体收益；未提供的 token、耗时等指标不补造。自动检查只证明实际覆盖的合同关系与可运行性，文字试用只证明对应输入下的使用结果。

## 2. 开发审查中修正的实际问题

| 问题 | 修正与依据 | 复核方式 |
| --- | --- | --- |
| 巨型整数版本触发浮点有限性转换溢出 | 整数直接按整数判断，仅对浮点检查有限性；布尔不能充作版本 | 运行测试中的巨型整数、布尔和非有限数字负例 |
| 外部透明 JSON 中的 `state`、`source_refs` 被误当 M4 协议 | 对 `ExternalContext.values`、只读投影值和状态属性容器保持其约定的透明边界 | 外部载荷／投影回归及保真比较 |
| 诊断将带 `/` 的整段路径转义成一个不存在的键 | 分层构建 JSON Pointer，保留精确问题定位 | 版本不匹配诊断的路径断言 |
| 作用对象只允许道具／环境 | 允许另一 actor 成为视线、回应、触碰等事件的对象；执行者仍须 actor | 另一人物作为视线对象的测试 |
| 普通因果依赖被错误要求状态完全继承 | 只对 `continuation.next` 明确相邻边比较状态；普通 `depends_on` 不推导相等 | 三事件非相邻依赖、冲突继承和缺项继承测试 |
| “动作段终结”与“不能再有任何因果后继”混淆 | terminal 表示该动作段结束，仍允许作为后续段的因果前提 | terminal 与普通后继共存测试 |
| 下游读取登记缺少 M9／M11／M12 | 增加三个消费者；M9 当前以文字交接分段需求，不冒称已有结构化请求合同 | 影响分析与所有权检查 |
| 非法来源内容在 trace 阶段掩盖形状诊断 | 对未通过结构检查的载荷作类型保护，保留原 `contract_shape` 和退出码 1 | `sources.fixture_d=null` 的真实 CLI 回归 |
| 透明 JSON 使用普通相等时混同布尔和数字 | 使用规范化 JSON 比较原请求／投影，保留 JSON 类型差异 | 只读输入和投影保真负例 |
| 父节点登记与冻结模块名称不一致 | M4 与三个公开子模块均登记完整原则、接口和资源；父节点名称统一为“人物表演、动作链与物理因果” | 最终测试、资源清单和发布核验 |
| 长案例证据文件缺少导航 | 在证据文件入口增加五组章节导航，保留证据 ID、原始案例和正文判断 | 发布核验定位该问题后修正，并重跑受影响的交付哈希与发布检查 |

状态属性的检查只比较同名属性键的明确字符串值，不能识别自然语言同义词、求解身体动力学或证明真实接触。此限制已经写入合同指南和工具结果。

## 4. 两次独立文字使用

### 4.1 事件与前提的独立调用

原始[任务输入](forward-use/events/input.md)、[请求](forward-use/events/request.json)、[M4.1 提案](forward-use/events/proposal.json)、[实际命令记录](forward-use/events/check-run.json)、[原始检查输出](forward-use/events/check.stdout.json)、[说明](forward-use/events/output.md)与[读取清单](forward-use/events/read-manifest.json)均已保存。

实际 `check --request` 执行一次，退出码为 0，`local_contract=pass`、`overall=unverified`。主开发者逐项对照原输入检查了三个事件：双手从右脚脱袜、单手持袜并空出另一手、转头看袜并举起查看；人物、白袜身份及事件先后关系均保留。第一事件保留右脚穿袜悬空、左脚赤脚支撑；后两事件保留右脚赤脚悬空。最终持袜手的左右没有被擅自决定，提案保存了两处明确未知及一个非阻断问题。

提案只写 `events`，没有填写 M4.2、M4.3、绝对秒数或 M8 权威状态。工具分别给出两个 `coverage_unavailable` 非阻断诊断，准确保留机制和结果分区尚未验证的状态。输入中的案例来源仅被作为任务背景，试验没有声称看过原视频或将案例作者的效果判断当成本轮观察。

读取清单的 SHA-256 是源文件原始字节摘要；运行 trace 对 schema／registry 采用规范化 JSON 摘要。两者不能直接据数值不同判定版本变化。本次对这一记录口径进行了说明性修正，实际请求、提案和原始运行输出保留不变；最终按相同摘要范围核对来源。清单中对试验者自己报告初稿的两次读取保留当时的哈希，对应 `output.initial.md`，不能要求其等于经过修正的最终 `output.md`；任务输入、技能资源及实际运行输入均与对应最终记录匹配。

本试验达到限定三个事件的 M4.1 交付目标。父接受、机制、结果和真实表演均不在该试验的通过范围内。

### 4.2 剑舞接续与参考权限审计

原始[任务输入](forward-use/continuation/input.md)、[实际输出](forward-use/continuation/output.md)与[读取清单](forward-use/continuation/read-manifest.json)均已保存。主开发者在产物写出后按任务逐项复核：

- 识别 Ref2VA 主正文字段错用、身份图被误作首帧、再次拔剑、未经批准改为左手、运动参考被扩大为完整人物／场景／剪辑／音轨继承。
- 删除没有依据的 `2.000` 秒及特写切点，没有为了修复冲突擅自增添入鞘、交接、时间省略或状态重置。
- 英文片段保留剑舞及限定运动质地借用，明确“唯一原剑已出鞘、解剖学右手持有、原剑鞘固定腰侧且为空”的计划入出态。
- 将实际动作源选段、支撑／朝向／轨迹、时间窗、完整标签绑定和媒体表现保留为待补条件；正确区分中文审计、英文动作片段与完整六字段交付。
- 没有运行结构校验器，因此明确不宣称结构检查通过；没有真实媒体，因此明确不宣称动作物理或连续性门禁通过。

主开发者复核该试验记录的 9 个来源文件 SHA-256，均与最终文件匹配。读取清单特别注明了长工具输出展示截断：完整文件字节被读取或用于哈希，不等于其中每一行均完成语义审阅；案例引用只采用已显示的片段。本轮保留这一限制，不把该记录升级为全文理解证明。

本试验达到给定输入下的文字审计目标；英文片段仍是需要 M2／M3／M7／M8／M11 补足依赖的语义草案，不是完整可提交的 H3 请求。

## 5. 案例和官方资料的证据限度

案例库存覆盖 29 案、98 个文本；3 个全文读取、5 个片段读取、90 个仅库存。规则逐项保留原作用域：已出鞘状态、支撑脚、接触切换、动作速度等不扩大为普遍限制。原案例作者的效果判断保留作者归属；本轮媒体观察与 H3 调用均为零。

多人交互和动作迁移相关检查属于接口设计，不以只登记库存的案例冒充实测。官方 MiniMax 文本只界定五模式、字段、四类 Label 与格式；Anthropic／Agent Skills 文本只界定技能创建方式。协议快照、来源许可与开发标准都有固定提交和文件哈希。

## 6. 结论的准确范围

本轮交付一个可独立复制、按需加载、可独立调用三个子模块并进行父接受的 M4 技能包。其确定性工具能拒绝已覆盖的合同、引用、版本、所有权和显式状态冲突。专业文字判断、实际身体／道具物理、声音与时序、完整 M11 编译、H3 推理、生成片验收仍需要各自输入和执行证据；没有将本轮结果升级为全局 G0—G4 或十二模块全部完成。
