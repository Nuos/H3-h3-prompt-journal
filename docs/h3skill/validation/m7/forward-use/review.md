## 试用后修正与保留限制

1. **显示值不能再次替代权威数据量化。** 试用者指出从1.067秒反推编辑ceil会把182帧推进到183帧。专业参考和合同指南已明确保留精确帧号／有理时间，显示误差另算。
2. **视觉切换类型仍需明确。** 原始M11交接把任务中的“视觉切换”称为第二镜；根代理判定题目没有明确cut类型和目标视角。原稿保留，补充[m11-handoff-reviewed.md](mapping/m11-handoff-reviewed.md)，只交接边界并按真实编辑类型决定是否生成Shot。H3映射文档补充了同样要求。此项说明数值通过不能替代文本语义审阅。
3. **诊断定位的可读性限制。** 某些未知重复出现，部分路径属于合并检查的分区视图，不直接等同于原JSON位置。合同指南已说明如何对照Request.inputs／Proposal.context，且不把虚拟路径误当子模块写入权限；本版未做诊断去重。
4. **开发中先行读取的失败。** 两次试用开始时合同指南仍在并行落盘，首次读取失败已如实保留；正式交付版本文件完整，后续均完成核对。未将该历史失败伪装成当前版本的读取结果。

这些是一次有记录的实际使用与复核，不是自动触发率、普遍成功率或盲测性能基准。没有运行H3、听音、解码视频或验证口型、真实卡点及成片质量。
