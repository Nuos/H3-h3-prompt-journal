# M9.3 生成任务划分

## 职责

将已经决定的内容、镜头与编辑结构分配给独立模型请求，形成 `GenerationPlan`。读取带版本的能力资料和当前有效的镜头、时间、连续性、声音及参考权限投影。任务结构由 M9 决定，H3 模式、素材编号、最终字段与实际运行参数由 M11 编译。

本模块不是视频生成器，也不保证一个合法请求必然生成所需画面。未取得真实能力证据时可以完成候选拆分，但应明确哪些容量与输入组合尚未核实。

## 分开三个范围

| 范围 | 用途 | 责任关系 |
| --- | --- | --- |
| 生成内容范围 | 模型一次运行需要覆盖的镜头／阶段，必要上下文及余量 | M9 分配；M7 排时；M11 编译／核对能力 |
| 候选源窗 | 打算从生成片或其他源片中采用什么内容 | M9 选择；实际可用性由 M12 观察 |
| 成片使用区间 | 候选源窗进入最终作品的实际位置与时间长度 | M9 装配意图；M7 权威映射；M12 成片检查 |

没有先验理由要求三个范围时长相等。一个目标片段可以由多个任务生成后择窗，一次生成也可以含多个真实镜头。拆分目的必须明确，如能力限制、状态难点隔离或独立段落；不能只按照案例原有 SEG 数机械复制。

## 实施步骤

1. **读取能力证据。** 保存后端／工作流 ID、版本、支持模式、适用的输入与时长条件以及证据来源。能力对象由 M11 或兼容外部资料提供；“H3 通常支持”不等于本次工作流已确认。
2. **分配内容。** 为每个任务列明镜头及阶段，区分完整覆盖、局部覆盖、候选重叠和有意重复。不得无解释地遗漏必保阶段，也不把重叠候选自动重复放入成片。
3. **设置边界。** 明确入段和出段需要哪些状态与动作阶段，关联 M8 的允许变化及交接条件。连续任务不能每段重置站姿、重新拔刀或重启音乐；独立蒙太奇则按其保留关系组织。
4. **补齐独立上下文。** 给出本段主体和参考权限、场景／站位、必要起态、动作链、摄影方案、声音策略、结束条件和实际使用的输入素材。全局剧情摘要不能代替本段可见可听事件。
5. **分配模型内切镜。** 对本次生成目标中的真实镜头建立局部序列；M11 从 `[Shot 1]` 编译，M7 提供局部切点。只在后期发生的转换留在编辑结构，不给模型制造多余事件。
6. **核对可执行性。** 内容容量、首尾帧、声音时长或参考组合与能力冲突时，向 M7／M11 返回具体诊断。需要改动作、声音或作品目的时再回对应责任方，不能静默裁掉关键内容。
7. **形成交接。** 输出任务与稳定镜头的对应、所需输入、有效计划版本、模式候选及其依据、编译依赖、边界检查点和未核实项。

## 自包含不等于重复全部资料

只传本任务需要的可复用语义及已绑定素材；保留来源 ID／版本，不复制整套全片工程文档。必要的状态应直接写明，不用“和之前相同”让模型依赖未提供的历史。人物身份与本段姿态分开，同一张身份图不能覆写已批准的持物状态。

音乐 MV 的新任务不自动重启整条音轨。M6 决定复制、部分复制、参考或新生成，M7 对齐源窗口与目标时域，M9 只安排这项声音关系如何穿过镜头与装配边界。若音轨只在后期铺底、未提供给本次模型作为输入或参考，就不自动创建生成请求中的 `<Audio N>`；成片音轨策略留在编辑交接，生成阶段的声音需求另行明确。

## 首尾帧与参考模式

- **I2VA：** 真实首帧约束本任务的开场；不能一边要求完全对齐，一边用身份参考理由忽略其姿态。
- **FL2VA：** 首尾图分别约束本任务两端，通常优先单镜；只在用户明确指定多镜时采用多镜路径。尾图落在实际末镜。
- **L2VA：** 尾图约束末态；从合理先态到尾图的过程需要明确，不能从尾图反称前段事件已有证据。
- **Ref2VA：** 参考图、故事板、视频结构、运动与音频按真实角色绑定。仅参考源视频运镜和剪辑节奏通常属于 `reference generation`，不自动等于编辑源视频或续接源视频。
- **T2VA：** 从文字构建本任务完整事件与镜头结构，不伪造不存在的参考素材。

详细语法见 `h3-label-mapping.md`。候选模式不等于已执行请求，输入数量和时长也不从本地提示词字数反推。

## 完成与失败

任务 ID、内容分配、独立上下文和边界已登记，只能说明计划可被交接。实际能力资料、正式编译或媒体结果缺失时保持对应未验证。特别区分“候选任务能表达目标”“请求满足已知能力”“视频实际呈现目标”三个结论。

拆分、选窗或媒体版本改变时，保留历史并使受影响的编译与接缝结论失效；不要把旧任务的通过标记搬到新任务。明确停止条件、修复责任和重新进入点，避免无限反复自评。
