# M9 与 H3 五种输入模式、字段及 Label 的对应

## 核心摘要

M9 提供镜头、编辑和生成任务的专业语义，M7 提供时间换算，M8 提供状态条件，M11 负责最终 H3 字段、素材编号和参数。M9 的 `ShotMap`、`EditGraph`、`GenerationPlan` 均为内部制作对象，不能作为 H3 新字段直接提交。

本表核对固定官方版本 `MiniMax-AI/MiniMax-H3@199b7d0e1fd95e7b3eafa8c15eca692534142427`。**B** 为本包 `h3-base-official.txt`，共 222 行；**R** 为 `h3-ref-official.txt`，共 341 行。行号从原文件第 1 行开始，快照不添加页眉或重新编号。P 表示官方协议，D 表示 M9 的编排／审计设计。

**关键词：** H3 模式、真实镜头、Shot、Picture、Video、Subject、Audio、源窗、生成任务、局部时间。

## 1. 五模式与三个子模块

| 模式及官方依据（P） | 官方结构 | M9 的编排要求（D） | M9 的审计问题（D） |
| --- | --- | --- | --- |
| T2VA：B L5、L14、L36–48 | 无图片对齐首行，直接三个核心字段 | M9.1 组织真实镜头及镜内阶段；M9.2 给出需要在目标中生成的切点；M9.3 分配本次任务内容 | 是否把动作阶段、故事板格或后台任务机械写成新镜头？是否凭空引用素材？ |
| I2VA：B L6、L16–20、L52–56 | 首帧对齐指令＋基础三字段 | 把实际首帧映射到本目标 0.00 秒与第一镜，再向后发展；为独立任务确认自己的起点 | 该图是真实首帧还是身份／构图参考？实际首帧是否与安排的起态冲突？ |
| FL2VA：B L7、L22–26、L58–64 | 首尾帧对齐指令＋基础三字段 | 连接两端可观察路径；尾图属于实际末镜、有效时长末端；通常单镜，只在明确指定时多镜 | 有无把每张故事板格强制当切点？新增多镜是否有明确依据？最后画格是否真是模式尾帧？ |
| L2VA：B L8、L28–34、L66–70 | 尾帧对齐指令＋基础三字段 | 以末图为落点规划前序与末镜，向 M8 请求相容状态 | 是否错误把尾图放在开场？是否凭尾图宣布前序动作已经发生？ |
| Ref2VA：R L13–37、L215–242 | 六字段，主正文为 `detailed_description` | 镜头／阶段、参考角色、保留范围、局部时序和任务上下文一起交 M11 | 是否误用 integrated 字段？是否把结构参考误判为编辑／续接？是否把后期操作塞进每个任务？ |

M9.1 管理归属，M9.2 管理选择与边界，M9.3 管理独立任务结构；三个子模块均可为五种模式提供语义交接。支持这些交接不代表当前后端已启用全部模式，实际能力须有 M11 或兼容外部来源。

I2VA／FL2VA／L2VA 的固定首行由 M11 按 B L16–34 原样序列化；其中末镜 N 和有效时长来自当前目标及 M7，不沿用全片的镜头编号或源音频全局时码。

## 2. 逐字段编排与审计

| 官方字段（P） | M9 提供的内容（D） | 核对要点（D） |
| --- | --- | --- |
| 基础 `integrated_multimodal_description`：B L46、L76–92 | 本次目标的镜头顺序、镜内事件、动作阶段、切镜及其可见结果；声音事件引用 M6 | 描述完整可见／可听过程；切点有信息变化，阶段和轻微机位变化不自动成为切镜 |
| Ref2VA `subject_definitions`：R L25–73 | 当前目标需要独立追踪的内容与素材角色；分镜图说明对应镜头及规划信息 | 每个标签定义什么、来自哪里、作用于谁？只有外观来源的图片是否误建成具体帧条目？ |
| Ref2VA `summary`：R L121–153 | 目标类型、镜头流向、编辑／续接／结构参考及音频关系 | 按真实关系选择任务前缀；仅参考 cuts／rhythm 通常是 `reference generation`，不是 `video editing` 或 `video continuation` |
| Ref2VA `retention_analysis`：R L157–207 | 对已定义角色说明保留、改动、迁移或参考范围；逐镜出现位置 | 标签含义与定义一致；“保留剪辑结构”不能自动授权复制主体外观；新动作不等于身份参考失真 |
| Ref2VA `detailed_description`：R L211–258 | 在整体风格开场后逐镜说明构图、主体位置／外观、场景／光线、动作变化、摄影机、当前声音和参考生效点 | 全画面动态不能缩成剧情概要或参考关系列表；真实切镜与同镜动作、每任务起终条件明确 |
| `overall_soundscape`：B L152–158、R L21 | 与编辑范围相容的环境声、动作声、非言语人声及跨切关系，语义来自 M6 | 不重复整段对白／歌词；未提供声音方案不等于完全静音；只有用户要求整个目标完全静音时用 `N/A` |
| `non_diegetic_music`：B L160–166、R L22 | 仅观众可听的配乐在当前目标内的持续、变化和收尾，引用 M6／M7 | 角色可听音乐属于镜内叙事事件；没有非叙事配乐时用 `N/A`；后期铺底与本次模型音轨不得混淆 |

基础四模式字段顺序：`integrated_multimodal_description` → `overall_soundscape` → `non_diegetic_music`。Ref2VA 顺序：`subject_definitions` → `summary` → `retention_analysis` → `detailed_description` → `overall_soundscape` → `non_diegetic_music`。

Ref2VA 六部分用英文；对白／歌词 `<d>` 内和画面实际文字保留原语言（R L5、L217；B L129–150）。M9 的中文制作记录可以独立保存，不把内部审计说明翻译后插入最终正文。

## 3. 四类参考 Label

| Label 与官方依据（P） | M9 中的合法作用（D） | 错误用法与审计（D） |
| --- | --- | --- |
| `<Subject N>`：R L41–58 | 可重用的可见内容，包括人物、场景、物件、衣物、动作、姿态或效果；一主体可有多来源 | 它不是源文件序号或镜头编号；不要用 Video 标签替代来自视频的可见动作主体 |
| `<Picture N>`：R L62–73 | 具体首／关键／尾帧、修改后的关键帧、构图或故事板规划锚点；注明对应哪些镜头及规划维度 | 一个故事板图可约束多镜，一镜也可有多格；只提供身份／服装的图片在 Subject 定义里引用，不机械建立独立 Picture 定义 |
| `<Video N>`：R L77–88 | 直接编辑源、续接起点或整个视频的摄影机／切镜／节奏／时间结构 | 仅借用结构不等于直接编辑／续接；内部任务 ID、输出候选或剪辑实例不自动变成 Video 标签 |
| `<Audio N>`：R L92–118 | 当前目标中确实被复制或参考的独立音频或启用的同步音轨 | 文件自带声音不代表启用；仅后期铺底且未交给模型的音轨不自动成为本次生成输入；视觉与音频索引独立 |

同一标签在定义、摘要、保留分析、逐镜正文与声音字段中保持同义（R L35–37）。如果 Picture／Video 只是另一项的来源且后续不单独分析，就在该项定义内部引用，不增加无用途的独立条目。

引用动作与引用时序分开：可见动作来自 `<Subject N>` 的授权内容，整段切镜／节奏关系可由 `<Video N>` 表示。内部 `phase_id / panel_id / shot_id / task_id / clip_id` 只是制作合同，不新增 `<Phase N>`、`<Grid N>` 或 `<Task N>`。

视觉关系标记固定为 `fully_preserved`、`partially_preserved`、`attribute_transfer`、`weak_reference`；音频关系为 `fully_copy`、`partially_copy`、`reference`、`weak_reference`（R L161–207）。标记作用于该标签已经定义的角色，不可事后扩大参考权限。

**先确定角色，再确定该角色内的保留程度。** “只参考身份”或“只参考剪辑节奏”只是缩小角色范围，不能据此直接选择 `weak_reference`；若该已定义角色的特征全部保留，应按实际关系审查 `fully_preserved`。没有决定严格继承还是宽泛借鉴时保留等级待定，不靠“参考内容少”推断等级。

`fully_copy` 指完整源音频成为目标最终全部音轨；只保部分时间／声层，或复制后新增、移除、替换声音时，按实际关系检查 `partially_copy`。仅复制内容语义、节拍风格或音色而不复制信号时，检查 `reference`。M9 发现矛盾回传 M6／M11，不自行改声音策略。

## 4. 镜头、任务、时间与声音语法

**真实切镜。** B L86–92、R L215–223 要求第一镜 `[Shot 1]` 不带切点时间戳，后续镜头使用顺序编号及严格递增、位于有效视频时长内的切点。例如 `[Shot 2] At 00:03.500, ...`。起始风格在基础模式的第一镜内说明；Ref2VA 在第一镜前用一两句建立整体风格（R L228–242）。

模型正文中的叠化、淡入淡出或擦拭按 B L92 要求，在用户明确指定时使用；后期候选桥接不能自动成为这种生成要求。首尾帧首行也不做统一化美化：FL2VA 原模板的 `Picture 1 (from Shot 1)` 与 I2VA／L2VA 的括号形式不同，由 M11 按各自原文保留。

**任务局部作用域。** 每次独立请求都是一个目标视频，建立自己的第一镜与局部时间；全片稳定镜头 ID 保留在制作对照表。两次独立生成同一规划镜头，不意味着第二次请求从 `[Shot 2]` 或上一任务结尾时码开始。此作用域规则是依据官方目标视频语义形成的 M9／M11 交接设计。

**同镜变化。** 摄影机从横移转为后退、动作从下落进入接触、分镜格从第 2 格到第 3 格，都可能继续留在同一 `[Shot]` 内。只有实际剪辑事件才建立后续镜头。若旧稿把 Shot 当动作章节，应先用 M9.1 重建真实镜头，再编译。

**时间来源。** M9 提供源选择、事件切点和编辑意图，M7 负责坐标换算与量化。源音乐 33.916 秒、段落 6.958 秒、后一个生成任务 0 秒可以指向不同坐标中的相关位置，不能混写成同一个时间值。精确数值需要有效映射，不能由 M9 自行代算后声称已同步。

**发声与切镜。** 同一句对白或歌词跨切时，用 `<scenetrans>` 连接两部分并明确声音连续；视频结尾截断语音用 `<cutoff>`（B L127–142、R L218–223）。全局说话者 `(Sx)` 跨镜保持，静默角色无 speaker ID；Audio 编号不是 speaker 编号。M6 保留原词与发声语义，M7 排时，M11 序列化。

官方 R L242 的 350–500 英文词是一般生成任务建议，对话密集与编辑任务另有说明；不是 M9 的硬字数上限，更不是后端 token 能力证据。必要状态、事件或边界不能为了机械限字而删除。

## 5. 模型内生成和后期装配的边界

| 制作决定 | 本次 H3 正文是否表达 | 留在制作交接中的部分 |
| --- | --- | --- |
| 一次目标内部从远景硬切到近景 | 是，按真实镜头与局部切点描述可见事件 | 切镜理由、审计过程和源证据 |
| 两个任务后期硬切或匹配连接 | 每个请求写自身起终态与必要过程，不自动各写一次切镜特效 | 装配顺序、源窗、匹配条件与真实接缝待核验 |
| 后期溶解／视觉桥梁 | 仅在决定由模型生成该可见转换时表达；否则保留给后期 | 编辑操作及其执行环节、转场范围与时间映射 |
| 多生成一段再选择最合适相位 | 写任务需覆盖的内容与边界条件 | 候选余量、选择依据、实际观察和采用窗口 |
| 演员短暂保持姿态 | 写呼吸、支撑与必要余动，遵守 M4 | 不自动改成编辑冻结画格 |
| 后期冻帧／变速 | 不把剪辑软件操作冒充人物动作 | M9 意图、M7 映射、M6 声音影响及 M12 实际检查 |
| 完整音轨仅在后期铺底 | 不凭此给生成请求虚构 Audio 输入；生成声音策略另由 M6 明确 | 成片音轨及其源版本、坐标、同步与许可 |

已选窗口不是模型凭一句“取最好一帧”能够事先证明的事实。源片未生成或未观察时保留候选与未知；M12 取得实际证据后再由 M9 修订选择。

## 6. 旧案例语法迁移及交付检查

案例可出现 `[Shot 5 | 9.208–11.875s | ...]`、裸 `PICTURE 1`、自定义六字段、基础首行与 Ref2VA 字段混写。这些是领域方法的历史证据，不能覆盖本包固定官方协议。

迁移时先保存原文和来源，分开动作章节、真实镜头与生成任务；由 M2 确定素材角色，M7 确定局部时序，M8 提供必要状态，再由 M11 编译。白凤双生成说明保留原导演稿为依据，M9 的执行映射和独立任务上下文不等于授权改写原稿。

逐项核对：五模式正确、字段集合及顺序正确、每个真实切点可定位、标签始终同义、参考作用时地明确、任务输入实际存在、首尾帧角色不混用、后期操作没有误入模型要求、声音来源与阶段一致。上述是协议与文字审计，不能据此宣布 H3 已实现画面、无缝拼接或成片质量通过。
