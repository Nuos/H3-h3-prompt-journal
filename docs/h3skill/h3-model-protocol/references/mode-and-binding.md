# M11.2 模式选择与素材序列化绑定

**核心摘要：** 按素材在目标视频中的用途选择模式，之后确定素材输入顺序和各类别标签。保留稳定实体／资产 ID 与 H3 序列编号的对应。

**关键结论：** 一张图可能是身份参考、真实首帧或真实尾帧；视频存在声音不等于启用了音频参考。

**关键词：** 模式、用途、首尾帧、Subject、Picture、Video、Audio、绑定。

**目录导航：** 1. 模式判断；2. 素材与标签；3. 参考关系；4. 审计与回传。

## 1. 先判断任务关系

| 已确认的用途 | 候选模式 | 必须保留的关系 |
| --- | --- | --- |
| 无参考，文字生成完整音画 | T2VA | 无图像对齐首行 |
| 单一实际首帧，向后发展 | I2VA | 0 秒、第一镜、实际首帧 |
| 实际首帧与尾帧之间的过程 | FL2VA | 两端真实图像与中间可观察变化 |
| 只规定实际尾帧 | L2VA | 最终镜头在有效结束时刻达到尾图 |
| 内容／风格／动作参考，分镜或中间帧，多种素材关系，视频编辑／续接，音频复制／参考 | Ref2VA | 明确每一参考的角色、目标和生效范围 |

表中是协议候选关系，实际还需 profile 支持。显式模式与素材用途矛盾时返回诊断，不偷偷换模式。只有首帧或尾帧并不排斥 Ref2VA 的帧锚表达；若选择 Ref2VA，须完整采用六字段及其参考规则。

FL2VA 原文倾向单镜连续插值；多镜仅在明确需要时使用。不要将这一倾向变成所有多参考任务的硬性单镜要求，也不要为了符合模板新造切镜。[B:60–64]

## 2. 建立两层标识

先保留 M2 提供的稳定 `asset_id / entity_id` 和实际来源版本，再生成本次请求内的 H3 标签。更换输入顺序时更新所有派生引用；不能从 `<Subject 2>` 推断某个永久角色 ID。

| Label | 用途 | 序列化与审计要求 |
| --- | --- | --- |
| `<Subject N>` | 从素材抽象出的可复用可见内容，包括人物、场景、物件、服装、动作、姿态、风格和效果 | 一个 Subject 可取自多个资产，一个资产可提供多个 Subject；标签不等于输入图片槽位 |
| `<Picture N>` | 具体帧、构图或分镜锚，也可只标明 Subject 的图片来源 | 来源型图片在 Subject 定义里引用即可；独立使用的帧／分镜才建立独立条目，并说明作用于何镜何时 |
| `<Video N>` | 编辑源、续接起点、整段运镜／剪辑／节奏／时间结构 | 源视频中的人物、动作或场景仍用 Subject；不能用 Video 替代内容主体 |
| `<Audio N>` | 被复制或参考的独立音频、明确启用的视频同步音轨 | 编号独立于 Video；记录来源音轨、用途与有效窗口，不自动继承未启用声音 |

输入清单要能回答：哪个资产版本、哪个通道、在实际输入顺序的哪个位置、贡献哪个引用内容、允许保留哪些属性、在哪一段生效。仅提供网络地址或路径不是本脚本已验证文件可读的证据；文件存在、媒体解码和绑定到真实控件需执行方再核对。

同一图片只提供身份时，不自动继承姿态、镜头、背景、衣物或灯光。若图片已作为实际首帧／尾帧输入，不能再用一句“仅身份参考”消除它的真实帧约束。权限问题回 M2，起末态冲突回 M8。

## 3. 在定义的用途内确定保留关系

| 对象 | 合法关系值 | 判断原则 |
| --- | --- | --- |
| Subject／Picture／Video | `fully_preserved`、`partially_preserved`、`attribute_transfer`、`weak_reference` | 对照该条目已经定义的角色及属性；新增背景或后续动作不自动降低已定义身份的保留程度 |
| Audio | `fully_copy`、`partially_copy`、`reference`、`weak_reference` | 先判断是否复制同一信号，再判断完整最终音轨、局部／分层复制或仅参考 |

少数属性引用不等于 `weak_reference`；若明确身份属性被完整保留，仍应按定义的身份范围判断。`fully_copy` 要求完整源音频就是完整最终音轨，新增脚步声、删除环境声或仅截取窗口都不符合此关系。

Ref2VA 摘要的任务类型按真实用途组合、去重：`keyframe completion`、`reference generation`、`video editing`、`video continuation`、`audio reuse`、`audio reference`。只参考视频运镜通常是 reference generation；不是 video editing。只参考音色而不复制信号使用 audio reference。

## 4. 审计与回传

核对声明的模式、媒体类型、用途、输入顺序、引用标签、定义与保留分析，确认不存在丢失资产、标签复用成别的主体、未启用的音频或新增权限。槽位和编号错误归 M11.2；资产来源／权限冲突归 M2；编辑／续接语义归 M9；帧锚时刻归 M7；帧内状态归 M8。

**依据：** B 为基础指南，R 为 Ref2VA 指南；B:5–34、54–70，R:24–118、122–208。当前机器合同支持的精确角色枚举以 `contracts.json` 为准；遇到合同尚不能表示的合法专业关系，明确报告能力缺口，不将它判为 H3 官方不支持。
