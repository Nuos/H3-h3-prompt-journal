# M11.3 提示词字段编译

**核心摘要：** Agent 根据已确认的语义写出自足的英文逐镜描述，确定性脚本完成协议封装、标识替换及显式关系核对。保真性需要正文与计划逐项对照。

**关键结论：** 三字段与六字段分开；公共上下文为每个独立任务展开；脚本追溯不能证明自由文本语义正确。

**关键词：** 语义保真、字段、Shot、Sx、对白、追溯、纯模型正文。

**目录导航：** 1. 编译输入；2. 字段与镜头；3. 声音和文字；4. 清理与核对。

## 1. 从已确认计划取得内容

读取本次生成任务对应的意图约束、主体与参考权限、空间、动作链、摄影、声音、局部时间、状态、真实镜头和有效视觉风格。每段输入保留稳定 ID、版本和来源；无须复制与当前任务无关的整个项目。

把“总体风格”“人物定义”“分镜表”“台词表”等制作组织转成具体镜头的可见／可听内容。每次独立生成都要包含其有效公共上下文；仅写“同上一段”“沿用前述人物”不能保证独立请求自足。保留所有必保事件和原词，冗余可以合并，语义不能无声删除。

Agent 写出完整事件：明确动作的执行者、对象、空间位置、起态、过程、结果及后继反应，并交代同一镜头的摄影、环境、光线和声音。不要将动作名列表、故事摘要或“保持一致”抽象承诺当作完整动态描述。已确定的 M9 镜头结构不能由正文排版重新划分。

为可机器核对的必保内容提供义务 ID 与正文片段映射；有明确原文的台词和画面文字另外保真。追溯记录与正文分离。把一个 ID 挂在无关句子上不会使内容合格，Agent 必须核对语义实质。

## 2. 字段与真实镜头

基础四模式严格输出三个字段；Ref2VA 严格输出六字段。名字按官方原文拼写：`integrated_multimodal_description` 不是 `integrated_multimodel_description`，Ref2VA 的主正文是 `detailed_description`。`camera_movement`、内部对象、导演备注和参数不能随意增为顶层字段。

迁移历史案例时，源文 `final_visual_constraints` 中有效的画面约束要按对象与生效范围转入合法正文并保留追溯，不能因为字段不合法就丢掉约束。`newly_generated` 等非官方保留枚举先还原为其创作语义，再在已定义的参考角色内选择合法关系；不机械替换为某个强度，也不改写源案例。

| 项目 | 基础四模式 | Ref2VA |
| --- | --- | --- |
| 风格起始 | 写在 `[Shot 1]` 内 | 在 `[Shot 1]` 前先写一至两句整体风格 |
| 第一镜 | `[Shot 1]`，不加切点时间戳 | 同左 |
| 后续真实镜头 | `[Shot N] At MM:SS.mmm, ...` | 同左 |
| 参考关系 | I2VA／FL2VA／L2VA 的实际帧对齐首行及主正文 | 定义、摘要、保留分析、逐镜正文及适用声音字段一致 |
| 声音汇总 | 环境／物理声音与观众可听配乐分开 | 同左，必要处保留 Audio 复制／参考关系 |

切点来自 M7 的生成局部时间，镜头身份来自 M9。第一镜为零起点；后续切点严格递增且位于有效时长内。源时间和成片时间先经 M7 映射，不能拿源片 52 分钟上的时间直接写入独立 8 秒任务。

首尾帧首行中的末镜 N 是实际末镜，S.SS 是有效时长且两位小数。FL2VA 与 I2VA／L2VA 的尖括号、方括号形式不同，遵照原文生成，不为“统一格式”修改官方句式。

## 3. 声音、对白与可见文字

1. 根据实际发声事件的先后给声音源分配 `(S1)`、`(S2)` 等编号，跨镜复用。不要按 Subject 编号、角色列表顺序或 Audio 编号分配说话者。共同发声使用已存在编号的组合；无法表示的并发关系交还 M6 明确。
2. 人物或其他独立声音源实际说话时，标明说话者；直接复用 BGM 内的歌词提示仅以 Audio 为来源，不虚构人物发声或口型。引用音色时，不自动搬入源音频台词。
3. 将声音身份、动作和发声方式写在 `<d>` 外。标签内部只放语言与实际台词／歌词。基础模式逐词逐标点保留原文；Ref2VA 对源音频复用／重演的标点规范化保留前后值及授权依据，听不清的内容使用 `[unclear]`，不得猜词。
4. 同一句跨切时，两段连接点使用 `<scenetrans>` 并写明声音连续；在视频结束被截断时使用 `<cutoff>`。缺少切分依据时返回 M6／M7，不擅自删剩余台词。
5. 画外音按官方 `says in an off-screen voiceover` 形式表达；若画面有对应人物，在每段对白后说明该人物嘴唇保持闭合。纯独立旁白不能凭空增加画内人物。
6. 实际可见文字用英文双引号包住，保留原文和标点。完整对白和歌词只放在逐镜主正文，声音汇总不再复述。

`overall_soundscape: N/A` 仅适用于明确全片完全静音。无观众配乐可以使用 `non_diegetic_music: N/A`；这不意味着环境、人物或物理声音静音。所有声音策略以 M6 的决定为准。[B:127–171；R:258–306]

编译时分别声明新生成／重演的发声与直接复制原信号中的发声。完整 `fully_copy` 音轨已有的对白允许按原词写入逐镜正文；不能因此自动将其降为新增声音层。反过来，完整配乐上新增本片台词不能继续宣称完整最终音轨未变。直接复用 BGM 中的语词提示只以 Audio 为可听来源；实际由具体人物或旁白发声时仍保留其 S 编号。具体公开字段见合同指南。

参考音频的复制／参考关系放在相应层：环境与物理声音写入 `overall_soundscape`，观众配乐写入 `non_diegetic_music`，音色与具体台词关系在对应镜头的发声处表达。只有配乐时，环境字段可以明确写无环境／物理声，不把全片误标为静音。[R:282–303]

## 4. 清理与核对

将未解析的稳定引用、未知标签、模板占位符、内部 ID、制作备注、测试结论和 Gate 记录留在诊断中；有阻塞项时不输出伪装可用的完整模型文本。使用本合同支持的占位语法，不在自由文本中手填容易串线的编号。

自由文字可能含含混指代、抽象词、错误因果或相互矛盾的约束，纯字符串检查不能全面识别。正文交付前，Agent 对照计划逐镜审阅动作起止、参考绑定、画面范围、声音来源和必保信息；把语义审阅结论与机械检查结果分开记录。

官方 Ref2VA 的 350–500 词为通常的写作建议，不设置硬截断或 token 限制。字数增长也不自动提高质量；以完整、明确、无无效重复为准。[R:6、215–245]

**依据：** B／R 对应包内两份官方原文；冻结方案要求编译不改变导演决定，案例方法和差异见 `case-evidence.md`。
