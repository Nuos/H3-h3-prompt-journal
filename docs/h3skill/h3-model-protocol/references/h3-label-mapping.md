# M11 与 H3 五模式、字段及 Label 的映射

**核心摘要：** M11 是十二模块中的协议适配责任方：M11.1 提供版本化能力，M11.2 确定模式和绑定，M11.3 编译官方字段，M11.4 映射真实参数。四者适用于五种模式，但内部数据不能冒充 H3 原生字段。

**关键结论：** 基础四模式严格三字段；Ref2VA 严格六字段；素材编号、内容主体、说话者、真实镜头和工作流参数分别管理。

**关键词：** H3、T2VA、I2VA、FL2VA、L2VA、Ref2VA、Label、编排、审计。

**目录导航：** 1. 来源与范围；2. 四子模块；3. 五模式；4. 六字段；5. 逐 Label；6. 声音与镜头；7. 检查边界。

## 1. 来源与范围

协议固定于 MiniMax-AI/MiniMax-H3 提交 `199b7d0e1fd95e7b3eafa8c15eca692534142427`。B 表示包内 `h3-base-official.txt`，R 表示 `h3-ref-official.txt`，行号均从原文第一行开始。两文件保留原始字节；来源、哈希及本轮核对见 `h3-protocol-source.json`。

本文记录官方协议与本模块处理责任。`CapabilityProfile`、绑定结果、编译结果、任务包和义务追溯属于项目内部合同；它们不是新的 H3 顶层字段。当前脚本支持的公开输入枚举是实现边界，不能倒推为 H3 能力的全部范围。

## 2. 四个子模块分别如何作用于官方协议

| 子模块 | 覆盖模式 | 对应官方位置／Label | 编排要求 | 审计要求 |
| --- | --- | --- | --- | --- |
| M11.1 能力与版本 | 五种模式 | 五模式的协议版本和可用条件；无新增模型字段 | 记录官方格式与部署能力的版本依据，为后续选择提供条件 | 未知保持未知；协议支持不能冒充工作流已接通 |
| M11.2 模式与素材绑定 | 五种模式 | 基础模式 Picture 帧锚；Ref2VA 四类 Label；Subject 与 Sx 的对应关系 | 按用途选模式，建立资产顺序和稳定 ID 到标签的映射 | 禁止按图片数量机械路由，禁止标签漂移、隐式启用音轨或扩大属性权限 |
| M11.3 提示词字段编译 | 五种模式 | 基础三字段／Ref2VA 六字段；Shot、Sx、d 及连续语音标记 | 组织完整逐镜音画和参考生效点；展开独立任务公共上下文 | 字段集合、首行、引用、镜头时序、原词、必保信息、正文纯净度 |

## 3. 五种输入模式

### 3.1 T2VA

直接从三个核心字段开始，不加图像对齐首行。主正文在 `[Shot 1]` 后写整体风格、构图和场景，再沿实际时间线写动作、摄影和声音。参考素材一旦承担真实指导用途，应重新核对所选模式，而不是把 Ref2VA 字段混入 T2VA。[B:5、14、36–48、78–89]

### 3.2 I2VA

实际第一帧使用官方固定首行：

```text
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.
```

首行后空一行，再放基础三字段。第一镜从首帧身份、衣物、位置、构图和场景锚发展，写清动作起始与结果。身份照片未经明确首帧选择不能自动进入此模式。[B:16–20、34、54–56]

### 3.3 FL2VA

首行严格使用原文形式；此处 Picture／Shot 不带尖括号／方括号：

```text
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.
```

替换 N 为实际末镜编号，S.SS 为有效时长的两位小数。正文保留从首帧到尾帧的可观察过程，不只罗列两张静态图。首尾图不相容时返回相应状态／空间／动作责任方。[B:22–26、34、60–64]

### 3.4 L2VA

```text
How the reference pictures align with the target video — <Picture 1> (from [Shot N]) aligns with the S.SS-second mark of the target video.
```

尾图对应实际末镜和结束时刻；只有单镜时 N 才等于 1。前序动作必须能够到达尾图状态，不能误把尾图当作首帧。[B:28–34、68–70]

### 3.5 Ref2VA

按顺序生成六字段，不添加基础模式的图像对齐首行，也不混入 `integrated_multimodal_description`。具体帧锚、分镜、内容参考、视频结构及音轨关系在六字段内部表达。整体风格写在正文 `[Shot 1]` 之前。[R:13–37、227–239]

## 4. 逐字段的编排和审计

| 官方字段 | 使用模式 | 应写入什么 | 重点审计 |
| --- | --- | --- | --- |
| `integrated_multimodal_description` | 基础四模式 | 按真实镜头组织风格、构图、主体、空间、动作与反应、摄影、说话者及画内声音 | 全画面动态明确；第一镜无时间戳；后续切点正确；不混入 Ref2VA 包装 |
| `subject_definitions` | Ref2VA | 每一需要单独追踪的内容／帧／视频结构／音轨的定义、角色与必要来源 | 同一 Label 贯穿六字段保持同义；来源型 Picture／Video 可以只嵌在 Subject 定义 |
| `summary` | Ref2VA | 一个英文短段，开头为去重的方括号任务类型组合 | 类型由用途决定；编辑任务遵守官方开头；不引入未知标签 |
| `retention_analysis` | Ref2VA | 每一单独追踪引用的作用位置、保留／转移／复制关系与理由 | 只在已定义的角色内判断强度；Audio 关系与视觉关系不混用；不出现 Sx |
| `detailed_description` | Ref2VA | 按播放顺序写完整逐镜画面、动作、状态、摄影、声音及引用生效点 | 不降为摘要或关系清单；保持英文正文，台词和可见文字保留原语言 |
| `overall_soundscape` | 五种模式 | 全片环境、物理动作和非语言人声；有参考时保留对应声音层关系 | 不复述台词歌词；N/A 仅表示明确全片完全静音 |
| `non_diegetic_music` | 五种模式 | 只有观众能听的配乐，包含乐器、速度、节奏和动态 | 无配乐时 N/A；人物能听到的收音机／演奏等归主正文 |

基础字段与声音规则见 B:36–48、76–171；Ref2VA 的定义、摘要、保留分析与正文见 R:24–306。

## 5. 逐 Label 的编排和审计

| Label | 对应内容 | 模块具体处理 | 典型错误 |
| --- | --- | --- | --- |
| `<Subject N>` | 可复用可见内容：人、动物、物、环境、服装、动作、姿态、风格、效果 | 保留多资产到一主体／一资产到多主体的来源关系；首次明确出现时描述可见特征、位置和当前动作 | 用图片槽位代替身份；把新增动作当作身份不保真 |
| `<Picture N>` | 具体目标帧或镜头规划锚；也能是 Subject 的图片来源 | 保留帧角色、Shot 和时点，或分镜图对应的真实镜头与规划内容 | 身份图自动成为首帧；来源引用被误加为独立目标帧 |
| `<Video N>` | 编辑源、续接起点、整段时间结构 | 保留源窗口、结构与内容主体的区别；具体动作内容仍可由 Subject 承担 | 参考运镜误写 video editing；Video 替代所有主体 |
| `<Audio N>` | 复制或参考的音频信号 | 明确单独音频／启用同步轨；按声音层引用；需要时绑定实际 Sx | 视频自带音轨就自动启用；Video 与 Audio 同号配对；复制 BGM 的歌词被分配新说话者 |

四类编号分别从各自顺序产生，不编码跨类别配对。Ref2VA 可以出现 `<Video 1>` 与同源 `<Audio 2>`；是否同源由来源记录说明。[R:41–118]

## 6. 镜头、说话者和声音标记

| 标记／规则 | 编排要求 | 审计 |
| --- | --- | --- |
| `[Shot N]` | 对应真实镜头，连续编号 | 阶段、分镜格、后台生成任务不能直接变成镜头数量 |
| `At MM:SS.mmm` | 只用于后续镜头切点，生成局部时间 | 严格递增且小于有效时长；无源／作品／生成时间混用 |
| `(Sx)` | 根据实际发声顺序生成，跨镜稳定 | 与 Subject／Audio 编号独立；同一声音源不重编号；不进入 retention_analysis |
| `<d>[Language] ...</d>` | 真实台词／歌词；身份、动作和表演方式在外 | 基础模式逐字逐标点保留；Ref 源音频规范化不改词、不翻译、不猜测 |
| `<scenetrans>` | 同一句话跨切的连接点，配连续声音描述 | 两侧关系和 M6／M7 的切分一致 |
| `<cutoff>` | 发声被视频结束截断 | 只有真实获准截断时使用，不掩盖台词超时 |
| 英文双引号 | 画面中真实可见的文字 | 原文与标点保留，不能自行翻译标牌 |

声源、台词和音轨策略属于 M6，时间属于 M7，镜头属于 M9。M11 生成序列化形式，不能借此修改这些决定。[B:86–89、127–151；R:215–221、258–278]

## 7. 实现检查和仍需审阅的边界

脚本核对公开合同表示的字段、用途、编号、引用、时间、原词插入、追溯和参数关系；各项具体覆盖见合同指南与测试记录。它不推断自由文本中所有同义表述、所有内在矛盾，也不测量实际媒体。

导出时至少再完成一次 Agent 语义对照：必保内容确实存在，动作过程可读，参考用途没有越权，独立任务上下文完整，后端参数有依据。形成候选 G2 输入后，由 M12 或明确的独立审阅执行剩余检查；本包不代替整套持续审计。
