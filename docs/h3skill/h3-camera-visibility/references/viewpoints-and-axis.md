# M5.1 观察机位与光轴

## 输入与职责

根据当前观看任务、主体／场景关系和已授权参考建立观察机位。只拥有 `viewpoints` 分区；需要人物移位时向 M3 请求，需要改变动作时向 M4 请求。M5.2、M5.3、M5.4 可以使用兼容外部机位输入，不必先运行本子模块。

先读用户要求与实际输入，再按需选 C01 物理机位案例中的方法。C01 是文本方法与作者论述；其效果措辞不构成本包的真实生成成功率。[C01]

## 从效果词转成观察条件

| 要回答的问题 | 编排内容 | 审计问题 |
| --- | --- | --- |
| 摄影机在哪里 | 相对场景锚点、主体前后左右与可达区域 | 所谓“侧面”属于谁的身体侧、哪套坐标？ |
| 摄影机多高 | 相对地面或明确参照物的高度 | 是否把低光轴误写成低机位？ |
| 摄影机离什么多远 | 明确距离对象与来源；可用关系性描述 | 是否只有“特写”而没有支持其透视关系的条件？ |
| 光轴看向哪里 | 目标部位、场景锚点或视线方向 | 目标与观察位置是否相容？ |
| 机身怎样摆 | 必要的俯仰、侧向朝向与绕光轴滚转 | 是否把滚转误写成角色倒身或后期旋转？ |
| 这个位置看见什么 | 所需前景、主体可见面、地面／顶面和背景关系 | 是否把想要的效果直接当作几何已满足？ |
| 哪种误解需要排除 | 只针对本任务指出错误替代 | 是否堆砌无关禁令、把条件规则写成普遍禁令？ |

普通镜头用足以确定任务的描述；特殊视角补足容易混淆的关系。无可靠尺度时可以提出有标记的设计距离，或保留待定，不能伪装成从素材测出的数值。

## 必须分开的概念

- **高度与俯仰：** 摄影机在地面附近且向上看，与摄影机在胸口高度向上看，是不同观察条件。[C01]
- **正上方与斜上方：** 正上方需要光轴朝向地面；斜上方可以保留人物正面信息。不能只写“俯拍”就默认二者相同。[C01]
- **位置与取景：** 距离、姿态与画面范围需共同核对；单个机位名称不自动给出景别或所有部位的可见性。[C01；D]
- **机身滚转与对象倾斜：** 前者改变整个画面的方向关系；对象姿态归 M4，不能由摄影描述偷偷替换。[C01]
- **平移与转向：** 原位转向、平行跟随、绕到主体另一侧有不同路径；跨侧时应说明实际绕行关系。[C02][C03]
- **稳定身份与画面槽位：** 相机换侧可能改变画面左右，稳定角色 ID 不因此改变；需要 M3／M8 协调。[C04]

这些分别记入领域说明，不要求每条记录都拥有数值欧拉角、三维坐标或完整镜头模型。采用角度数字时先说明坐标和含义；案例的“无角度版本”只是一种语言策略。[C01][C03]

## 特殊视角检查

从地面、俯顶、贴近主体或身体边缘观察时，检查起点和终点是否落在已有场景允许的区域。主体与摄影机需要绕行时，写清从哪一侧通过，经过哪些可见关系，以及路径和动作是否冲突。只有文字输入时形成待检条件，不报告真实碰撞已排除。[C01][C03；D]

用户明确要求现实物理摄影时，不能用裁剪、数字推近或成片旋转冒充位置变化。动画、幻想、后期效果等其他策略须来自任务许可；M5 仍清楚表达采用何种方式及其对可见性的影响。[C02][C03；D]

## 返回与失败修复

输出机位候选、光轴／姿态、来源、未知项和对子模块的引用。无法解释某个特殊视角时，返回具体冲突：缺空间尺度、位置被实体占据、光轴目标不可见、方向定义不一致，或参考角色未获许可。

调整观察位置由 M5.1 修订；调整画面边界交 M5.2；调整焦点交 M5.3；改变路径交 M5.4；改变主体位置交 M3。不得通过改角色身份或动作来静默解决摄影问题。
