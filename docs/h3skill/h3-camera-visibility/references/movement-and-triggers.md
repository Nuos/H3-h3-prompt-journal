# M5.4 摄影机运动与触发

## 工作单位

用“起始机位—主路径—光轴目标—触发事件—终止机位与构图—稳定条件”表达一次摄影事件。将相机事件与人物动作分别编号，通过引用表达响应关系。案例的组合词和数值是策略实例，不是通用固定参数。[C02][C03]

只拥有 `movements` 分区。起终机位由 M5.1 提供，画面任务由 M5.2 提供，焦点策略由 M5.3 提供；这些都可来自兼容外部输入。不得为迁就路径悄悄改变其他分区。

## 先选择响应关系

| 策略 | 摄影决定 | 交给 M7 的内容 | 检查 |
| --- | --- | --- | --- |
| 提前到位 | 关键事件前到达目标观察位置 | 到位事件先于目标事件，等待／保持条件 | 提前移动是否有观看理由？ |
| 同相响应 | 与动作某个阶段协同变化 | 需要对齐的启动、峰值、接触或恢复事件 | 是否混淆了不同相位？ |
| 滞后追随 | 动作发生后再响应并重获目标 | 因果顺序、允许偏移及待确定容差 | 延迟与修正是否有边界？ |
| 固定观察 | 保持机位与朝向，让事件在画面内发生 | 固定观察覆盖的事件范围 | 是否误把人物／环境全部冻结？ |

四策略来自冻结方案对案例差异的抽取。C02、C03 中的 1:1 同步适用于相应舞蹈设计；C07 明确允许摄影师提前、稍滞后或暂时保持，让人物进入画面，并反对机械追随每个肢体。按当前观看任务选择关系；精确秒数、偏移、帧率与量化由 M7 统一管理。[C02][C03][C04][C06][C07；D]

## 把术语展开成路径

| 摄影词 | 应具体表达 |
| --- | --- |
| 推进／后退 | 沿什么方向，向哪一对象靠近／远离，光轴如何保持 |
| 平行跟随 | 位于主体哪一侧，与主体运动的相对关系 |
| 超越／绕侧 | 从哪边出发，沿哪条可达路线经过主体什么部位，到哪里结束 |
| 升／降 | 摄影机本身如何改变高度，光轴目标和构图如何转换 |
| 原位摇转 | 机位保持时光轴如何改变，结束看向什么 |
| 遮挡／揭示 | 什么进入镜头附近，期间摄影机怎样连续移动，何处恢复可见 |
| 稳定观察 | 明确无平移／转向的范围，哪些人物动作继续发生 |

物理推进与变焦、机身滚转与后期旋转、摄影机升降与原位俯仰分别表达。需要选择不同技术时说明决定和权限，不用一个术语掩盖另一种效果。[C01][C02][C03]

## 复合运动与阶段边界

先确定主路径，再决定确有信息作用的次级调整。每次转换说明由哪个主体事件、空间关系或观看任务引起，并继承上一阶段终点；不把多种词汇并列当成路径。单一镜头可以有多个连续阶段，阶段名称不自动产生剪辑。[C02][C03]

相机经过身体边缘或短暂遮挡时，路径仍连续；遮挡解除后的位置必须能由该路径解释。若实际采用切镜或空间省略，由 M9 声明边界类型，再由 M8 核对允许改变的条件。不要用看不见的间隔掩盖无依据的传送。[C03；D]

动作释放后响应、先到位等策略需要区别动作阶段。C02 的部分条款偏向释放时移动，后续同步条款强调同时启动与峰值；不能把两种表述直接叠加。先选择当前任务关系，再提交 M7，保留选择依据。[C02]

## 不设置全局运动风格

可以使用固定、平稳、手持、低机位、跟随或带意图的延迟；先看作品任务和已授权素材。案例中的单主体、上半身优先、1–2 步移位、禁角度数字、禁慢走、禁数字变换和特定停止姿态均保留原场景范围。M5 不因选择某一案例模板就删改 M4 表演或 M9 分镜。[C01][C02][C03][C07]

## 审计与返回

审计起终机位、事件引用、路径与主轴、转换理由、光轴目标、固定观察范围，以及关键动作的可见窗口。出现冲突时返回明确责任方和本次基准版本。

文字中的“可达”只是设计要求；无几何测量与媒体证据时不宣称碰撞或运动效果已验证。脚本只检查其公开实现的引用和确定性条件。实际运动、漂移、构图和清晰度由 M12 在媒体产生后检查。[D]
