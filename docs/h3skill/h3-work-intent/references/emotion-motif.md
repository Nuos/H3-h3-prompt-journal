# M1.3 情绪能量与母题

## 职责与最小输入

接收目标、段落语义和已知的主题/音乐结构线索，形成情绪与能量发展意图、可识别母题及其变奏/回收关系。兼容输入可由用户或其他实现直接提供，不强制先运行 M1.1/M1.2。精确字段见 `contracts.json`。

本模块记录的是导演意图。“能量上升”不是测得的响度，“高潮段落”不是确定的第几拍，“克制”不是角色必需执行的完整动作。实际音乐依据归 M6，排时归 M7，动作机制归 M4，摄影归 M5，视觉细化归 M10。

## 编排步骤

1. **确认情绪/能量的来源。** 从用户目标和已读案例文本中提取。没有音频，只能提出相对走向或引用用户提供的结构；不可声称已经听出速度、歌词位置或实测拍点。
2. **按段落写变化。** 说明本段进入时、发展中、离开时的感受与表演能量及变化理由。允许平台、回落、留白、突变与回收；不把持续增强当作通用规则。
3. **给抽象意图具体的观察依据。** 为“克制”“受阻”“释放”等说明希望观众看到或听到的变化类别，例如已有动作的完整/残留、动作方向的打开/收回、已有角色关系的靠近/分开。细部身体过程和声学参数交责任模块设计。
4. **定义可再次识别的母题。** 记录母题 ID、首次建立、保留的识别特征、允许变化的维度、后续段落如何变奏或回收。不要把某个案例的剑、长袖、海滩或固定人物设成所有作品必需母题。
5. **检查母题与必保约束。** “变奏”不自动授权替换身份、改变用户指定道具或覆盖已锁定内容。触及这些要求时返回 M1.1/M2 的明确修改请求。
6. **处理音画关系。** 区分音乐情绪意图与真实音轨用途。复用原曲不自动意味着人物对口型，歌词意象不自动要求画面出现同名物件；只有任务授权才交 M4/M6 实现。
7. **返回语义提案。** 保存走向、母题、对应段落和可观察的表达建议；未取得的音乐与媒体依据保持未知。提供给 M4/M5/M6/M9/M10 的是目标与约束，不是越权写入它们的计划。

## 局部审计

| 规则 | 可核对问题 | 修复位置 |
|---|---|---|
| M1-E01 发展依据 | 情绪/能量变化是否有段落目标或文本依据？ | M1.3 |
| M1-E02 可观察表达 | 是否只有“忧郁/史诗/高级”等词，找不到待实现的可见/可听表现？ | M1.3 提目标；M4/M5/M6/M10 细化 |
| M1-E03 母题可识别 | 母题的保留特征、变奏维度和回收位置是否可回查？ | M1.3 |
| M1-E04 非单调许可 | 是否误把留白、弱化或重复认定为缺陷？ | M1.3 按当前意图复核 |
| M1-E05 音乐事实边界 | 是否凭 BPM、文字标题或文件名声称已定位实际拍点？ | M6/M7 补证据；撤销错误声明 |
| M1-E06 属性权限 | 母题变化是否越过固定身份/道具/剧情权限？ | M1.1/M2 裁决 |

## 与 H3 的交接

- 四种基础模式的 `integrated_multimodal_description`、Ref2VA 的 `detailed_description`：承接经专业模块展开后的动作、表演、观看与视觉变化；不要将完整导演自检问答塞入这些字段。
- Ref2VA 的 `summary`：可以概括总体发展，但不能代替镜头级描述或引入尚未定义的素材标签。
- `overall_soundscape`：只承接经 M6 确认的环境/物理声音语义；不能将“悲伤”直接当作声景。
- `non_diegetic_music`：把情绪目标交 M6 转为乐器、速度、节奏、动态等可听描述。官方基础指南不要求在此解释配乐的心理功能。音频复制/参考方式需保持与 M2/M6/M11 的实际合同一致。
- `<Audio N>` 的存在和对应关系由实际音轨用途决定，M1 不凭“这是 MV”自动创建音频标签。

## 来源与适用边界

`case-evidence.md` 中古典武侠舞方法论直接说明母题的建立、变形、残留与回收，以及能量不必逐段增强；海滩剑舞、白凤蒙尘、四人队形、夏日水线和台灯 A/B 提供不同发展方式。其具体动作、人物关系和音乐数值仅在相应案例成立。效果是否在实际视频中实现，需要独立媒体观察。
