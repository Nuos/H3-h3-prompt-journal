# M10.4 材质与视觉效果

## 核心摘要

将质感附着到具体对象，将变化附着到可追溯条件。M10.4 拥有 `MaterialEffectPlan`，组织表面表现和视觉效果；主体身份、空间结构、动作原因、权威时间与跨镜状态各由原责任模块维护。

本文为 D 类实现设计；以水线、湿发湿衣、刀剑／衣物细节、自然材质和环境效果等案例文本为条件化证据。文字中的质感词不等于完成物理材质仿真或实际生成验证。

**关键词：** 对象绑定、表面状态、湿润、反光、环境效果、可见性。

## 1. 最小输入

取得需要表现的主体、部位、道具或环境表面，当前作用域，已知身份／材质约束及可接受变化。只有引用了动作、时序或连续性决定时才需要相应只读投影；缺少变化原因时，可以交付静态候选及未决项，不能补造已经发生的入水或换装事件。

单独描述材质无需先完成全片照明和调色，但实际采用的相关决定要有来源及版本。目标 ID 必须可解析，不能仅凭“她的衣服”“那个反光”确定唯一对象。

## 2. 分开身份、表面状态与效果

| 类别 | M10 可形成的表达 | 需要其他责任方决定的内容 |
| --- | --- | --- |
| 已有材质的视觉呈现 | 指定部位的纹理、反光或质感要求 | 新增／替换衣物、改变道具结构或数量：M2 |
| 可变表面状态 | 湿润后发束黏合、衣物表面受水的可见变化 | 何时变湿、持续多久、何时恢复：M4／M7／M8 |
| 环境效果 | 雾气、水花或光效的对象、范围和可读性条件 | 空间位置与遮挡：M3／M5；原因和时刻：M4／M7 |
| 画面质感 | 当前作品允许的视觉表现与局部边界 | 机位、景深、焦点或剪辑决定：M5／M9 |
| 源参考中的可见效果 | 在已有参考权限内描述所借用属性 | 素材角色、保留程度与最终 Label：M2／M11 |

湿发与湿衣不能默认为重新设计发色、发型、衣物款式或身份。表面受光使颜色变暗的可见现象，也不能用来偷偷接受永久身份变更。遇到这种歧义时写明原属性、目标表面变化及待确认界限。

## 3. 写清效果的条件链

按“已有条件 → 可见变化 → 终态／延续条件”组织。需要动态起落时，先引用 M4 的动作或 M3 的环境条件，再由 M7 排时；把结束后仍存在的湿度、附着物或效果状态交 M8。

不从一张湿发照片推断角色在目标视频中已经入水，不从歌词或音乐情绪自动生成火焰、粒子或衣物变化，不从场景水面自动授权改变水深和人物站位。

只对本次视觉表现提出要求。相同动作在不同风格下可以有不同材质表达，但这不授权删去身体过程、遮掉关键接触或改变故事结果。

## 4. 保护动作与主体可读性

对每项效果说明作用区域、受影响对象、保留的可见信息和允许的遮挡条件。效果能否覆盖眼睛、手部、支撑脚或道具接触点，必须服从当前镜头具体观看任务，不设置跨作品统一的“永不遮挡”或统一人物数量规则。

若强反光、浓雾或水花可能覆盖必保信息，交 M5审阅；若需改光源或对比，交 M10.2／M10.3；若需改事件发生方式，交 M4。不能只在文末加一句“不影响动作”就把冲突标为解决。

明确区分计划保护条件和实际检查结果。没有生成片段时，实际水花轨迹、纹理保持、闪烁与遮挡均未观察。

## 5. 变化许可与跨镜交接

镜头 A 结束时的湿润状态、道具表面或环境效果是否延续到镜头 B，由 M8 的连续性策略决定。连续接续、动作匹配、独立蒙太奇或明确省略可以有不同许可，不对全部段落强制一条状态持续规则。

M10 交接“应持续的视觉属性及作用范围”；M8 登记权威计划状态；M12 登记生成后的实际观察。下一段再次输入角色参考图不自动允许其表面状态归零。

## 6. H3 表达与局部审计

在当前模式主正文逐镜描述具体对象的材质和效果变化。Ref2VA 若确实借用外观／可见效果，按已有素材角色在定义、保留分析与正文中保持一致；不要创建 `<Material N>` 或 `<Effect N>` 作为新官方类型。

审阅对象是否唯一、权限是否有效、变化条件是否存在、强度与范围是否有依据、关键可见条件是否冲突、跨镜持续是否待协调、后期效果是否误写成每个模型请求必须生成的事件。局部脚本只核对有类型声明与引用，Agent 审阅句子语义，实际效果必须另有媒体证据。
