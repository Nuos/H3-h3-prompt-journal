# M10.3 色彩与调色策略

## 核心摘要

分别处理主体固有颜色、环境颜色、局部光色和整体调色。M10.3 拥有 `ColorPlan`，负责视觉基调、对比、曝光倾向及局部色彩关系，不拥有人物／服装重设计权限。

本文为 D 类实现设计。案例中的冷中性、低饱和、暖日光、清爽或厚重质感均需携带原作用域；不把某一音乐 MV 的偏好设为所有作品的默认值。

**关键词：** 基调、对比、曝光倾向、局部光色、身份保护、色彩关系。

## 1. 最小输入与职责

取得视觉目的、当前作用域、必须保护的主体色彩、可接受变化，以及实际使用的风格／照明／参考资料。仅修改局部调色时可以接受兼容外部投影，不必完整运行 M1—M9。

若声称保留角色发色、服装配色或道具标识，应有 M2 或用户可追溯的属性依据。未提供原图、未观察其颜色时保留未知，不能伪造原图测量值。精确颜色管理与设备参数不是本包凭文本自动推导的能力。

## 2. 四类颜色分开写

| 颜色来源 | 例示的决定类型 | 字段责任 |
| --- | --- | --- |
| 主体／物体固有属性 | 角色发色、衣物色块、道具标识 | M2 绑定身份及允许修改；M10只消费 |
| 场景与环境属性 | 水面、山体、室内表面的既定颜色 | M3／M2 提供已有场景与资产；M10组织视觉关系 |
| 局部光照 | 暖光落在发丝边缘或衣物表面 | M10.2 LightingPlan |
| 整体调色 | 冷中性基调、对比、曝光倾向及局部保护 | M10.3 ColorPlan |

同一物体在光照和表面状态变化下可有不同可见颜色，但不因此取得改变其身份属性的许可。若“统一冷调”实际要求把紫发永久改成蓝黑发，需回 M2／M8审阅具体变化，不能由色彩方案直接接受。

## 3. 写出可执行的关系

说明全片或当前场景的基调、主要色彩关系、对比与曝光倾向、需保留的细节，以及允许局部偏暖／偏冷的对象。把“冷”“暖”“饱和”附着到范围和目的，避免堆砌互相不明的形容词。

“夕照的暖色边缘光，整体保持冷中性且不抹除该局部暖色”在语义上可相容；“全片所有颜色必须完全无暖色，同时保留明显暖色日光”需要拆解范围或返回冲突。脚本不通过词语同时出现就判断正确性，Agent 必须阅读完整句子与作用对象。

不得自行指定 LUT 文件、ICC 配置、输出色域、相机曝光值或统一 Kelvin 数值。若用户提供这些资料，先记录来源、阶段和实际工作流能力；H3 自然语言描述与后期软件参数分别交接。

## 4. 跨场景与独立任务

对每个场景说明继承的全片基调与允许例外，再按当前镜头需要展开。独立生成任务携带自己的有效色彩要求及保护属性；不能仅写“继续上一段色调”。

有意的场景色彩转换不自动构成漂移；是否允许以及何时发生需与 M1 作品意图、M7 时序、M8 连续性及 M9 镜头边界相容。真正的生成偏色由 M12 对比计划和实际片段后登记，不能从提示词结构直接下结论。

## 5. 局部审计与交接

| 问题 | 审计处理 |
| --- | --- |
| 暖光与冷调同时出现 | 判断是否分属实际光源与整体调色；不能机械互斥 |
| 为统一风格改变发色、肤色或衣物 | 查 M2 权限和 M8 变化许可；无依据时保留阻塞 |
| 风格来自身份参考图 | 核对参考用途；身份授权不自动包含调色 |
| 调色吞掉接触、材质纹理或关键表情 | 与 M5 协调可读性，与 M10.2／M10.4协调局部效果 |
| 整片无差异与局部例外不明 | 回 M10.1 解决作用域及继承关系 |
| 后期调色被写成每段内的发光或变色事件 | 分开制作阶段；需要生成的可见变化才进入对应主正文 |
| 宣称无色差、无闪烁 | 要求 M12 的实际媒体范围与证据；无证据时未验证 |

向 M11 交接可观察的色彩描述，基础四模式使用 `integrated_multimodal_description`，Ref2VA 使用 `detailed_description` 并保持参考定义、保留分析一致。`ColorPlan` 不成为 H3 新顶层字段；不改写 M6 的声音策略。
