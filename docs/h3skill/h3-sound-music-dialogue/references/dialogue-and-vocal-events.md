# M6.2 对白与发声事件

把可听词句、非语言发声及其表演分别建成有来源的事件。输出归 `SoundPlan.vocal_events`；字段、版本和接受规则以 [公共合同](contract-guide.md) 为准。此处规定声音语义，不另建成片时间表。

## 1. 独立入口与输入

处理对白、唱词、旁白、咳嗽、笑声、呼吸、同时发声或跨镜话语时调用。最小输入是本次必保的发声要求、原始文字或未知说明，以及说话者／声源的可用绑定。明确用户要求足以启动独立提案，不以完整 `SoundPlan` 或先跑 M6.1 为前置门槛；无法确认的绑定作为具体待补项返回。

按需读取 `sources`、动作事件、镜头关系及用户批准文字。只参考音色时，使用当前任务的台词，不能擅自搬入参考音频的原台词。

## 2. 区分事件类型

| 类型 | 必须说明 | 避免混淆 |
| --- | --- | --- |
| 对白／感叹 | 实际发声者、原文、语言、表演及语义先后 | 角色出现不代表说话；听不清不能编词 |
| 独立演唱 | 实际演唱者、唱词、旋律／音色来源、口型要求 | 有歌声的 BGM 不等于画面人物演唱 |
| 旁白 | 叙述声源、词句、与画面及可见人物的关系 | 不把画外人物的场内话语自动改成旁白 |
| 音轨词句提示 | 音频来源、词句可信度、动作或情绪提示用途 | 不增设舞者发声，不自动生成字幕或歌词意象 |
| 非语言发声 | 谁咳嗽、笑、喘息或叹气，何事件触发及如何结束 | 不强行转成台词，也不把人物发声塞入无来源音效 |

原文事实与本轮演绎分开：已有稿件写了笑声，只能证明存在该要求，不能据此声称实测到了笑声或得到某种声纹。

## 3. 文字保真与表演组织

内部至少区分三层：**源文本原文**、**用户已批准的实际话语**、**面向当前协议的格式化文本**。批准的改词保留变更依据和版本；格式化不能覆盖前两层。不存在批准改写时，不通过缩句、翻译、同义改写或补词解决时长问题。

每个事件说明声源、事件类型、原词原语言、声音在画内／画外的关系、表演方式及开始／结束条件。语气、速度、动作与词句分开存放，避免让舞台指令变成实际说出的内容。自然语言缺项必须保留具体未知，不能填入模板台词冒充来源。

对白顺序可以表达为“回应前一句”“接触事件后发笑”“在下一镜继续”；绝对时间由 M7 接受和计算。已有来源时间可登记为有出处的约束，但不能用未经测量的语速估计宣布可在指定时间内说完。必保台词与时长冲突时，提出调整表演、时长或经批准改词的候选，由相应责任方裁决。

同时发声时，逐一确认各声源和实际词句，明确其确实是重叠意图；没有依据不能擅加打断或重叠。复杂对话的倾听反应、停顿、抢话和情绪转折可提出 D 类设计，但本次案例覆盖不足以认证其生成质量。

## 4. 歌词的四种关系

1. **音轨内提示：** 原音轨继续播放，某句作为动作提示。词句属于音轨，不改变画面人物的声音身份。
2. **情绪参考：** 从给定歌词获得已授权的情绪方向；不自动把歌词中的人物、物件或行为加到画面。
3. **实际演唱／复演：** 当前任务明确要求角色发声，建立独立声源和唱词事件，再核对参考用途与信号策略。
4. **仅音色参考：** 借已授权的声音特征，目标词句仍来自当前任务，不继承参考的原唱词。

若词句未被可靠听写，不能把推测句子作为精确歌词锚点。滨水案例 E01 明示人声未核实；下山案例 E02 报告歌词实体化失败，且其轻微口部表演是局部要求；海岸剑舞 E03 则明确不做口型。这些材料支持按当前任务选择关系，不支持一条全局“所有 MV 都对口型／永不对口型”规则。

## 5. 跨镜延续与结束

说明同一话语是在切镜前完成、跨切继续、刻意被打断还是在片尾截断，保持同一事件和声源可追溯。M8 接受连续性状态，M9 决定切点与声桥的编辑关系，M7 映射时间。M6 提交延续语义，不自行复制整句到下一镜导致声音重新开始。

## 6. H3 交接与审计

五模式的实际话语均交 M11 以 `<d>[Language] ...</d>` 编排；声源标记、动作和表演放在话语标签外。基础模式需逐词逐标点保留；Ref2VA 可按官方规则规范基本标点，但保留原词原语言，听不清部分用 `[unclear]`，且不覆盖内部原始记录。跨切和片尾截断的专用标记见 [H3 映射](h3-label-mapping.md)。这些是 P 类协议依据，不是案例已经证明的对白能力。

实际声音事件进入主正文；`overall_soundscape` 汇总听觉层次，不重复整段台词；观众独听的配乐进入 `non_diegetic_music`。引用的歌词究竟是音轨 cue、人物演唱还是参考用途必须在语义上先确定，再编译格式。

审核词句是否被静默改写；语言是否漂移；非语言发声是否伪装成台词；音轨歌词是否误分给角色；跨切是否被重复朗读；静音与必保话语是否同范围冲突；原文／批准版／格式版是否可追溯。

## 7. 证据与局部返回

E06 的两句短日语感叹和结尾咳嗽／笑声提供最小的角色发声分配例；E07 则明确排除对白、歌唱及旁白，同时保留厨房声音。它们不等于长篇对白、稳定音色、精细口型、多人重叠或持续跨镜对白的实测样本。

文字不明、声源缺失或时长冲突时，交付仍有依据的事件和具体缺项。文字修复由本分区提出，来源交 M6.1/M2，信号策略交 M6.3，排时交 M7，剪辑交 M9。未运行 H3 或未听成片时，语音清晰度、情绪、口型与连贯性保持 U，不写“已通过”。
