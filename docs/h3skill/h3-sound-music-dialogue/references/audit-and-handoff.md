# M6 审计、缺项与责任交接

## 核心摘要

按“输入证据—子模块候选—父级组合—协议交接—实际媒体”逐层检查。一次本地合同通过不能替代声音语义审阅、H3 编译审计或真实听觉质量验证。专业值由对应子模块修订，父模块只接受或退回。

## 1. 检查对象和结论层次

| 层次 | 检查对象 | 可报告结论 | 不能推导 |
| --- | --- | --- | --- |
| 结构 | JSON、字段、类型、版本、公开写入分区 | 本包已实现的结构约束是否满足 | 声音来源真实、文本听写正确 |
| 确定性关系 | ID 引用、原请求与来源、文本锁定、音轨策略、版本与收据 | 已实现关系是否矛盾或越权 | 自由文本内所有语义正确 |
| Agent 专业审阅 | 声源合理性、歌词角色、声音与动作关系、规则适用范围 | 有证据支持的文字方案及未决项 | 实际口型、音色、噪声或混音已合格 |
| 编译交接 | 模式、Label、Sx、字段、复制关系与边界标记 | M6 交接材料是否齐全；指出待 M11 检查项 | M11 运行、完整 G2 或后端兼容性已通过 |
| 媒体检查 | 实际音频、视频与成片 | 仅报告实际听取／观察和测量的范围 | 未提供或未打开媒体的效果 |

父接受生成的仍是计划草稿。即使所有记录具备来源，`known` 也只表示该计划声明有依据，不表示来自媒体实测。

## 2. 四子模块局部审计

| 节点 | 必须核对 | 缺项时可继续的工作 | 阻断范围 |
| --- | --- | --- | --- |
| M6.1 | 稳定声源与实体／独立旁白／音轨的区分；音色依据；参考许可 | 建立可追溯的候选绑定，保留未知音色或空间信息 | 不得确认未给定声音身份或把不同来源合并 |
| M6.2 | 台词原文与语种；实际发声源；表演方式；歌词cue和口型要求；跨镜意图 | 保留已批准台词和语义顺序，登记待测语速或时间 | 不得猜词、改词、移植只供音色参考的原台词 |
| M6.3 | 复制／参考／生成／静音策略；源音频版本；启用与许可；源窗口与音乐依据 | 没有音频时给条件化方案及资料需求 | 不得伪造实测拍点、精确窗口或完整最终音轨复制结论 |
| M6.4 | 环境与动作声的具体来源、动作关联、已在源内／新增／参考关系、持续条件 | 列出候选声音与动作事件，待核对实际源内容 | 不得把新增声层与整条最终音轨原样复制同时接受 |

未提供某模块的数据时，不要求执行全部上游。接受用户或外部工具的兼容公开投影；仍然核对来源、版本和本任务适用范围。数据缺失不能靠伪造一个上游已运行标记解决。

## 3. 组合审计

1. 核对每个声音事件指向存在且含义一致的声源；只读投影不能在提案中换成另一份来源或内容。
2. 核对台词原文与实际原请求；追加／改写台词、改变音轨用途都属于语义修订，按新请求和基版本重新提交。
3. 对照完整复制、部分复制与新增声音。源音轨中本来存在的动作声可作为源内内容登记；声源内是否真的存在该声需实际证据，不能仅凭画面动作推定。
4. 对照歌词cue、实际演唱与音色参考。已存在的歌唱不自动成为另一角色的口型任务；明确要求复演时建立独立发声事件及依据。
5. 对照静音范围。全片静音、仅无配乐、局部停声、某声层缺项分别表达。当前要求冲突时列出冲突，不静默扩大禁声范围。
6. 对照源窗口与时间域。M6 描述音轨需要与来源；M9 选择编辑窗口与装配意图，M7 给权威映射。已有具体源窗口可按来源原值登记，不能暗中变为成片时间。
7. 对照连续性。声音跨切持续、明确中断、起止条件分别交接；切镜不自动重启音乐。延续与剪辑策略冲突时返回相应责任方。
8. 对照副作用和版本。脚本只返回新对象；出现冲突不部分写入。相同 ID 的不同内容不是幂等重试，应拒绝并使用新提案。

结构闭合和明确字段检查并不能解析所有自然语言矛盾。若来源摘要声称“只是音色”而自由文本又要求复演，应由 Agent 比对实际原材料与 M2 权限，登记问题；不将字符串通过误写为语义完全通过。

## 4. 失败类型、修复位置与终止

| 失败或变更 | 本域责任 | 对外回传 | 下一步与终止条件 |
| --- | --- | --- | --- |
| 声源和画面身份混淆、未知音色被当作事实 | M6.1 | M2；空间问题 M3 | 取得来源或保留未知；复查使用该声源的事件 |
| 台词变词、语种错误、听不清处被猜补 | M6.2 | M1 的文本目标；M11 的格式转换 | 用批准原文重提案；原文缺失则停在待确认 |
| 歌词cue被转换为人物演唱或口型 | M6.2/M6.3 | M4/M5；身份参考 M2 | 明确实际发声来源与画面要求；仅复查受影响事件 |
| 全量复制同时叠加声音 | M6.3/M6.4 | M1/M2 的目标与权限；M9 的混合装配 | 明确保留原音轨或允许部分复制及新增，再复验 |
| 无实测音频却声称精确拍点或语速 | M6.3 | M7 | 获取有效依据或标记未知；不以反复自评代替测量 |
| 声音事件与接触动作不符 | M6.4 | M4；空间来源 M3 | 修正当前域或请求动作域修订，不越域改值 |
| 切镜后音乐重启、话语无故截断 | M6.2/M6.3/M6.4 | M7/M8/M9/M11 | 明确边界和连续性，再检查对应编译与媒体 |
| 合同版本不兼容、基版本过期 | M6 父级 | 请求发起者或对应子模块 | 获取兼容快照；不强制覆盖或隐式迁移 |
| 文件解析／技术执行错误 | 当前调用 | 调用者 | 修复输入后重试；不得把技术重试当作新创作通过 |

纯计算可安全重跑；未来如连接有副作用的生成或写入工具，必须先确认操作身份与已有结果，不能沿用纯检查的重试假设。本版本没有这些外部副作用。

## 5. 交给其他模块的公开信息

| 接收者 | 从 SoundPlan 读取或接收 | 不允许 M6 代做 |
| --- | --- | --- |
| M1 | 声音目标与文字内容冲突、必要选择 | 改写作品目标或用户锁定台词 |
| M2 | 缺失资产、启用通道、参考属性与许可问题 | 确认未提供媒体或自行授予许可 |
| M3 | 画内／画外声源的空间问题 | 改变站位或场景拓扑 |
| M4/M5 | 需要实际发声的表演、可见口型或反应要求 | 因有歌声自动让人物开口，或强制改变机位 |
| M7 | 声音事件 ID、顺序／触发、源窗口、持续与容量问题 | 自建竞争的绝对时间或实测节拍表 |
| M8 | 声源身份和声音状态的持续／终止条件 | 改写已确认状态或实际观察 |
| M9 | 音轨使用与跨切延续、需要的装配策略 | 决定切点、变速、渲染或直接混音 |
| M11 | 稳定来源、批准话语、音乐／声音类别与参考关系 | 最终 H3 素材排序、Sx/Label 分配和协议编译 |
| M12 | 待核验清单、来源、版本与已有检查结果 | 宣布实际媒体或全流程 Gate 通过 |

这些是公共交接契约，M7—M12 在本轮尚未实现，不能因登记路由就声称真实消费者已运行。兼容外部实现可以按公开数据读取；一次调用仅带该任务所需投影。

## 6. 变更与验收记录

变更传播按真实 `read_paths` 判断。声源变化只使读取该声源的结果失效；文字变化复查该事件及有关排时／口型／编译；音轨窗口变化复查对应声音策略、映射与装配；无关显示名称不自动重做全片。未登记的语义依赖由 Agent 补查。

交付时分别写出：处理范围；使用的来源及版本；完成的子模块；结构与关系检查；专业审阅发现；剩余未知；交接对象；真实媒体是否取得。记录实际失败与修复，不抹去首次失败制造一次全过的历史。
