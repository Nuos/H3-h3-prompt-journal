# M6.1 声源与说话者绑定

把“谁出现在画面里”“谁实际发声”“声音从哪个资产取得”“允许借用哪些声音属性”分别说明。输出只归 `SoundPlan.sources`；实际机读字段以 [公共合同](contract-guide.md) 和 [contracts.json](contracts.json) 为准，本页的语义项目不构成另一套 schema。

## 1. 独立入口与最小输入

当任务涉及说话者、旁白、画外声音、音色参考、歌声归属或来源不明时调用。最小输入是本次声音任务、可辨认的发声对象或未知说明，以及实际提供的来源。已有用户文字可以直接满足输入，不强制先执行 M2 或其他子模块。

按需读取 M2 的实体标识、音频启用状态和使用权限；涉及当前镜头可见性时读取相应场景／镜头投影。没有语音参考也可依据明确创作要求提出新声音设计，但只能标为 D 类设计，不能写成已听辨的音色或已确认的真实声音身份。

## 2. 声源登记

| 要确认的关系 | 编排要求 | 不能据此推定 |
| --- | --- | --- |
| 画内人物发声 | 关联既有实体和稳定声源；记录本次可见性、方位及发声目的 | 图片中的脸、年龄或服装不能证明实际音色 |
| 画外人物发声 | 已知人物沿用同一声音身份，位置另记；未知人物保留未知 | 离开画面不自动成为旁白，也不要求新增人物 |
| 旁白 | 明确叙述声音、与人物的关系及是否可见；无依据时不补画面化身 | 旁白不自动要求可见角色开口 |
| 音轨里的词句 | 指向实际音频及其用途，区分节奏提示和复演 | 音乐里有人声不证明舞者演唱或需要口型 |
| 环境／动作来源 | 关联场景、物体或动作事件；详细事件交 M6.4 | 画面存在某物不证明源音频已包含它的声音 |
| 音色参考 | 说明允许参考的声音特征、目标声源、范围和来源 | 音色参考不同时授予原台词、旋律、节奏、人物身份或信号复制权限 |

源音频、可见主体和独立发声者可以关联，但不能用同一个编号含混代替这些关系。一份资产有多个许可用途时，逐项记录；视频有音轨也必须确认本任务是否启用该音轨。仅提供磁盘路径或文件名不能证明本轮已取得或听过文件。

## 3. 绑定流程

1. 列出观众应听到的声音，标明 F 类原文要求、A 类作者报告、D 类新设计或 U 类未知。证据分类见 [案例证据](case-evidence.md)。
2. 将每个实际发声事件关联到稳定声源。先处理已有实体、音轨或环境来源；确需新增来源时提出候选并回传 M2，不借声音需求改写人物身份。
3. 对参考资产记录“借什么、用于谁、在何处生效”，对未知属性保留具体原因。词句用途和表演方式交 M6.2，复制／参考关系交 M6.3。
4. 登记画内、画外、旁白或配乐来源及其可听关系。镜头改变只改变该镜的呈现，不自动更换说话者。
5. 交回 `sources` 候选、未解决身份／权限项及消费它的事件。父模块统一接受版本，M6.1 不代写其他分区。

## 4. 案例依据与提炼边界

**E06（F）：** 三人恶作剧的提示词分别把两句日语感叹分给 A、B，并把结尾咳嗽／笑声分给两人；画外拍摄者执行动作，却没有因此被写成第三个说话者。这支持逐事件核对发声者，不能推出“画面里每个人都要一个 Sx”。作者关于实际成片的描述属于 A，本轮未听音频。

**E02（A/F）：** 下山十二段 README 报告歌词／场景词引出额外宾客，提示词区分歌词锚点、情绪与视觉内容。由此提炼的 D 类规则是：音乐中名词、身份和情节不自动取得视觉生成权。原案例要求的轻微口部配合仅是该案创作选择，不上升为所有 MV 的默认行为。

**E01（F）：** 滨水双段明确说明人声内容未核实。仅存在音乐资产或拍网格不能据此填写歌词、歌者身份、声音年龄或音色。

旁白身份、复杂音色迁移和多人声源分离在本次已读案例中的实证不足；本页为其提供 D 类可追溯设计接口，尚未完成媒体效果验证。

## 5. H3 编排与审计

五模式主正文描述实际发声者、位置、表演与动作关系；Ref2VA 还在 `subject_definitions` 中交代可见主体及 Audio 用途。参考 Label、声音编号和确切格式交 [H3 映射](h3-label-mapping.md) 与 M11：`<Subject N>` 是参考可见内容，`<Audio N>` 是声音来源，`(Sx)` 标实际独立发声源，三者不互相代替。

直接复用的配乐中一句歌词仅作为时间提示时，声源仍可只有 Audio；不为舞者发明 Sx。独立角色或旁白实际发声时，交 M11 建立相应稳定声音标记。是否分配标记依据声音语义和官方协议 P，不依据历史案例标签习惯。

审核以下问题：声音有无悬空来源；同一人物是否跨镜无故换声音身份；一个音色参考是否被误扩成复制台词；画外声音是否被误写成旁白；未启用的音轨是否被当成当前输入；是否将未知听辨写成确定事实。

## 6. 局部失败与交接

来源或权限不足时，返回具体缺项和仍可成立的绑定草稿；不以静音或删除台词掩盖未知。身份／权限修复交 M2，词句／表演修复交 M6.2，原信号策略交 M6.3，跨镜身份与状态交 M8，时间和切点分别交 M7/M9，协议编号交 M11。只复核实际受变更影响的消费者。
