# M6 来源、许可与内容边界

## 核心摘要

本包实现冻结方案的第六核心职责：声音、音乐、对白与歌词关系，形成 `SoundPlan`。创作方法限定为本仓库 `case-studies/` 文本；冻结开发文档规定职责与架构；MiniMax 官方资料规定输入协议；Anthropic 与 Agent Skills 资料规定技能格式及创作方式。合同、路由和补充试用任务均属于本轮实现设计。

**关键结论：** M6.1—M6.4 分别提出声源、发声事件、音轨策略、环境与动作声音候选，M6 父级唯一接受。程序检查、Agent 文字任务、作者效果报告及真实媒体结果分别报告。

**关键词：** M6、SoundPlan、案例边界、来源版本、声音策略、协议、独立调用。

## 2. 证据类别和读取范围

| 类型 | 意义 | 可以支持什么 |
| --- | --- | --- |
| F | 案例原文事实、设计方案或明确规则 | 该案例的内容与适用范围；不自动等于生成效果 |
| A | 作者对成功、失败或测试的报告 | 保留报告归属，不能当作本轮复验 |
| D | 本轮合同、路由、规则细化和设计夹具 | 可供调用、检查与后续验证的实现 |
| P | 官方协议或技能格式资料 | 字段、Label、目录和格式；不能替代领域案例 |
| I | 本轮真实工具执行与 Agent 文字任务 | 对应记录中已执行的范围 |
| U | 未取得、未检查或未实现的证据 | 明确缺口，阻止越界的完成声明 |

逐文件索引登记路径、固定提交、哈希、读取范围及规则定位。文件清点、下载或关键字命中不等于全文语义阅读；索引必须据实际读取区分。图片、视频和音频未纳入本轮文本证据检查。

案例对音乐参考、母轨窗口、节奏关系、歌词与视觉解耦及部分动作声音有依据。完整多人对白、复杂打断／重叠、真实音色、口型、混音和自动转写不能由这些案例全面证明。补充的对白或未知输入任务属于 D/I 验证，不能登记为新增案例事实。

## 3. 模块与独立性

运行包只包含 `SKILL.md`、必要 `scripts/`、按需 `references/` 和可复制 `assets/`。元数据使用非空 `name` 与 `description`；技能名和目录名一致。开发报告、测试、实际试用和发布清单在包外，不成为运行依赖。

M6.1—M6.4 是同一技能中的四个公开职责入口，不以四份独立安装包冒充模块化。每个入口有最小请求、来源与版本、写入分区、局部验证和显式返回点；兼容输入可由用户或其他实现提供。父模块执行唯一接受路径；脚本不导入兄弟技能、不依赖项目私有对话状态。

完整复制此技能目录后可运行文字规则与 Python 3.10+ 标准库工具。Host 是否自动发现 `docs/h3skill/` 取决于宿主配置；仓库提交不等于已安装到任何特定宿主或已验证自动触发率。`agents/openai.yaml` 为可选宿主资料，本包不把它当作 Anthropic 必需文件。
