# M6.4 环境与动作声音

明确哪种环境或事件产生什么可听声音、何时开始和停止、来自源音轨还是需要新增。输出归 `SoundPlan.effects`；用 [公共合同](contract-guide.md) 交付，不以本页建立另一套声音字段。

## 1. 独立入口与最小输入

当任务需要环境底声、脚步、接触、衣料、水声、物体运动、定格音效或局部声音中断时调用。最小输入为环境／动作／编辑事件及本次希望听到的结果。可从用户给定事件直接提案，不要求先跑完整 M4 或 M6；缺声音策略时，保留新增意图并明确需 M6.3 确认，不能假装与完整复制自动相容。

按需读取场景关系、动作事件、声音来源和音乐策略。物体在画面里可见只是视觉事实，不证明当前声音一定存在或源音轨已收录它。

## 2. 分清声音类型

| 类型 | 需要记录 | 事件结束与连续性 |
| --- | --- | --- |
| 环境底声 | 环境来源、可听范围、持续条件、已在源内或新增 | 场景／听点变化是否影响它，由任务决定 |
| 动作接触声 | 施力或接触事件、接触双方、声音发生条件 | 接触结束、衰减或持续摩擦需分别说明 |
| 物体运动声 | 运动来源及与动作的关系 | 不能把视觉静止一律当声音立即停止 |
| 风格化后期音效 | 对应编辑／情绪事件和明确授权 | 与物理场内声分开，剪辑触发交 M9 |
| 非语言人物发声 | 人物及咳嗽、笑声、喘息等事件 | 交 M6.2 管理，保持发声身份而不伪装成无源拟音 |

声音的细节应服务当前观看任务。不因为案例存在夜巷、海滩或石地就为其他任务默认添加同样底声；也不把案例的“无对白”“单人”“固定机位”升级为跨案例全局限制。

## 3. 物理因果与编辑音效

将动作事件与声事件一一关联，例如“脚跟／鞋底接触石地后产生接触声”，而不是仅写“更真实、更有质感”。已有动作缺少接触时，不为音效偷偷增添一个跺脚或撞击；将必要动作调整交 M4。

E04（F）明确列出脚下降、接触石地、产生声音、切换袜饰的关系。这是有用的提示词事件结构，但原稿同时要求完整音轨复制，必须先解决新增声层冲突。不能只摘物理因果而把冲突写成已验证成功。

E06（F）把倒水、塑料面罩声、喷水和笑声与动作连接，又把定格时的倒带／冲击／短暂近静音作为后期效果。由此提炼 D 类规则：物理声音依据场内事件，风格化音效依据明确的编辑意图；两者均需来源及发生条件，但不能互相冒充。

## 4. 源内已有与需要新增

每项明确属于“源音轨内已有并保持”“需要新增／替换／删除”或“未知”。源内已有的判断需要可靠来源，未听音频时不能因为画面有接触就填成已有。

若最终音轨 `fully_copy`，只可描述实际源内已有并原样保留的声音。用户同时要求新脚步、环境层、呼吸或冲击声时，向 M6.3 返回策略冲突；由当前授权选择取消新增、改为部分复制，或指定另一次声音处理。即使处理在后期完成，最终声音关系也不能继续被标成未经修改的完整复制。

M6.4 不自行静音音乐、删改对白或改变复制策略来容纳效果；父模块按真实请求接受修改。缺少兼容策略时，保留有依据的效果候选及阻塞原因。

## 5. 静音、可听性和跨镜

说清静音覆盖哪个声层、哪个事件和什么范围。E06 的定格近静音是局部效果，动作恢复后环境声返回；该案全程无画外音乐仍有大量场内声音。E07 的厨房稿排除对白、歌唱和旁白，仍保留烹饪与环境声。

在公开合同中，M6.3 的 `Music.use_strategy=none` 只表示无配乐。明确全片静音由本子模块的 `Effect.event_kind=whole_track_silence` 登记，必须匹配真实请求 `whole_track_silence` 及用户依据；父 M6 检查它与其他声音是否冲突，不由 M6.4 擅自删除其他分区的事件。

需要声音连续时，记录“同一底声继续”“接触后的余响延续”或“切点处有意中断”等语义；M8 处理持续状态，M7 定位事件，M9 安排跨切装配。切镜本身不是所有环境声重启、淡出或归零的依据。未经实际听验，不宣称对白可辨、效果不遮蔽台词或响度已合格。

## 6. H3 编排与审计

五模式的主正文写动作与关键可听事件的对应，`overall_soundscape` 概括环境、效果和听觉层次。角色能听到的乐器、广播或手机声音是场内来源，进入主正文；仅观众听见的配乐由 `non_diegetic_music` 表达。参考 Audio 及使用关系由 M6.3/M11 编译，详细规则见 [H3 映射](h3-label-mapping.md)。

审核有无动作前无原因先响的声效、悬空来源、接触双方不明、把后期效果伪写为物理结果、把非语言人声误作环境声、完整复制仍新增效果、局部静音误覆盖全片、切镜造成未经设计的声音重启。

## 7. 证据限度与返回

本页依据 E03/E04/E06/E07 的文本要求，作者的音频分析和结果描述仍是 A 类报告。当前仅进行了文字检索、读取与编排；未试听原声或生成结果，不能报告拟音同步、声像、混音或最终音质通过。

效果或触发关系不足时，返回具体未知和仍可成立的局部设计。动作修复交 M4，人物发声交 M6.2，音轨策略交 M6.3，连续性和排时／编辑分别交 M8、M7/M9，当前模式语法交 M11；不为了补声音扩大本模块所有权。
