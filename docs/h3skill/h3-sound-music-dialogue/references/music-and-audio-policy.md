# M6.3 音乐与音轨使用策略

先说明复用的是声音信号、某个声层还是参考特征，再决定它怎样进入目标作品。输出归 `SoundPlan.music`；包括与音乐有关的来源／窗口／使用策略及无配乐范围，具体字段见 [公共合同](contract-guide.md)。明确的全片静音由 M6.4 在 `effects` 中登记，父 M6 核对各声层互斥关系。音乐分区不接管 M7 的共享时钟或 M9 的剪辑装配。

## 1. 独立入口与最小输入

出现原声复用、音乐参考、音色参考、音频切片、音乐新生成、无配乐或音轨策略冲突时调用。最小输入为任务范围、拟听到的内容、实际来源和许可的已知状态。没有音频时仍可提出新配乐的 D 类要求或明确未知；不能把文字描述当作已经听过、切过或测量过音频。

输入只需相关资产投影、用户需求和已存在的声音新增／删除要求；不要求先运行其他全部模块。涉及语音参考时读取必要的声源和话语投影即可。

## 2. 策略与边界

| 声音意图 | 编排要求 | 协议审计 |
| --- | --- | --- |
| 完整最终音轨复制 | 完整提供的源音频就是目标完整最终声音；无新增、删除、替换或再加工 | Ref2VA 对应 `fully_copy`；不是仅“音乐主体未改” |
| 局部信号／声层复用 | 说明复制的窗口或声层，以及新增、删除、替换部分 | 对应 `partially_copy`；保留整条配乐但加脚步或旁白也属于此类 |
| 精确特征参考 | 说明只参考音色、节奏、风格、词句或纹理中的哪些特征，以及目标用途 | 对应 `reference`；不声称直接信号复用 |
| 宽泛特征参考 | 说明只借类别或气氛，不承诺逐音一致 | 对应 `weak_reference` |
| 新生成 | 根据明确任务描述声音，不假定存在可复制的 Audio | 无来源不能虚构 Audio Label 或复制关系 |
| 无配乐／音乐层静音 | 说明适用镜头或范围；合同中 `Music.use_strategy=none` 表示无配乐 | 不推导全片无声；完整声音静音交 M6.4，未知不能冒充已确认静音 |

这张表中的关系词来自 P 类 [官方映射](h3-label-mapping.md)；内部业务策略不要求与官方字符串同名。`fully_copy` 的判断覆盖最终声音，而不只看 `non_diegetic_music` 字段。

若已存在且确认提交的是独立切片，可把这个提交切片作为源资产判断是否完整复制；必须保留它与原主音轨的来源关系。仍需从主音轨挑选／裁切的窗口，不得假装已经成为取得并确认的独立资产。选择和制作切片属于 M9，M6 登记已有窗口及声音要求。

## 3. 先解决矛盾，再生成正文

**E02：** 下山段一同时写“仅节奏参考、无信号复制”和“完整 1:1 最终音轨”。不能把两项无条件保留。依据当前用户要求，选择原信号复用或特征参考；选择不了时列出冲突及其影响，不偷偷删除其中之一。

**E03/E04：** 海岸剑舞和抬腿换装同时出现完整复制与额外海浪／脚步／布料／接触声。先确认这些声音是否本来就在源音轨里：源内已有且保持原样，可继续按完整复制理解；若需要新增、删除或替换，则策略必须是部分复制，并写清处理内容。实际源音频未读取时不能自行断定“已经内含”。

**E01/E05：** 滨水双段、袜饰三镜要求各段独立使用音频切片，并按主时间线拼接。案例支持区分提交切片与最后连续主音轨；不支持每个视觉镜头都从整首歌开头重播。

## 4. 源窗口和音乐时间依据

记录资产版本、源时间域、窗口来源、单位、已知边界，以及对应的段落／事件。文件名中的时间仅是线索，不等于实测时长；Windows 路径、SRT 转述或 README 的“精确”也不能代替本轮实际取得资产。

分别登记作者给定的 BPM／首拍、当前任务的要求、实际分析结果和未验证项。BPM 只给名义周期，不能单独证明真实首拍、重音、速度变化、歌词起音或任意时刻的拍点。没有媒体或可信测量记录时，输出候选结构和待核查项，不编写“实测 BPM”“精确拍点”或自动打勾。

E01 段二在源区间从 12.070 秒开始时仍复写首拍 0.070 秒，属于需要核对源／局部时间域的文本张力。由 M7 依据全局事件与源偏移计算局部位置，M9 保证窗口与装配一致；M6 不独立维护竞争拍表，也不直接判定实际音频错位。本轮未听原曲，不能替案例确认首拍。

## 5. 歌词、音色与音乐分工

音乐参考不自动授权声音身份复制，音色参考不自动继承旋律、伴奏或原词句。歌词可作有依据的音轨提示，但不能自动赋给画面角色、生成字幕、增加歌词中的人物／物件，或要求嘴部表演。实际人物演唱交 M6.1/M6.2 建立独立声音事件。

音乐的进入、退出、持续和与话语的关系可提出明确语义要求，例如“说话期间保持可辨”“跨镜保持同一音乐段落”。若需要具体混音值、淡入淡出、声层分离或变速，登记为处理需求与待验证项；不能把这类修改继续归为完整复制。主观音量描述不等于响度测量。

## 6. 静音与 H3 字段

无画外配乐不等于没有对白、场内音乐或环境声。E06 要求无配乐但保留现场声音及定格音效，E07 要求无配乐和无发声但保留厨房／烹饪声。局部近静音也不等于全片静音。

五模式均向主正文和两个声音字段交接声音关系；Ref2VA 另交 `subject_definitions`、`summary`、`retention_analysis`。Audio 直接复用与特征参考的任务类型、空值和 Sx 细节由 M11 按当前协议编译。历史案例的 `None`、自定义段落或把完整复用写成两个 `N/A` 的方式不能当作当前所有模式的通用模板。

## 7. 审计和局部返回

核对同一音频是否同时被写成无复制与完整复制；完整复制是否又新增声音；源窗口是否超出已知源时域；目标镜头是否无故重启音乐；时间是否只有文本声明而缺测量依据；静音是否与必保声音同范围冲突；歌曲人声是否被误分给舞者。

未决策略交父 M6，权限交 M2，词句／发声交 M6.1/M6.2，新增效果交 M6.4，时间交 M7，切片和混音装配交 M9，语法交 M11。保留可执行局部提案和具体未验证项；案例中写了数值或模型标签不等于本轮媒体结果已验证。
