# M7 审计、失败回传与版本交接

## 1. 按证据划分结论

| 检查层 | 执行者与输入 | 可得结论 | 不包括 |
| --- | --- | --- | --- |
| 格式与合同 | 离线脚本、实际 Request／Proposal／State | 字段、类型、来源引用、分区权限与版本相容 | 领域语义和媒体真实性 |
| 确定性时间关系 | 脚本、明确时钟与数值 | 区间、已实现约束、换算、量化误差 | 动作自然程度、实测节拍和 H3 执行精度 |
| 专业文字审阅 | 当前 Agent、原始要求、案例与公开计划 | 事件含义、观看任务、策略冲突与合理预算 | 真实视频已成功 |
| 真实媒体观察 | 相应观测执行者、实际输出与记录 | 记录范围内的真实偏差与效果 | 未观察镜头或未来运行结果 |

所有局部 pass 都带范围。未知的时间证据不能变成“无音频”“静音”“无切点”或“已对齐”。父级接受只产生新的内部草稿，不授予全项目 G0—G4 通过状态。

## 2. 子模块审计清单

### M7.1 时间依据

- 每个时钟有唯一 ID、域、对象范围和有版本的来源；相同数字不掩盖不同零点。
- 秒、毫秒、拍、帧的单位可解释；帧数、末帧采样时刻和覆盖时长口径分开。
- 源、生成、编辑 FPS 分别登记；有理数不提前截短；VFR 不以平均 FPS 精确换算。
- 候选网格有 BPM 与已知或明确未知的首拍偏移；实测声响有其资产和测量记录。
- 案例报告中的时长或帧数矛盾保留，不自动升格为 H3 能力限制。

### M7.2 事件排时

- 事件身份与所有者有效；动作／相机／声音／编辑事件不能借“同时”合并身份。
- 起止区间有序且落入声明范围；必须保留的最小持续、先后与偏移有来源。
- 相机提前到位检查到位对峰值，固定观察检查覆盖；不把 1:1 同步泛化成所有镜头逐拍启动。
- 对白、接触、保持、回收等必要阶段没有用无依据的重叠或零时长抹去。
- 有冲突时返回责任方，不擅自删动作、改台词、增加摄影运动或新增切镜。

### M7.3 映射与量化

- 映射引用真实选窗／编辑决定及版本；源窗口、有效生成时长和成片使用时长分别可解释。
- 变速方向定义明确，端点和区间跨度一致；无授权不选择变速或定格。
- 定格、多值、裁剪外范围、VFR 缺数据等情形不输出伪精确单值。
- 量化保留策略、原始时刻、帧号、误差和容差；关键先后在量化后复验。
- 源时间不直接充当 H3 生成局部切点；首尾帧口径按实际有效时长检查。

## 3. 修复归属

| 问题 | 首要回传 | M7 返回材料 |
| --- | --- | --- |
| 资产版本、音频标注或源 FPS 不清 | M2／M12；声音依据关联 M6 | 具体来源、冲突值、缺少的记录 |
| 动作预算无法容纳 | M4，必要时 M9／M1 | 事件、前提、可用区间、最小缺口 |
| 相机晚到或看不到关键事件 | M5，必要时 M3／M4 | 到位与峰值的时间关系、观看窗口 |
| 原文台词与时间预算不符 | M6，必要时 M9／M1 | 原文引用、当前预算、未测量项 |
| 剪辑选窗、速度或定格与映射冲突 | M9 | 编辑决定、输入输出端点、所需修订 |
| 后端帧率／有效片长或模式不明 | M11 | 任务 ID、所需参数与口径 |
| 邻接状态检查时刻受影响 | M8 | 原时刻、新时刻、关联事件和版本 |
| 已生成媒体偏离计划 | M12 记录，再定位专业责任 | 实际媒体版本、误差与本次复验范围 |

## 4. 父子接受与低耦合

各子模块按公开合同提交本分区，父 M7 对照实际原请求、证据、输入上下文与基版本唯一接受。已有事件和来源不能通过整分区替换被静默删除或改绑；同 ID 重试应幂等，改变已接受提案的内容需新的提案和当前基版本。

其他模块只读取需要的公开字段和版本。路由说明是调度合同，不代表已运行 M8—M12。将未知责任作为明确返回项，不要求为一个小任务重跑全部上游。

变更影响按实际 read_paths 定位。更改首拍、源窗口、速度或目标 FPS 时，登记真正读取这些值的消费者；只改标题或未被读取的字段不能使所有下游一律失效。未登记的依赖无法由脚本猜出，交接时须补全。

## 5. H3 最终交接

向 M11 提供每个生成任务的局部事件顺序、真实 Shot 切点、有效片长、关键帧落点和声音跨切关系。只交有依据的可执行描述，保持人物／资产和事件的稳定引用。

H3 正文使用官方字段和 Label，按镜头描述完整可见、可听事件。TimingMap、内部来源 ID、容差、工程规范和审计说明保留在制作记录。生成视频的帧级执行、节拍贴合、跨段接缝和成片效果需要实际媒体验证。
