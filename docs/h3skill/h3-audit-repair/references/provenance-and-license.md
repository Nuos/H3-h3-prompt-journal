# 来源、版本与内容边界

**核心摘要：** 领域规则只从本仓库案例文本提炼；冻结方案约束职责和路由；H3 官方资料约束模式、字段与 Label；技能规范约束包结构。工程合同和合成夹具另行标记。

**关键结论：** 本包提供可执行的审计工作流与记录工具；它不因具备 G3／G4 的登记接口便已完成真实视频验收。

**关键词：** 固定来源、领域边界、证据性质、许可、验证范围。

**目录导航：** 1. 来源分层；2. 离线资源；3. 格式与许可；4. 完成边界。

## 2. 离线资源

本包包含基础四模式与 Ref2VA 官方文本快照，固定版本和摘要见 `h3-protocol-source.json`。案例证据提供自足的规则、条件、反例与逐文件索引；完整原案例继续保存在仓库。本包运行时不依赖兄弟模块的私有脚本、在线网页或原仓库绝对路径。

在需要精确原句时读取对应离线官方文本；在需要真实素材、配置或媒体时取得任务本身的输入。离线资料不能填补真实任务里缺失的观察或后端证据。

## 3. 技能格式与许可

目录名与 `name` 一致，`SKILL.md` 包含 `name`／`description` 必需元数据及精简流程。`references/` 按需加载规则，`scripts/` 提供确定性工具，`assets/` 提供可复制模板和示例；`agents/openai.yaml` 是可选宿主展示信息。这些可选目录不构成 Anthropic 对每个技能的统一必需清单。

开发报告、测试、原始执行日志、来源核对和发布清单位于技能目录之外。不得把格式检查称为“官方功能认证”，也不得把工具退出成功称为所有 Gate 通过。

`case-source-LICENSE.txt` 保留案例仓库的 MIT 许可与作者归属。H3 官方快照保留 `h3-NOTICE.txt` 及来源记录中的独立许可信息，不改标为本项目许可。格式标准的既有原文及许可保存在仓库 `_standards/`；本轮未修改这些快照。

## 4. 完成边界

Python 工具只核验显式 JSON 与记录关系，不自动理解全部电影语义、不证明任意外部日志真实、不解码媒体、不调用生成服务，也不写入其他模块。Agent 的语义审阅、观察工具、生成执行和全片验收是各自需要证据的操作。

本轮实现、文本试用和程序验证不代表 H3 推理或真实媒体效果验证。示例中的虚构资产、来源、观察或依赖只检验合同；实际任务必须使用真实资料，并按实际覆盖报告结论。
