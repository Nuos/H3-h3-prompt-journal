# M12.3 媒体观察与测量登记

**核心摘要：** MediaObservationLedger 保存实际看见、听见或测得的事实，与计划值及评价分开；每条观察绑定媒体、计划、方法、时间域和覆盖。

**关键结论：** 提示词、文件名、工作流截图和作者报告不能替代本轮媒体观察；登记程序不会自动解码或观看媒体。

**关键词：** 媒体身份、计划版本、观察、测量、抽样、覆盖。

**目录导航：** 1. 最小记录；2. 执行观察；3. 时间与通道；4. 抽样与完整性；5. 偏差；6. 历史与复核。

## 1. 固定最小记录

登记媒体 ID、版本、文件定位和内容摘要；记录它是源素材、生成片还是实际装配成片，并引用对应计划及配置／装配版本。没有文件或无法访问时登记缺项，不能创建声称“观察到”的事实。

每条观察注明观察者或工具、实际方法、时间域、开始与结束、视频／音频通道、观察覆盖、发现及限制。测量值注明单位、方法、分辨率或容差；未经测量的近似观感不伪装为精确数值。

## 2. 将事实与判断分开

先记录可定位的事实，再与要求比较。例如“在该时间窗内，右手离开道具后道具仍停在空中”是观察；“不符合当前重力与支撑要求”是比较；“某条提示词导致悬空”是尚需证据的归因。

外部工具或人工观察可以作为兼容输入；保留实际观察者与原始日志，不把本 Agent 作为并未执行的观察者。工具仅检出候选时仍需复核：低阈值场景变化可能来自快速运动或光晕，同景同机位硬切也可能漏检。

本包只登记显式结果并核验它们的合同关系。需要视频逐帧、播放听音或实际测量时，由有相应能力的观察者／工具完成并保留证据；缺能力则报告未验证。

## 3. 不混用时间域和通道

区分源素材时间、作品计划时间、生成局部时间和最终编辑时间。裁剪、变速、定格、插入保持或重采样之后，使用 M7 的有效映射；不能把同一毫秒值直接套到另一个时间域。

帧号需要帧率、计数约定与容差。关键动作与声音是否“同帧”必须有双方实际时间依据；只看视频帧不能认定音频同步。未听音轨不报告对白原词、声源或节拍通过。

## 4. 保留抽样范围

| 方法 | 可以报告 | 必须保留的限制 |
| --- | --- | --- |
| 单帧或少量关键帧 | 这些采样位置的姿态、构图、接触或可见内容 | 不能证明采样间连续运动、全片身份稳定 |
| 连续窗口审阅 | 所声明区间内已观察的连续条件 | 不能扩展到其他窗口或未检查属性 |
| 全片播放 | 实际播放版本和通道下的观察 | 播放过不等于所有细节已逐帧、测量或判断 |
| 信号／数值测量 | 指定指标、区间和方法的值 | 不能直接证明叙事理解、自然表演或美学质量 |
| 合成夹具／模拟日志 | 记录接口的可运行性、错误处理 | 不构成真实 G3／G4 验收证据 |

观察覆盖以要求为单位判断。即使扫描了所有帧，也不能据此声称测量了每一种声音与视觉条件。抽样可以报告明确采样位置的局部事实。本版程序对 G3／G4 的通过采用 full_window 覆盖要求，sampled 记录不能升级为通过；这属于当前接口的保守实现边界。不能将原本要求完整检查的任务静默降级。

## 5. 比较偏差

将观察中的期望值与实际值关联到同一计划范围，保留身份、动作、支撑、道具、空间、相机、视觉、声音、时序及接缝中实际关注的条件。对合法蒙太奇按照该边界允许变化的属性评价；不要把所有属性差异一律叫作连续性错误。

生成媒体不符合计划时先登记偏差；M8 可据此提出接受实际末态的新计划，其他责任模块可提出修订或重生成。M12 不覆盖 M8 的计划，也不为了让结果一致而改写原观察。

## 6. 保存历史与复核

媒体变更形成新媒体版本和新观察；原媒体与失败仍保留。仅计划、检查范围或方法改变时，可以复核同一媒体，建立新的计划关联与检查记录，并说明哪些观察事实仍适用。

本版合同锁定同 scope 的原检查含义和方法。改变检查语义或方法时建立明确的新范围并保留旧问题；要关闭旧范围的问题，仍需满足原检查，不能用新范围中的较弱判断替代。

禁止以更新媒体文件但保留原版本、覆盖旧测量或删除失败窗口的方式获得当前通过状态。是否必须重新生成取决于修复方案与实际媒体是否仍满足新要求，不能机械要求每次文字修订都重跑 H3。
