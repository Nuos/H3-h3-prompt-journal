# 审计记录

模板用途：复制为独立审计文档后填写；不是 H3 模型正文。保留未验证范围，不把模板空项解释成通过。

## 核心摘要

填写本次任务、检查对象版本、实际检查范围和主要结论。

## 关键结论

填写已完成条件、发现的具体问题、仍缺证据的条件，以及本次结果允许支持的交付声明。

**关键词：** 按实际对象填写。

**目录导航：** 1. 要求与范围；2. 输入版本；3. 检查与 Gate；4. 媒体观察；5. 变更和复验；6. 未覆盖范围；7. 来源。
