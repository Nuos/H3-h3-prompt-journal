# 三人物遮挡衔接式环绕长镜头：案例简评

## 2. 多维简评

**方法与输入输出。**输入三张图，输出一条20秒长镜头。最有价值的是区分“在场、可见、被揭示”，并为身份、环境和环绕中心分配职责；遮挡具有前置条件，避免只有转场名称而缺少发生过程。[S3：4–164、247–330]

**编排与状态。**“完成环绕后才能揭示下一人”提供了优先级。但人物站在最终位置、彼此接近、全段不允许其他人露出、摄影机绕到后侧且不得穿模，这些要求需要共同满足；现有文本未给出站位、视场、遮挡范围和机位轨迹的联合检查。不能仅凭负向清单判定其可行或不可能。[S3：68–164、1189–1279]

**验证与泛化。**README 将命名模式描述为突破，并报告成功成片；未提供版本、参数、重复次数及失败分布。本次只核验文本。词汇文件也提醒：命名不是模型接口，“最终同框”不能独立证明此前存在连续三维空间；译文对“证明”的保留不增加证据强度。[S1：31–41、61–70；S4：1585–1589；S5：90–107]

## 3. skill 化判断与最小落地步骤

建议先限定为“三人、同一环境、遮挡接力”原型：输入参考职责、人物站位、可见性表和目标时长；输出统一时间轴、各段入出机位及遮挡条件；逐项检查身份、意外露出、环绕角度、遮挡后的连续性和结尾构图。不同人数、拥挤环境或反光场景须另做验证，不宜直接扩成通用多人运镜 skill。以上为封装建议，目录未提供可执行实现。

## 4. 主要缺口与优先级

- **P0：统一“完整环绕”。**README 写每人360°，正文的完成条件是前侧→三分之四→侧面→后侧，没有明确完成360°；应选择单一可验收定义，避免把“经过多个方向”与整圈混用。[S1：29；S3：275–330]
- **P0：统一时间预算。**人物2/3的分段标题分别从6.5/13.0秒开始，总节奏表却将6.5–7.5、13.0–14.0秒分配给揭示，正式环绕从7.5/14.0秒开始；README 的结尾约2秒，正文只留19–20秒。应明确转接是否计入环绕、超时时如何保留末段，而不只说完整性优先。[S1：65–68；S3：582、709、981–1104]
- **P1：补空间预检与回归。**为站位、遮挡和短后拉的多人构图建立共同可满足的样例；保存版本化生成记录，并将“实际看见的连续性”与“文字要求物理连续”分开评分。[S3：141–164、780–925；S5]
