## 四、优先沉淀方向

### 1. 先统一长篇音乐舞蹈的编排主流程

以[神裂十八段](./2026-10-kanzaki-beach-sword-dance-18-segment.md)和[十三段古典武侠舞](./2026-10-classical-wuxia-dance-13-segment.md)的方法文为主骨架，吸收[下山](./2026-10-xiashan-veiled-solo-twelve-segment.md)的穿戴物保护、[白凤](./2026-10-baifeng-mengchen-classical-dance-six-segment.md)的匹配剪辑。建议输出顺序为：参考权限表→音乐事件表→动作与段落计划→相机/剪辑模式→跨段状态表→各段完整提示词→静态检查和生成后验收。此处是后续实现建议，当前未创建编排器。

### 2. 规则库按任务选取，并明确冲突处理

[动作链库](./2026-10-dance-motion-chain-library.md)、[物理机位库](./2026-10-physical-camera-position-library.md)、[动态运镜纪律库](./2026-10-camera-movement-discipline-library.md)适合由主流程按需引用。提前到位、同步跟随、延迟观察，以及收势切、动作中匹配切，应各自带适用条件。身份图是否控制起始姿态、是否允许重描外貌、镜头是否允许数值角度，也应由当前项目明确选择，避免把不同案例的局部规则全部叠加。

### 3. 专项能力以可观察事件或状态接口封装

优先候选包括[触地换装](./2026-10-leg-lift-contact-cut-stocking-six-look.md)、[右入展示装配](./2026-10-sock-showcase-right-entry-three-shot.md)、[多人队形接力](./2026-10-four-subject-formation-choreography.md)、[手势控舞](./2026-08-first-person-finger-controlled-dance.md)。输入和输出要能列成事件表或状态表，验收也据此检查。对于[水上综艺](./2026-08-water-obstacle-variety-show.md)等开放叙事，则保留“必要剧情固定、具体动作开放”的策略，采用事件完整性与粗略时间预算。
