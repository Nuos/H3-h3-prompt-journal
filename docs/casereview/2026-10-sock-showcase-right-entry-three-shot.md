# 右入换装三镜流水线：案例简评

## 核心结论

**适合封装“状态目录→独立生成→音频对位硬切”的展示类子技能。**案例把视觉变化拆成三个生成任务，明确恒定项、唯一变化项和装配边界，并提供失败修正与提交检查。它的方法论较完整；主要问题是 README 对切点两侧状态的表述与最终提示词不一致，且尚无执行包及回归记录，不能将“一镜一状态”扩大为所有 H3 任务的通用法则。[S1][S2]

## 3. skill 化判断与最小落地步骤

建议输入结构包括恒定属性、可变属性、每个状态、入画方向、局部时长、全曲音频偏移、文字开关；输出为三类材料：每镜提示词、剪辑决策表、验收记录。镜头数量应由状态数量推导，时间边界和音频切片通过计算生成。[S1][S2]

最小验证集应包含两种以上展示对象和不同状态数，检查首帧新状态是否成立、是否多出人物、固定构图是否保持、剪接时长是否准确。当前 1.667—2.267s 的生成段仅是案例要求，实际调用还需核验目标 H3 工作流支持的时长、帧数及裁切方式；文本没有提供这些运行参数。

## 4. 主要缺口与优先级

1. **P0：修正切点机制的文字冲突。**README 第 26 行说切点两侧都在迈步中；但其第 3、22 行及最终 prompt 均为上一镜保持 pose、下一镜跨步入画。应采用“pose→跨步”的可见跳切定义，不能误写成同一动作无缝续接。[S1：3、22—26；S2：18—25、45—52]
2. **P1：限定参考图权力例外。**主体定义称服装及全部配饰均由图 1 决定，同时又要求袜饰按状态改变。应明确“除当前状态指定的腿部袜饰外均保持”，使恒定项和变化项成为可检查的属性集合。[S2：15—25、41—52、69—79]
3. **P1：补齐检测候选点的处理记录。**README 记载 4.4s 也被检测到，最终只选 2.267/4.233 两个切点；应解释 4.4s 是忽略、合并还是微镜头取舍，便于复用反推流程。[S1：13、42；S2：90—98]
4. **P1：建立参数与成片回归。**保留固定机位、单人、无字等可判定项，配模型/工作流版本及失败记录，再验证跨任务可靠性。
